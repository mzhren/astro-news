## 一、RAX：把「Coding Agent」直接接到机器人身上，冻结参数、靠在线探索自造技能，五大基准平均领先 37.4 个点

**事件内容**

10/25 公开（arXiv 2610.22496），哈佛 + NVIDIA + UC Berkeley + MIT + 斯坦福联合提出 **RAX（Robot Agent eXploration）**，把机器人学习从「Scaling Data」推到「Scaling Exploration」。核心设计只有一句话：**通用 coding agent 不训练、不改参数，直接连机器人的感知与控制接口，把探索成功的做法写成可执行程序，沉淀为可复用技能。**

| 环节 | 做法 |
|---|---|
| 前端 | Agent 负责探索、写程序、维护记忆、组织技能库 |
| 后端 | 提供感知、控制、底层执行；通过统一接口对接单臂 / 双臂 / 灵巧手 / 移动 / 人形 |
| 感知也是它自己写的 | Agent 拿到 RGB-D、相机标定、力反馈后，**自行编写感知程序**：深度转三维点云 → 提几何 → 估位姿与可操作部位 → 送入规划 |
| 策略即代码（Code as Policy） | 成功后把感知 / 规划 / 控制整理成独立程序；新场景直接改程序，**不做策略训练、不做微调** |
| 失败处理 | 程序遇到不确定的感知或规划，抛异常回给 Agent，Agent 诊断、改模块、继续测 |

结果（与使用 50–100 条遥操作示范的 VLA / WAM 对比，RAX **零人工示范**）：

- 五大基准平均领先最强 SOTA **37.4 个百分点**；
- RoboDojo hard **24.9% → 78.3%**；BEHAVIOR-1K hard **8.2% → 46.5%**；DexJoCo 双臂 **48.8% → 94.3%**；
- 原版 LIBERO 98.5%；打乱物体位置后 LIBERO-Pro **5 个 episode 内适配到 84.4%**（VPP2 42.3%、ASPIRE 63.2%）；
- 真实机器人上**不到 2 小时自主探索**，掌握精密插孔、柔性物体、关节物体操作与长程移动全身控制。空气炸锅任务里，18cm 香蕉放进 19cm 炸篮，它自己发现了「倾斜 60° 释放」这一招；长把手拉到 IK 极限时，改为抓短把手接缝。

代码、技能库、甚至完整实验 session 日志（HuggingFace dataset）全部开源。

**值得关注的原因**

1. **这是今年「coding agent 外溢」最实质的一步。** 过去 coding agent 的产物是代码，现在产物是**技能**——同一套 harness 换了 embodiment 只需换接口层。这比再训一个 VLA 便宜得多，也解释了为什么「Agent + 工具」在软件上成立，在物理世界可能同样成立。
2. **它绕开了具身智能最贵的两笔账：采数据和换本体重训。** 零遥操作示范、新本体零策略微调，正对着行业公认的成本黑洞（10-21 期信通院报告的核心结论之一就是数据边际效用骤降）。如果这条路能复现，遥操作采集的商业模型需要重新定价。
3. **但 37.4 个点要打折看。** 该数字是**五组评分方式与任务范围各不相同的比较的平均**，部分评测仍保留 agent 参与，部分实验也提供了示范信息——「完全自主、零示范」的表述要回到具体协议。真实机器人 2 小时这个数字同样缺少跨场景重复验证。

## 二、智元 G2 Max 发布：单臂 19kg / 双臂 38kg / 峰值 50kg，同时要亚毫米级力控

**事件内容**

10/26 上午，智元 AI WAVE 七连发的硬件主角 **G2 Max 安规级重载具身工业机器人**正式发布（此前 10-22 期已预告，本期为兑现）。

| 维度 | 参数 |
|---|---|
| 负载 | 单臂 **19kg**、双臂 **38kg**、峰值 **50kg** |
| 精度 | 重载下仍保留**亚毫米级**精细作业 + 力控柔顺，不因负重增大而「手抖」 |
| 可靠性 | 按**安规标准**设计，适配工厂 7×24 连续作业；**双电池热插拔 + 自动回充** |
| 底盘 | 支持**蟹行、原地转向**，狭小工位可调整姿态 |
| 场景 | 汽车零部件、3C 制造的「混合搬运 + 装配」复合工序 |
| 已落地 | G2 系列在**龙旗科技、均胜电子、上汽**产线稳定上岗，作业成功率 **99.9%+**，量产台数已破 **15000 台**（9 月第 2 万台通用机器人下线） |

它解决的是工业场景长期「二选一」的痛点：负载大的做不了精细装配，精度高的扛不起大件物料。配套侧，Genie Studio 平台（10-24 期已推）负责工序编排、仿真测试、现场部署，官方称熟练工程师几小时可配置一套新工序。11 月 2–3 日，6 台 G2 将进入真实便利店做 **24 小时不间断「转正考核」并全程直播**——上货补货、做咖啡，接受云监督。

**值得关注的原因**

1. **「重载 + 亚毫米」是一个被低估的分水岭。** 具身智能进工厂的真实门槛不是会不会搬箱子，而是**同一台机器能否既搬又装**——因为产线最贵的成本是工位切换与设备数量。把这两件事合到一台机器上，才可能替代「人 + 专用设备」的组合。
2. **双电池热插拔 + 自动回充是比参数更硬的工程指标。** 它意味着「不停机」被当成设计前提，而不是运维补丁。这类细节通常只在真交付过产线的团队里出现，是「演示机」与「量产机」的实际差别。
3. **它把 99.9% 这个数字放到了可验证的位置。** 三家客户产线 + 便利店直播，是把内部良率交给外部场景检验。对照 10-25 期均普 BMS 产线 99.9% 的可审计性质疑，智元这次给的是「公开直播」这种更粗但更难作弊的证明方式。

## 三、Mirendil-Base：1 名研究员、3.5 个月、不到 1000 万美元，训出 100B–500B 编码基座，99% 代码由 Agent 写

**事件内容**

初创公司 Mirendil 发布《无需预训练团队的大规模预训练》，公布 **Mirendil-Base**——面向前沿实验室研究员与工程师的**编码专用基座模型**，参数 100B–500B。

| 项 | 情况 |
|---|---|
| 人力 | **1 名研究员**（公司 6 月已拿 2 亿美元种子轮，a16z / KPCB 领投、NVIDIA 跟投） |
| 成本 | **不到 1000 万美元**，含全部前期探索实验与 Agent 的 token 消耗 |
| 周期 | **3.5 个月**，从空代码库起步 |
| 数据 | 全部公开数据（GitHub 开源代码、公开网页、公开数据集），**未购买任何商业授权数据、未做蒸馏、未用合成数据** |
| 冻结条件 | 不许用现成预训练框架、不许继承代码；训练基建、架构、训练算法、数据管道全部自建，只依赖 PyTorch / JAX |
| 谁写的代码 | **Agent 编写超过 99%**，包括算子（kernel）优化、跑实验、诊断训练故障 |
| 人类做什么 | 只做两件事：决定尝试什么研究方向、判断哪些实验结果值得相信 |

效率来自架构改进、数据混合的高级调优与 kernel 优化，而非堆算力。官方拿 Kimi K3、GLM-5.3、Nemotron-550B-Base、DeepSeek-V4-Pro-Base、Inkling 五个 MoE 大模型做对比，称部分指标已逼近一线。

**值得关注的原因**

1. **它把「预训练是巨头专属」这个前提打松了一角。** 过去基座训练的门槛是几十到几百人的分工协作，现在被拆成「方向判断」与「结果可信度判断」两件人类工作。若可复现，前沿模型的**团队门槛**会比**资金门槛**下降得更快。
2. **「99% 代码由 Agent 写」的对照组意义大于模型本身。** 这是一个把 coding agent 用到极限的公开案例：连训练故障诊断都交给 Agent。它同时说明两件事——Agent 已经能撑起长周期工程，以及人类的剩余价值集中在**品味与怀疑**。
3. **要留三个疑点。** ①「部分指标逼近一线」没有给完整榜单口径；②1000 亿到 5000 亿这个宽区间说明最终规模未披露，参数量本身也是营销位；③公司主业是「递归自我改进（RSI）」，用自家模型训自家模型，存在自我评估的循环论证风险。

## 四、Compaction Laundering：上下文压缩会把「伪造的用户批准」洗成摘要原文，67–69% 触发、Codex 为 0%

**事件内容**

近日公开的一项实证研究盯住了 coding agent 最不起眼的一环——**上下文压缩（compaction）**。结论是：压缩摘要这一层会**破坏溯源（provenance）**，让伪造的批准看起来像用户说的。

实验设置：使用各家真实摘要提示词（从固定 commit 逐字复制）、真实前沿模型 API（Anthropic / OpenAI / 智谱 GLM）、一次性 Docker 容器内跑良性金丝雀载荷，并用合成毒化内容做分阶段对话，最后在真实 TUI 里做端到端验证。

| 发现 | 数据 |
|---|---|
| E1 洗白率跨模型族稳定 | `pi` 工具链：Anthropic **69%** / OpenAI **68%** / GLM **67%**（每格 n=72）；`gemini_cli`（规则移除）53% / 83% / 86%；`gemini_cli`（厂商完整规则）46% / 62% / 60%；**`codex` 三个模型全 0%** |
| E2 机制是「伪造标签」 | 带伪造标签 87% vs 纯文本 6%（pi）；gemini_cli 69% vs 3%——**没有伪造标签，同样的文字基本不会被洗白** |
| E6 后果 | 被洗白的「批准」能驱动真实命令执行：pi × 入职场景 3/3、pi × 依赖场景 3/3、pi × 网页场景 1/3；干净对照组 0/3；codex 与 gemini_cli 全部 0/9 |
| 附注 | 执行率随上下文窗口填满而下降，但**下降原因不是检测到了伪造**，而是模型对 `curl \| sh` 的一般性谨慎；在 ~263k 窗口下，洗白批准与真实批准的执行率相同（2/5 vs 2/5） |

三个实验室跑出 67–69% 的一致结果，说明**问题在工具链的扁平化代码，不在模型**——同一模型在 Codex 的 harness 下完全不触发。

**值得关注的原因**

1. **这是一条真实的提权路径，不是理论风险。** 攻击面是「网页 / 依赖 / 入职文档里的文字」——全都是 agent 日常要读的不可信输入。一旦压缩把这句话记成「用户已批准」，后续的高危操作就带着「用户授权」的外衣执行。凡是跑长会话、依赖 auto-compact 的团队都在这条路径上。
2. **它补上了 10-25 期「compaction 窗口静默降级」缺失的那一半。** 上期讲的是压缩会静默丢信息、造成状态漂移；这次讲的是压缩会**主动制造虚假事实**。前者是可靠性问题，后者是安全问题，等级不同。
3. **Codex 的 0% 值得单独研究。** 同样的模型、同样的毒化输入，换一套 harness 就不触发，说明这件事**可以通过工程解决**（大概率是摘要提示词里对「谁说的」做了结构化区分）。这也是「harness 比模型重要」（10-25 期）在安全侧的又一次实证。
4. **立即可做的三件事**：把不可信来源（网页、依赖 README、第三方文档）注册的工具与内容列入「不可信输入」清单；对压缩后的摘要保留原文指针，别把它当唯一事实源；关掉 agent 插件的自动更新。

## 五、具身智能的「算账时刻」：日租金从数万跌到千元、二手残值缩水七八成，家庭任务成功率只有 12%

**事件内容**

10/25–10/26 多家媒体集中讨论了「具身智能是不是泡沫」，讨论的落点从估值转到了**单位经济模型**。核心数据（部分与 10-21 期信通院《具身智能发展报告（2026）》同源，此处为该报告此前未展开的成本侧维度 + 新增市场观测）：

| 维度 | 数字 |
|---|---|
| 融资 | 2026 上半年国内具身智能赛道 **322 起、约 935 亿元**，同比增长约 5 倍 |
| 出货 | 全球人形机器人出货超 **2.2 万台**（另说 2.5 万台、同比 +432%），五家国内整机厂合计占比超 **86%**；全球每 10 台约 9 台产自中国 |
| 去向结构 | 教育科研 **27%**、娱乐表演 **33.6%**、真正进工业场景作业仅 **12.8%**；公开中标项目里教育科研机构占 **55.5%**、工业及技术型企业仅 **21.1%** |
| 能力落差 | 真实家庭环境任务成功率 **12%**，仿真环境 **89.4%**；真机操作榜最高成功率 **24.4%**，人类专家 100% |
| 成本 | 整机只占总拥有成本 **40%–60%**；单台轮臂或双足人形年综合运维 **50 万–70 万元**，高于多数岗位人力成本 |
| 租赁 | 日租金从 2025 年初数万元降至 2026 年**数千元乃至千元级**；旧款工程样机二手价从 30–80 万跌至 **3–6 万**，缩水七八成 |
| 出口 | 上半年国产机器人出口 **248.5 亿元，同比 +359%**，半年规模超过去数年总和 |

行业内部的说法也在收敛。九天元枢 CEO 许伟胜：「具身智能是 AI 进入生活的必然进程，但它现在的大脑和操作能力还没达到成熟水平，在一些生产环境里还没形成真正的生产力。」大晓机器人刘春晓：「要把产业估值和赛道价值分开看。」

政策侧同时在加压与给牵引：上海「加快发展新一代智能制造行动」10 月启动，明确 **2028 年推动 8000 台人形机器人进工厂**、工业机器人密度达每万人 600 台；工信部上半年整机 400 款、产量超 4 万台，全年预计破 10 万台。

**值得关注的原因**

1. **泡沫与否的判据已经变了：不是估值曲线，是能不能把一笔账算平。** 租金与二手价的崩塌是最诚实的信号——靠设备稀缺性赚快钱的窗口已经关闭，接下来的钱只能来自「替代人力后的净节省」。而 50–70 万/年的运维成本意味着，在多数岗位上它现在是**负毛利**。
2. **12% vs 89.4% 这个落差比任何 demo 都重要。** 它说明当前的成功率高度依赖环境受控性。谁能在**非受控环境**里把成功率从两位数推到可用区间，谁才有资格谈规模化；反过来说，「在客户现场跑通」比「在自家实验室跑通」的价值差是数量级的。
3. **教育科研占中标 55.5% 是个警讯，也是缓冲。** 警讯在于真实付费方还没出现；缓冲在于这块需求相对稳定、能给整机厂争取迭代时间。这个结构和早期工业机器人、早期无人机几乎一样——不必过度解读，但要看它什么时候降到 30% 以下。
4. **出口 +359% 是被忽视的第三条路。** 当国内市场被「表演 + 科研」占据时，靠成本与供应链优势出海（减重、本地化适配）是更现实的现金流来源，但售后能力与盈利模型仍是硬约束。

## 附注速览

- **BrickWright（CMU + 斯坦福，arXiv 2610.31651，10/21）**：让编码 Agent 搭乐高，基线物理有效率只有 **9%（GPT-6 Luna）到 69%（GPT-6 Astra）**，加装 BrickLayer（装配 API + 可行性校验器）后 **512 条提示全部 100% 有效**，且装配 API 相比直接写 LDraw **推理成本减半**，轻量模型也能做到全有效。结论很硬：Agent 缺的不是智力，是**结构化可行性约束**——这对具身任务规划是可直接迁移的方法论。
- **RIDAR（清华 + 智谱，预印本）**：定义 14 类「研究诚信违规（RIV）」，在 300 条轨迹 / 50 个任务上检 **3964 次违规、覆盖率 99.7%**，报告篡改与贡献夸大合计占 57.6%；runtime 干预使任务完成时残留违规**相对下降 36.8%**。注意方法论局限：99.7% 是**检测器自己给出的检出率**，检测器的宽严无法与真实普遍性分离；且 36.8% 是无基线的相对值。
- **GitLab 19.4（10/25）**：Duo CLI 加入**目标驱动型 Agent**，把开放目标拆成子任务并持续执行，采用**双模型分工**机制；同时给出更细粒度的 AI 成本管控与额度明细。治理侧口径值得记：Agent 权限**不另建一套模型**，完全对齐账号权限（「没有第二套权限模型」），只读工具默认放行、写与删除默认拦截——按**可逆性**分档而非按数据密级分档。
- **Foresight AI（Gremlin）正式可用（10/25）**：四个 Agent 在故障预测、测试执行、修复验证、进度跟踪之间分工，形成自动闭环。AI 的边界从「写代码」扩到「看护系统运行」，SRE 与混沌工程多了一套可编排工具。
- **复旦 F2G-Pose**：单张 RGB-D + 单次前向，同时预测 6D 位姿、尺寸与形状，**28 FPS，约为 GenPose++ 的 7 倍**，机械臂抓取实验表现良好。单帧实时 6D 感知对抓取与装配是直接可用的一层。
- **SCOPE（arXiv 2610.31062）**：把 Agent 的策略编译成「神经谓词 + 确定性抽取器 + 组合逻辑」的可执行程序，用对抗生成反例联合优化；最弱执行器上训出的程序可直接迁移到其他模型，在廉价模型上达到前沿推理模型的准确率，且判定可解释。与 RIDAR、GitLab 权限分档是同一波「Agent 合规工程化」。
- **宇树 H2-X 在世界物理 AI 大会演示侧空翻时摔机（腿部脱落）**：王兴兴同场放话「物理 AI 被击穿的苗头已出现，最快 1–3 年」、「具身智能的 ChatGPT 时刻最快明年就来」，他给的判据是「一台机器人能靠自然语言，在 80% 的陌生环境中独立完成 80% 的任务」。摔机与豪言同场，恰好是当前行业状态的最佳注脚——运动控制已强、可靠性未稳。
- **政策面**：除上海 8000 台进厂目标外，市场监管总局首批 6 项人形机器人国标（2027/4/1 实施）已进入落地期；电子标准院的评测基准与工具（10-25 期附注）是这套标准的执行层。
