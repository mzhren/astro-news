## 一、Anthropic 发布 Claude Duet：Coding Agent 的 harness 被打包成通用个人智能体

**事件内容**

Anthropic 于当地时间 10/21 推出个人智能体应用 Claude Duet（研究预览，美国区 Pro/Max 候补申请），10/22 起在国内媒体扩散。

| 维度 | 具体情况 |
|---|---|
| 基座 | Claude Opus 5.5 |
| 形态 | 独立 iOS / Android App + claude.ai 网页端，非聊天窗口内嵌 |
| 执行环境 | 独立带浏览器的云端虚拟机，用户关掉手机/电脑后任务继续跑 |
| 工具面 | 可调用 Claude Marketplace 超 6000 个连接器与插件（Gmail、Slack、QuickBooks、Stripe、Gusto、Canva、Shopify 等）；无连接器的网站靠浏览器兜底 |
| 状态继承 | 直接继承原 Claude 账户的记忆、Skills、应用授权，无需重新配置 |
| 计费 | 预览期不单独收费，共用 Pro/Max 额度；每数小时巡检一次已连接账户，巡检越频越耗额度 |
| 支付 | 已接 Stripe Link 与 Shop Pay，虚拟卡机制，Duet 本身不持有完整卡号 |
| 安全 | 不获取密码与登录 token；发信、支付、签约、删除必须用户确认；内置分类器专门拦截信用卡号与身份证件 |

Anthropic 自己承认的短板：会误读对话、误判紧急程度、后台巡检间隙会漏新事项、个人事务（购票类）表现弱于职场任务。科技媒体 Every.to 联创 Dan Shipper 实测反馈：邮件文本质量不及 ChatGPT Dots，定时任务无法调用自定义连接器。

**值得关注的原因**

1. **这是 coding agent 那套 harness 的通用化移植。** 独立 VM + 后台长任务 + MCP/连接器工具面 + 记忆继承 + 敏感操作确认，这五件套正是过去一年 Claude Code 类工具在终端里跑通的东西。现在被原样搬到了「办公场景」，说明这套架构已经被验证到可以产品化复用。
2. **竞争壁垒从模型能力挪到了「记忆 + 连接器 + 安全架构」。** 国内同类：阿里千问 Go 已开放体验、腾讯元宝在研独立 App「元宝助手」、字节传将出「小豆」（Spell 项目）。Meta Muse 的做法是用户专属云端安全 VM + 独立 Sentinel 组件审核对外操作。真正难的不是模型，是谁能拿下企业系统的连接器授权。
3. **对做 Agent 产品的直接参考价值**：Duet 把「巡检频率 ↔ 额度消耗」做成显式成本项，这是个很现实的设计取舍——主动型 Agent 的成本模型和被动问答完全不同（Gartner 预计 AI 智能体与助手支出从 2025 年 164.8 亿美元增至 2027 年 654.7 亿美元）。

## 二、腾讯混元 + 复旦 WorkForge：给 Agent 造了 1.67 万套「可验证的真实职场」

**事件内容**

10/22 腾讯混元联合复旦大学发布 WorkForge 框架，核心思路是**从真实世界资源反向生成训练环境**，而不是让 AI 凭空造模拟数据。

| 指标 | 数据 |
|---|---|
| 环境规模 | 16,665 套工作区（WorkForge-16K） |
| 覆盖广度 | 40 个专业领域、60 种文件类型 |
| 单环境复杂度 | 平均 42.3 个文件 |
| 轨迹长度 | 单条轨迹平均约 7.6 万 tokens |
| 验证机制 | 双重校验：程序核对具体数字与交付文件 + LLM 语义评分 |
| 训练效果 | 35B-A3B：GDPval 45.5 → 73.6，APEX 5.0 → 21.3<br/>27B：GDPval 82.4 |
| 对标 | 27B 的 82.4 > Qwen3.5-397B 的 79.7（参数量约 15 倍），但 < GPT-5.6 Sol 的 90.1 |

一条容易被忽略的细节：示范轨迹是用 **GLM 5.3 + Claude Code + OpenClaw** 生成的，再拿这些轨迹去微调 Qwen3.5。也就是首轮是「借外部模型当教师」。

**值得关注的原因**

1. **Agent 后训练的瓶颈已经明确转移到「环境 + 验证器 + 轨迹供给」。** 模型不再是短板，能不能批量造出带可核对事实、能被程序判分的任务环境才是。WorkForge 的做法——先从原始文件抽可验证事实，再据此反推任务和评分标准——比「先出题再人工标注」便宜一个数量级。
2. **27B 打赢 397B 这件事本身值得警惕地解读。** 它证明的是后训练与环境质量的杠杆，而不是小模型通用能力追平大模型。GDPval 这类偏「交付物产出」的基准对训练分布敏感，跨榜外推要谨慎。
3. **对腾讯内部路线是一个注脚**：算力受限下「不硬拼最大基座，用环境和后训练把小模型推近大模型」，和混元近期 L0–L4 自我进化的梳理、徐灿转岗微信 WeLM 是同一套逻辑。
4. **一个待验证的问题**：教师模型是外部闭源栈（Claude Code/OpenClaw），学生是自家 Qwen 系。这个「数据工厂」的上限，取决于教师模型能力上限，中间存在蒸馏天花板。

## 三、国际具身智能技能大赛（IEIC）今日在沪开幕：评价体系从「表演」换成「上岗考核」

**事件内容**

10/23–25，2026 全球开发者先锋大会（GDPS）暨国际具身智能技能大赛在上海张江科学会堂举办，主题「具身进实景，劳动最光荣」，口号「选最能干的机器劳模」。

| 维度 | 具体情况 |
|---|---|
| 定位 | 工信部 + 国资委《2026 年度人形机器人与具身智能实景实训专项行动》的**首次全国性落地赛事** |
| 规模 | 9 大实景赛道、23 个赛项；1200+ 场景单位与本体单位申报；计划千余支队伍、300+ 本体企业 |
| 赛制 | 「产业出题、科技答题」+ 揭榜挂帅；模拟赛 → 仿真赛 → 实景赛全年三级体系 |
| 评分 | 四模块百分制：任务执行 / **具身数据采集与回流** / 自主智能 / 创新能力 |
| 场景供给方 | 延锋汽车、百联集团、申通快递等真实产线与服务需求直接搬进赛场 |
| 专家委 | 主席为图灵奖得主、中科院院士姚期智 |
| 参赛方 | 整机企业、AI 算法与大模型企业、高校团队、海外创业团队，每队 ≤5 人 |

同期亮点：智元、宇树、傅利叶、联想等整机厂 + 核心部件厂集中亮相；超万台机器人入驻张江人工智能创新小镇；100+ 家开源社区设专场。

**值得关注的原因**

1. **「具身数据采集与回流」被单独计分，是这届最关键的信号。** 过去比赛只看任务成不成功，现在把「你跑这一趟产出了多少可复用数据」算进分数——等于承认比赛本身就是数据工厂。这和智元昨天开源具身推理数据集、无界动力做世界模型基座是同一个产业判断：数据闭环比单点 demo 值钱。
2. **评价维度从成功率扩到「效率、安全性、经济可行性」**，这是从实验室指标切换到采购指标。ROI 进评分表，意味着 2026 下半年服务业与工业的前期试点要进批量部署阶段了。
3. **对本体厂是一次公开的压力测试**：23 个赛项里有焊接、上下料、巡检、康养、救援，全是连续作业场景，暴露的会是可靠性而不是灵巧度。会后各家的失败集（智元这次数据集特意包含错误样本）会是一手资料。

## 四、小鹏 IRON 上第二代 VLA：0.2 秒重推理，预判人类未来 6 秒动作

**事件内容**

小鹏发布 IRON 人形机器人交互演示升级，第二代 VLA 大模型已在端侧运行。

| 能力 | 具体表现 |
|---|---|
| 重推理频率 | 每 0.2 秒重新推理一次 |
| 预测窗口 | 预判面前人类未来 **6 秒**内的动作变化 |
| 交互表现 | 握手、碰拳、击掌可完成；对方突然握拳、或击掌位置临时挪动，IRON 能立刻调整姿态换手配合 |
| 算力 | 三颗自研图灵 AI 芯片，总算力 2250 TOPS |
| 技术来源 | 与小鹏汽车自动驾驶同源的物理 AI 基座 |

背景：何小鹏此前坦言做机器人难度约为造车的 20 倍，硬件、软件、设计、供应链都要自研，过去不愿展示是因为不能量产、不少演示靠剪辑。

**值得关注的原因**

1. **交互范式从「跟随」变成「预判」，这是人机物理共处的前置条件。** 过去人形机器人最大的体验断点是「必须按固定节奏配合，你一变招它就僵住」。0.2 秒重推理 + 6 秒预测，把这个问题从「响应速度」重构成「意图建模」。
2. **2250 TOPS 全部堆在端侧，说明高频重推理不能走云。** 这是具身智能区别于纯软件 Agent 的硬约束——延迟预算决定了架构，也解释了为什么各家都在自研推理芯片。
3. **车企路径的可复用性**：自动驾驶的感知-预测-规划栈直接迁移到人形，是「物理 AI 基座」这个说法第一次有了产品级证据。特斯拉 Optimus、小鹏 IRON 走的是同一条路，而纯机器人公司（宇树、智元）需要从零建这套栈。这条路线分化值得持续跟踪。

## 五、本体量产临界点：Optimus 转入「量产质量」阶段，NVIDIA Isaac 补上开发栈

**事件内容**

三件事在同一周发生，指向同一个结论。

**（1）特斯拉 Optimus（10/21 盘后 Q3 财报电话会）**

| 项 | 情况 |
|---|---|
| 产线状态 | 弗里蒙特工厂高产量产线已开始生产，下线首批**具备量产质量**的机器人 |
| 产能规划 | 加州人形专用线规划年产 100 万台；得州超级工厂筹备第二条线，长期设计年产能 1000 万台 |
| 芯片 | 明年 4 月左右换装 AI5 |
| 节奏 | 达到周产 2 万台至少还需一年甚至更久；2027 年底前后可能对外交付 |
| 马斯克表态 | 坚信人形机器人赛道将成为全球最大产业；明年年末机器人 AI、机电设计、可靠性、寿命等问题有望解决 |

**（2）NVIDIA 扩展 Isaac 平台（10/21 柏林 GTC）**

新增人形机器人参考平台、数据集、运行时框架与机器人学习工具，目标是打通「数据生成 → 模型训练 → 仿真验证 → 实际部署」全流程。同时联合思灵机器人推出人形参考机体 **Agile ONE SN**。

**（3）行业侧数据**

工信部披露：2026 上半年我国人形机器人整机产品突破 400 款，产量超 4 万台，预计全年突破 10 万台。PitchBook：2026 上半年全球机器人与物理 AI 领域风投 334 亿美元，已超 2025 全年 287 亿美元。

**值得关注的原因**

1. **「量产质量」四个字是本期最重要的信息，不是产能数字。** 它把产业问题从「能不能做出来」切换到「零部件一致性与成本能不能稳住」。样机阶段可以手工挑件，量产阶段必须依赖减速器、丝杠、轴承、电机的批量一致性——这正是国产供应链的切入点，也是今天 A 股电机、减速器板块异动的真实原因。
2. **NVIDIA 补的是「开发栈收敛」。** 参考机体 + 数据集 + 运行时 + 学习工具四件套齐了，意味着中小团队不必自建仿真与训练管线。产业瓶颈从本体硬件转向数据与训练，价值分配会重新切分：谁掌握高质量真实场景数据、谁能把「部署即采集」的闭环跑通，谁拿走下一代模型的数据资产。
3. **开发栈收敛的风险面**：Isaac 生态越完整，越容易形成「NVIDIA 仿真 + 国产本体」的默认组合，国产仿真平台（如智元 GenieSim）的独立生态空间会被压缩。
