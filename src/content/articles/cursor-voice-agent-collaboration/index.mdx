Cursor 推出"与智能体实时语音协作"：开发者可与编码智能体**双向语音对话**——口头描述改动、询问进展、查看 diff 与运行状态，智能体在后台继续干活；执行中主动播报简短进度，完成后给结果说明。

## 覆盖范围与细节

- 功能覆盖 Agents Window、IDE、网页端与 iOS；iPhone 支持 "Hey Siri, call Cursor"，锁屏/灵动岛可静音挂断。
- 通话内查询为只读，不会打断正在运行的编码任务。
- 语音层由 **Grok Voice** 驱动（识别 + 合成），编码本身仍走用户自选模型。
- Privacy Mode 下零数据留存；有每日使用上限，静默约 10 分钟自动挂断。

## 为什么值得关注

与常见的"听写转文字"不同，这是语音对语音的双向通道——AI 编程的交互入口从键盘扩展到"打电话"。它瞄准的正是异步监督长任务的场景：此前开发者抱怨"睡一觉醒来发现 agent 卡在第一轮"，而现在可以在通勤路上直接"问一嘴"进度、口头调整方向。
