Anthropic 本周在 coding 治理上"一松一紧"。

## 松：防复刻禁令放宽

10 月底上线的 Claude Code 防游戏复刻指令因误伤正常开发（含软件分析、逆向工程），约一周后修改：直接复刻仍会拒绝，但**允许做同类型的新游戏**（可借鉴特定战斗系统等点子）；升级到 v2.1.317+ 生效。Addy Osmani 承认短规则误伤了"提现有游戏名只是解释需求"的用户。

## 紧：Security Center 上线

Anthropic 推出 **Security Center**——实时仪表盘，覆盖 Chat、Cowork、Claude Code 三个产品面，持续将企业配置与 Anthropic 安全基线比对，可生成"auditor-ready"的审计导出。

## 为什么值得关注

一周内一松一紧，说明"系统指令当治理工具"这条路线正在真实使用压力下快速迭代；而合规仪表盘，可能成为未来企业合同的事实门槛。
