> 本期主线：**开源权重同时跨过"够用"和"前沿"两条线。** Revolut 把 2000 名工程师的默认工具从 Claude Code/Codex 换成自托管 GLM，账单只剩十分之一——这是"够用且便宜"第一次在受监管银行的生产环境里算得过账；Kimi K3.1 Pro 把 2.8 万亿权重放到今天到期，开源与闭源在 AA 指数上的差距从 12 分缩到 3 分。具身侧则是同一件事的两面：小米让机器人**干满一个班**，宇树公开承认**本体跑通、大脑没赢**，开始全球找大脑。

## 一、Revolut 把 2000 名工程师从 Claude Code / Codex 换到自托管 GLM：账单降到十分之一，代价是"把推理栈重写一遍"

**事件内容**

Revolut AI 基础设施负责人 **David Abitbol** 在纽约 AI Engineer 大会的演讲《Shipping like a startup, regulated like a bank》中披露了迁移细节，11/3 经 Dealroom 等媒体报道后扩散：

| 维度 | 信息 |
|---|---|
| 迁移规模 | 约 **2000 名**软件工程师，**默认编码工具**从 Anthropic Claude Code、OpenAI Codex 换成智谱 Z.ai 的**开源权重模型 GLM**，由 Revolut **自建部署** |
| 算力 | 约 **56 张 NVIDIA B200**，跑在自己的美国机房 |
| 成本 | 混合成本约 **$0.30 / 百万 token**，总账单约为此前的 **1/10** |
| 效率（厂商自述） | 约 2000 人样本中，编码时间缩短约 **60%**，从接任务到合入的 lead time 缩短约 **70%** |
| 此前路径 | 先上 Gemini，再用带"人均预算上限"的 Claude Code；Abitbol 称早期 Claude Code 投入产出比一般，且额度限制让工程师把 AI 留给"最难的任务" |
| 保留边界 | 图片任务仍走 **Gemini**；最难的工作仍保留 **Claude Code / Codex** 作例外；编码 Agent 跑在带审批规则的沙箱里，**人在环** |
| 合规顾虑 | 承认在受监管银行用中国开源模型有"污名"，因此**只取开放权重、只在自有基础设施上运行**，不走 Z.ai 托管服务 |
| 未计入 | 官方口径的 90% 节省**不含云、人力与监控成本**；且对照未剥离"取消 token 限额"这一变量 |
| 代价 | 开箱推理"**很糟**"；团队在同一批 GPU 上把首 token 延迟从约 **14 秒压到 1.7 秒**，才达到可用 |

**值得关注的原因**

1. **这是"订阅制 vs 自建"第一次在千人规模、受监管行业里给出可核对的账单对照。** 成本结构从 per-seat 订阅变成"GPU 折旧 + 电力 + 推理栈人力"，而后者在 2000 人规模下才摊得动。对绝大多数团队来说，真正的门槛不是模型，是**有没有人把 TTFT 从 14 秒调到 1.7 秒**——这条细节比"省 90%"更有参考价值：开源不是免费的，是把钱从账单挪到了工程。
2. **采购会走向双轨，而不是替代。** Revolut 的做法很克制：日常高体量任务交给"够用且便宜"的自建模型，难题、图片、需要最强推理的少数场景留给 frontier——这也是 Dealroom 提到的信号：对常规、高频工作，"good enough and cheap"开始赢。真正被威胁的不是模型能力榜，而是按席位订阅的定价模型。
3. **对国内团队的镜像意义：这条路的可行性取决于"数据能不能出域"。** Abitbol 明确是因为合规才选择"只取权重、自己跑"。这与今天 Kimi 放权重是同一枚硬币的两面：**开放权重的第一批刚需客户，是银行、医疗这类数据不能出境的场景**，其次才是推理服务商转售。反过来说，如果团队没有自有算力和驻场推理工程师，自建的账大概率算不过来。

## 二、Kimi K3.1 Pro 完整权重今日到期：开源与闭源差 3 分，但先主动砍掉 9.5 分网安能力

**事件内容**

月之暗面 10/23 发布 K3.1 Pro 时承诺**11 月 4 日前**放出完整权重，今天是窗口最后一天：

| 维度 | 信息 |
|---|---|
| 规格 | 总参数 **2.8 万亿**（MoE），每 token 激活约 **1040 亿**；**1M token** 上下文；原生支持文本 + 图像输入 |
| 榜单 | Artificial Analysis 智能指数 **55 分，全球第四**（前三是 Opus 5.5 的 58、Sonnet 5.5 与 Muse Wonder Full 的 56）；前代 K3 为 44 分，一代 +11 |
| 关键变化 | 开源与闭源前沿的差距从 **12 分缩到 3 分**；权重放出后将成为该指数上**排名最高的开放权重模型** |
| Agent / 编程 | Terminal-Bench 4.0 **65.7%**（K3 仅 13%，GPT-6 Astra 58.2%）；GDPval-AA **1846 Elo**（+312，仅次于 Opus 5.5 的 1866）；BenchCAD 工具调用 92.7%（Opus 5.5 为 96.2%） |
| 其他 | 内部 Hallu Bench Hard 幻觉率 **23.4% → 8.3%**（Astra 为 5.5%）；OfficeQA Pro v2 超过所有对比模型；财务建模/研究内部基准分别 +7.2 / +11.6 分 |
| 定价 | API 约 **$2 / $10** 每百万 token（输入/输出）；Highspeed 版约 3 倍速、单价更高（国内平台 ¥26 / ¥136） |
| 安全取舍 | 中期训练与 RL 阶段**针对性移除网络攻防数据**、保留通用编程；内部基准 **xdev-bench-hard** 上 exploit 通过率 **90.5% → 81.0%**，主动让出 9.5 分 |
| 待确认 | 发稿时权重下载页、许可证名称与第三方托管报价尚未公开可查；"主动净化"的基准为内部基准，第三方无法独立验证，也无法验证微调能否恢复被抑制的能力 |

**值得关注的原因**

1. **"开源落后闭源 12 分"这句话今年第二次被改写。** 从 12 分到 3 分，且强项正好落在 **agentic coding**（Terminal-Bench 从 13% 跳到 65.7%）——这意味着"本地可部署的前沿级编码模型"第一次在纸面上成立。对需要长上下文代码库、又不能把代码送上云的企业，这是今年最实际的一个选项。
2. **"开源前先自砍能力"正在变成发布范式，但它带来了新的采购风险。** 主动移除攻防数据是负责任的做法，问题在于**验证权在厂商手里**：81.0% 用的是未公开的内部基准，第三方既无法确认"降到 81%"是真的，也无法确认微调后会不会回到 90.5%。安全团队不能把"已净化"当成结论，必须自己跑 exploit 测试——权重开放恰好让这件事第一次变得可做。
3. **权重开放改变的是议价结构，不是使用方式。** 2.8 万亿参数的部署门槛（显存、专家并行、卡间带宽、KV cache）决定了绝大多数团队仍会走托管；真正受益的是三类角色：数据不能出域的大机构（见上一条 Revolut）、做二次微调的垂直厂商、以及靠"开放权重"打价格战的推理服务商。权重落地后第一波可观测信号是**第三方托管报价**，而不是又一轮跑分。

## 三、MIT 让 GPT-6 Astra 直接改 Qwen 权重：不用梯度、只动 0.016%，MATH-500 从 7.9% 到 48.1%

**事件内容**

MIT 团队公布八项实验，把"让前沿模型直接读写神经网络权重"命名为 **Weight-Space Programming（权重空间编程）**，11/3 经量子位等报道后引爆讨论：

| 实验 | 做法 | 结果 |
|---|---|---|
| **Qwen3.5-0.8B 提数学** | 把完整权重以文本形式放进 Python 环境，指令只有一句"尽可能提高数学能力"；Astra 自行诊断、决定改哪里 | 发现"推理循环"是主因（96 条回答中 85 条跑满 32768 token），定位到**第 15、19 层前馈网络各 64 个输出列**，只改动约 **0.016%** 权重；触顶率 **93.0% → 33.1%**；MATH-500 **7.9% → 48.1%**（给 10/25/50 次前向调用预算时分别为 12.3% / 14.1% / 48.1%）；未被要求优化的 IFEval 也从 21.0% 升到 **62.3%** |
| **认游戏** | 四个架构/输入/动作完全相同的 Atari 网络，只给原始权重 | 正确认出打砖块、乒乓、吃豆人、高速公路；打砖块是靠**权重集中的位置**推断的 |
| **认语言 / 找归纳头** | 三个 720 万参数小模型分别用 Python、日语罗马字、英语训练，剥掉输入输出层、且**不许喂数据** | 两轮内认对三种语言，并找出全部**归纳头**（induction heads） |
| **小车爬坡** | 给权重、场景描述和一段失败记录，不用工具 | 一次回复写出补丁，只改 **3.5%** 权重，1024 次测试**全部成功**——把训练学不会的"先倒车再冲坡"直接写进权重 |
| **全零权重写策略** | MinAtar：只给规则、源码和网络结构，无数据、无梯度、不能试跑 | 平均得分 **517.4**；PPO 训 1 亿步为 15.8、5 亿步为 25.3，约 **20 倍** |

**值得关注的原因**

1. **"改模型"第一次可以不进训练循环。** 过去修一个小模型的行为，路径是"加数据 → 重训 → 评测"；现在是"诊断 → 定位到具体层与列 → 打补丁 → 验证"。省掉的是梯度训练，**没省掉诊断和验证所需的算力**，但对小模型、边缘模型、私有化部署的客户，这可能把一次迭代从周级压到小时级。
2. **对 AI coding 的含义是：调试对象从源码扩展到"参数"。** Agent 已经能读二进制、读堆栈、读日志，现在还能读权重这种"不可读的代码"，并给出可验证的改动。这条路一旦工程化，IDE 与 agent 的能力边界会推到模型本身——"这个模型在我这跑不好，你帮我改一下权重"会成为一句正常的请求。这也是宇树愿意向全球大模型公司开放接口的底层预期（见第五条）。
3. **必须保持怀疑，但它给出的最小实验是可复现的。** 单模型、单任务、内部评测，且 Meta 研究员质疑提示词已提前把排查方向引导到了"循环"。真正硬的证据是那些**不需要解释力的实验**：从权重认出四款游戏、找出归纳头、全零权重写出 20 倍于 PPO 的策略——这些不是"调参调出来的"。建议按"认游戏/找归纳头"这个最小实验自己复现一次，再决定要不要信 6 倍这个数字。

## 四、小米人形机器人跑满 8 小时整班：从"连续 3 小时"到"产线级协同"，同时把基座模型搬进公寓

**事件内容**

11/3 乌镇世界互联网大会期间，小米披露机器人业务在工厂与家庭两侧的进展，并拿下大会"杰出贡献奖"（全球 15 家）与"领先科技奖"：

| 场景 | 信息 |
|---|---|
| **工厂（本次）** | 在小米汽车工厂**中控台侧盖板排序工站**首次挑战 **8 小时作业**，满足该工站**全天生产**需求；作业中实现**异常自主纠偏**与**产线系统级协同**（与 AMR 配合分拣、摆放零件）；官方称"初步完成**产线级**作业能力验证" |
| 工厂（历史路径） | 2026/3 首次进厂"实习"：自攻螺母上件工站连续 **3 小时**、双侧安装成功率 **90.2%**、满足 **76 秒**产线节拍；2026/7 同工站成功率升至 **98%**，新增中控台侧盖板排序、料箱折叠回收两个复杂工站，首次实现**柔性工件长时作业** |
| **家庭（本次）** | 以 **Xiaomi-Robotics-1** 为底座的具身基座模型在**小米青年公寓**启动"试运营"，搭建覆盖数据采集、推理、执行的 Agent 闭环；完成连续 **>30 分钟**、覆盖 **3 个房间**、**50+ 任务**的长程任务验证（工具准备、沙发/桌面整理、垃圾清理、分类归位、房间巡检、全屋复检、离场） |
| 模型口径 | 前两代迭代后，Xiaomi-Robotics-1 基于 **10 万小时真实世界操作数据**预训练；官方称**国内率先系统性验证具身 Scaling Law**，在 **RoboCasa365、RoboDojo** 榜单位列全球第一（厂商自述） |
| 奖项技术名 | "面向规模化落地的通用机器人操作基座模型关键技术" |

**值得关注的原因**

1. **"8 小时"是班次单位，不是演示时长——这是量产与 Demo 的分界线。** 它同时压测续航与散热、重复定位精度、异常恢复，以及与 AMR、产线系统的对接；对比 3 月的"连续 3 小时"，真正的增量不是时长翻了 2.7 倍，而是**从"单站作业"走到"产线级协同"**。排产看的是能不能顶一个班，不是能不能翻个跟头。
2. **数据闭环是小米最不一样的变量。** 自家汽车工厂既是客户也是数据源：真实工况、真实失败样本、真实节拍约束，与"向第三方买数据"（简智那条线）形成两种成本结构。10 万小时预训练 + 产线回灌，如果能证明"多一个工站只需少量后训练"，这套方法论就可以复制到别的制造企业——那才是它真正的商业故事。
3. **家庭侧才是泛化考卷，而这份考卷的评分标准还没公开。** 30 分钟 / 3 房间 / 50+ 任务是**长程任务链**，失败模式是复合的（任一环节崩掉整链归零），难度结构与固定工站完全不同。但所有数字均为厂商自述，**接管次数、成功率、单任务耗时、成本都未披露**——这三点不公开，"试运营"就还停在验证阶段。

## 五、宇树公开承认"本体跑通、大脑没赢"：开放硬件与运控接口，向全球找大脑

**事件内容**

11/3 上午，宇树科技创始人**王兴兴**在乌镇峰会开幕前受访表示：宇树已经把**本体、运动控制、执行器**等硬件能力基本跑通，下一阶段核心攻坚方向是**机器人大脑（具身大模型）**，并将在**全球范围**寻求合作：

| 维度 | 信息 |
|---|---|
| 开放内容 | 愿意开放**机器人硬件平台**与**运动控制接口**，面向全球大模型公司、AI 实验室、高校联合训练、迭代机器人大模型；已购买其硬件平台的开发者可直接提诉求联合开发 |
| 10 月既定三线 | ① 提升大规模量产能力，适配千万级乃至亿级需求；② 自研与合作并行，推进**适配自身硬件的物理 AI 小模型**；③ 布局**超大规模算力集群** |
| 财务背景 | 前三季营收 **18.17 亿元（+55.71%）**、归母净利 **3.87 亿元（+270.54%）**；但 **Q3 净利同比下滑约 17%**，董秘口径归因于**算力与大模型方向研发投入增加** |
| 对照（同日行业） | Meta 与傅利叶的二代 **Max 2** 已启动（重新设计躯干、改进机械手、加投影仪显示、增传感器以上下楼梯）；Meta 正在**上海招供应商开发工程师、深圳招产品设计/技术项目经理**，组建 Meta Robotics Studio 的量产团队——美国本土难获零部件，来华造本体 |
| 对照（路线） | 特斯拉 Optimus 全栈自研、Figure 押注自研 Helix；宇树选的是相反的生态位：把身体做成平台，用生态换大脑 |

**值得关注的原因**

1. **这是"硬件赢家"第一次公开承认下半场不在硬件。** 本体市占率领先的公司主动给自家"大脑"招外部伙伴，等于承认具身的上半场（本体、量产、成本）已经分出胜负，下半场（认知、泛化、任务理解）谁也没赢。对照 11-03 期乐聚把"端网协同与质量保障"签进合同、10-31 期智澄押 JEPA 世界模型，国内具身阵营的叙事正在集体从"运动控制"切到"世界理解"。
2. **中美形成镜像分工：Meta 来中国找身体，宇树去全球找大脑。** 各自用长板换短板——Meta 缺的是零部件与供应链（所以把产品副总裁派到上海工厂待了两个月），宇树缺的是前沿模型与算力。这个交换一旦成立，本体厂商的议价权会被进一步压缩成"代工 + 数据入口"，与 11-03 期"本体不是壁垒，数据与大脑才是"的判断同向。
3. **代价已经出现在财报上，且没有时间表。** Q3 净利下滑 17% 被明确归因于算力与大模型投入，而"全球找合作"既无投入规模、也无合作方名单，自研与开放的边界（哪些自己做、哪些交给伙伴）也未说明。这条路能不能把宇树的估值从"硬件公司"切换到"智能公司"，取决于两件事：合作方能否带来真实的泛化提升，以及 Q4 研发费率会不会继续吃掉利润。
