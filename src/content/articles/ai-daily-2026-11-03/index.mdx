> 关注方向：AI Coding / Agent 工程化 × 具身智能
> 覆盖窗口：11/2 – 11/3 上午。本期 5 条主条目 + 附注速览，已对齐 10-21 至 11-02 十三期推送做去重（DeepSeek Super-Agent、智元便利店直播、Codex 额度共享、MAI-Code-1.1-Flash、具身"交卷期"、数据定价均已报过，本期只收增量）。
> 本期主线：**Coding 侧同一天出现了"能力上限"与"可靠性下限"的对照实验。** 美团用 1.6 万亿参数在国产算力上把长程 agent 刷到 Opus 5 之上，Kimi 用 20 小时无人干预交付了一份可继续开发的 Unity 工程——两条都在证明"agent 能干长活"；而同日的 SlopCodeBench 用 196 个检查点给出反面数字：**没有一个 agent 完整做完全部任务，最佳严格通过率只有 14.8%**。具身侧则是"标准之争"开场：乐聚把端网协同与质量保障签进了合同。

## 一、美团 LongCat-2.5：1.6 万亿参数、全程国产算力，长程 Agent 榜单局部超过 Opus 5

**事件内容**

11/2 美团发布新一代大模型 **LongCat-2.5**，11/3 大批媒体跟进评测细节：

| 维度 | 信息 |
|---|---|
| 规格 | 总参数 **1.6 万亿**，每 token 激活约 **480 亿**；面向长程智能体任务的**原生多模态**模型 |
| 多模态方式 | 视觉信号编码为**多层级离散 token**，与文本在同一 token 空间统一处理；支持交互网页、3D 展示页面 |
| 训练 | 中训练阶段序列最长 **1M token**，累计数万亿 token；大规模**长程强化学习**，并把真实 agent 失败轨迹转成可验证任务 |
| 算力 | **全程国产算力**（LongCat-2.0 于 6 月首次在国产算力完成万亿参数全流程训练与推理） |
| 工程优化 | 长序列 SFT 单卡吞吐较 DDP 基线 **+86%**；W4A4 推理相对 W8A8，prefill **+43.3%**、decode **+42.77%**；围绕超节点重排任务分工，把参数/数据主通信压在超节点内 |
| 跑分 | AutomationBench **51.8**（Opus 5 为 50.3）、BrowseComp **91.9**（第一）、3DCodeBench **55.4**（小幅领先）、LongCatClawBench 第一；整体介于 Opus 4.8 与 Opus 5 之间，**纯代码与终端指令类任务仍有小幅差距** |
| 落地 | 同步上线 API；注册赠千万 token；配套 AI 经营工作台**"妙手"**（古茗、徐升记、益禾堂等已接入） |

**值得关注的原因**

1. **"国产算力能训万亿"和"能训万亿的长程 RL"是两个难度量级。** 前者是显存与并行策略问题，后者要在长轨迹上反复 rollout，对卡间通信和数值一致性的要求高一个档。美团这次披露的两个数字（单卡吞吐 +86%、W4A4 双端 +43%）恰好都指向"把通信和显存省下来喂给长序列"——这条工程路径一旦跑通，国内 agent 产品的单位推理成本会再下一个台阶，而不是靠降价换量。
2. **榜单位置说明"agent 能力"和"代码能力"正在解耦。** LongCat-2.5 赢在 AutomationBench（浏览器/流程自动化）、BrowseComp（检索）、3DCodeBench（文本生 3D），输在纯代码与终端。这和 10-29 期 Gemini 4 Carbon 赢在安全代码、10-30 期 Fusion 赢在成本效率是同一种结构性现象：**长程 RL + scaffold 能补 agent 行为，补不了代码肌肉记忆**。选型时按任务类型分模型，比看总分更实际。
3. **王兴"不会成为 Token 工厂"这句话是战略表态。** 妙手服务的是本地生活商家的经营分析（自主构建渠道利润表，识别"支付 GMV +23.2% 而渠道利润 -1.7%"这类增长质量问题），本质是把模型能力塞进自有场景做闭环。国内大模型厂从 API 价格战转向"自有场景 + agent 交付"，这条路的毛利结构比卖 token 好得多。

## 二、Kimi 发布游戏开发方案：20 小时无人干预，交付一份"人类团队能接手"的 Unity 原生工程

**事件内容**

11/2 月之暗面发布**"游戏开发与创意工作解决方案"**，基于 Kimi K3.1 Pro + Kimi Code + Kimi Work，通过插件直接操作专业工具：

| 维度 | 信息 |
|---|---|
| 工具覆盖 | 引擎：Unity、Unreal Engine、Godot；建模：Blender、Maya、Rhino、3ds Max（仅 Win）、AutoCAD；3D 生成：Tripo。Unity/Godot 走 Kimi Code，Maya/Rhino/3ds Max/CAD 走 Kimi Work，Godot/Maya 可经 MCP 接入 |
| 原型能力 | 无编程经验的策划 **1–2 天**做出可试玩 Godot 原型（演示为 2.5D 雨夜动作：挥剑、闪避、格挡、地面积水、灯笼光影） |
| 自主验证 | 交付前**自己运行游戏、看渲染画面与试玩录像**，对照要求找问题、改代码、再跑；Blender 里看多视角预览，Unity 里看录屏与日志 |
| 关键演示 | 与 Unity 中国 **Tuanjie Codely Agent** 协同（Kimi 看录屏定方案、Codely 在团结引擎改工程跑验证），**无人干预连续工作 20 小时**，把一个网页 Demo 复刻成 Unity 原生工程 |
| 交付物 | **可继续编辑的工程文件 + 代码 diff + 操作记录 + 验证记录**，而非截图或成品视频 |
| 大场景 | UE 5.8 天宫：半径 1750 米、36 间柱廊、3600 万原始三角面，Nanite 渲染 + Lumen 打光；另出古风 RPG 预告片 |
| 已用客户 | 网易游戏、三七互娱、点点互动、FunPlus、凉屋游戏（凉屋 CEO：已是日常开发第一选择） |
| 未公开 | token 消耗与相对人工的成本比 |

**值得关注的原因**

1. **交付物从"内容"变成"可接手的资产"，这是 AI coding 进厂的门槛线。** 生成一张图、一段代码都不难，难的是让人类团队拿到后改得动、查得到改了什么。Kimi 反复强调 diff + 操作记录 + 验证记录三件套，等于把"可维护性"当成产品指标来做——这一点比 20 小时这个数字更值得记。
2. **"AI 自己 QA 自己"是长任务可靠性的另一条解法。** 11/1 期 DeepSeek Super-Agent 的答案是"监听群聊、少占注意力"，Kimi 的答案是"跑起来看录屏、自己对照要求改"。两条路线都在解决同一个问题：agent 干几小时后如何不自欺。**能自我获取运行证据的 agent，才谈得上"负责人"而不是"执行器"。**
3. **对开发者的现实信号是工具分层已经明确。** 引擎级操作走插件/脚本（可确定性回放），桌面建模软件走 MCP，3D 资产走生成模型。这条"专业工具插件化 + agent 自主验证"的路会被复制到 CAD、影视、建筑——垂直工作流可能是国产模型厂除价格战外唯一的差异化出口。风险同样明确：成本未公开、审美判断仍靠人、各家工程规范差异大（权限/版本控制/责任边界）。

## 三、反面数据：SlopCodeBench 显示"关灯软件工厂"还不成立，最佳严格通过率 14.8%

**事件内容**

HumanLayer 创始人 **Dex Horthy** 公开质疑"关灯软件工厂"（无人值守、全自动交付）叙事，并给出自建评测：

| 维度 | 信息 |
|---|---|
| 核心论点 | 测试只验证**当下这次改动**；糟糕架构的代价按月、按年才显现，无人看管的模型很难在多轮修改中维持代码库质量 |
| 评测设计 | **SlopCodeBench**：36 道任务、**196 个分阶段检查点**，考核"每一步都没有把上一步搞坏" |
| 结果 | **受测 agent 无一完整做完**；最佳严格通过率 **14.8%**，10 月更新后升至 **16.3%** |
| 给出的工程建议 | 大改动先花 **20–30 分钟**与 agent 一起做计划；让 agent 用浏览器自测；保留计划与会话记录；候选修复 PR **仍须由人决定是否合并** |

**值得关注的原因**

1. **这是本周唯一一条负面数据，但价值最高。** 同一天我们看到了 20 小时无人干预、1.6 万亿参数长程 RL、Super-Agent——全部在证明"agent 能干长活"。SlopCodeBench 换了个问法："干完之后代码库还健康吗？" 14.8% 说明**"能写出跑得通的代码"与"能长期维护一个代码库"是两个能力**，而目前所有公开 demo 都只在测前者。
2. **分阶段检查点的评测方法比 pass@1 更接近真实工程。** 它测的是累积损伤，而不是单点正确率。建议团队做 agent 选型时，用这类型 benchmark 补 SWE-Bench 的盲区（对照 10-30 期信通院"99%^100 步≈37%"的连乘衰减，是同一个数学事实的两种表述）。
3. **三条建议今天就能落地，且不依赖任何新工具。** 20–30 分钟先规划、让 agent 自己用浏览器验、保留会话记录——成本几乎为零，但正好对应 agent 最常翻车的三个环节：目标漂移、自测缺失、事后无法复盘。

## 四、乐聚 OPENLET 开发者大会今日开幕：把"端网协同 + 质量保障"签进合同，并给出 80% 的进厂门槛

**事件内容**

11/3 乐聚机器人与开放原子开源基金会、中关村通力在北京石景山共同主办 **OpenLET 具身智能开发者大会**：

| 维度 | 信息 |
|---|---|
| 五项发布/签约 | ①央企应用场景发布（中国自控系统工程）；②**OpenLET 北京高校开发者共同体**（清华、北大、北航、北理工、北邮、北交大、北工大、哈工大北京研究院等）；③**具身智能端网协同部署与质量保障签约**（中国移动研究院、中关村泛联、联发科、乐聚、开放原子）；④首钢园人形机器人穿越赛；⑤物理 AI 孵化器及具身智能 OPC |
| 规模 | 40+ 家企业（覆盖 12 省 16 城）、8 场演讲/主旨报告、10+ 场开发者开放麦、真机黑客松（石景山人形机器人训练中心二期）、投资机构专场（中信金石、首钢基金、玖兆投资、星空投资等） |
| 配套议程 | 11/4 清华站、北邮站 Workshop；工业场景与二开成果展区 |
| 同日资本动作 | 乐聚 × 兆丰股份合资公司**浙江兆聚智能**成立，注册资本 1000 万元，经营范围含工业机器人制造、AI 应用软件开发 |
| 董事长冷晓琨的关键数字 | **"只有达到 80%，工厂才会接受机器人进产线"**；预训练（仿真为主）泛化强但成功率仅 **40–50%** → 后训练（训练场数据做垂域模型）约 **80%** → 工厂实景实训 + 真机数据回流，实际生产效率约 **95%** |
| CEO 常琳 | 开源数据驱动具身生态建设（数据侧的开放主张） |

**值得关注的原因**

1. **"端网协同 + 质量保障"是今天最实的一条。** 具身进厂的真实瓶颈常常不是本体，而是网络时延/抖动与验收标准无人背书。中国移动研究院 + 联发科 + 乐聚 + 开放原子的组合，意味着把确定性网络指标与机器人 SLA 绑在一起做联合定义——这是 10-31 期"信通院三把尺"之后，第一次看到**"谁来定验收尺"**落到具体签约方。若这套标准成型，会成为中小本体厂商的准入门槛。
2. **80% 这个数字和那条 40-50% → 80% → 95% 的曲线，等于公开了能力坐标。** 乐聚目前卡在"后训练 80%"到"实景 95%"之间；对照 10-30 期美的美罗U 在窄任务上 99.8%，说明**广谱任务的 80% 仍是未解难题**。这条曲线也给上游提了明确需求：训练场数据的质量与回流速度，直接决定从 80% 爬到 95% 要多久。
3. **生态位打法成型：高校联盟 + 央企场景 + 孵化器 + 开源数据。** 这与智元"创新日"是同一套结构，但乐聚更偏工业与开发者侧，且明确把 40+ 家工业技能公司拉进"二开"生态。对做具身应用的开发者，这是近期少见的、能直接对接央企场景与产业基金的入口。

## 五、具身资本"换层"：整机在退潮，数据与大脑在同日拿到大额——简智 1 亿美元 A+、机器科学 A2、考拉悠然 B++

**事件内容**

11/2–11/3 三天内，具身赛道非本体层密集融资：

| 公司 | 轮次/金额 | 关键信息 |
|---|---|---|
| **简智机器人（GenRobot）** | 1 亿美元 **A+**（11/2 披露，Q3 完成） | 产业方：上汽、百度、马来西亚 Eastworlds、首程控股、GALBOT；财务方：光合创投、SUNHELM、中信金石、中证投、建银国际、华泰紫金。成立 2025/5，**一年半 7 轮、累计超 2 亿美元**。不造机器人，做"无本体"人类技能数据：DAS 采集终端 + Gen Matrix 治理平台 + Gen ADP 众包产线。年初开源 1.3 万小时数据集，单月下载破百万。交付量单季 10 万 → **百万小时**，2027 目标**千万小时/季**。创始人陈建兴为前 Momenta 算法高级总监 |
| **机器科学（RoboScience）** | 数亿元 **A2**（11/3） | 琥珀资本、鸿瑞达、上海半导体产投联合领投；爽资本、360 战投、国联民生、金鼎资本及多家上市公司平台跟投。成立 2024/12，今年第三轮。创始人田野为前 **Apple AI Platform 技术负责人**，联创邵林为 NUS 助理教授（斯坦福 AI Lab 博士）。资产线：RoboMirage 可微多模态物理仿真引擎（2025/9）→ Visics 通用具身大模型（2026/6，主打跨本体泛化操作）→ REX G1 轮式仿人形（2026/8）；已在零售商超、物流推 EaaS |
| **考拉悠然** | **B++**（11/3） | 投资方明文炜业；资金投向世界模型基座、具身智能体产品化、高端人才。核心技术 **BWM-Pro 以 70.42 分登顶 TriWorldBench 总榜**（三个维度均第一）；产品 **Geek Mind** 具身大脑，内置硬件抽象层，把不同品牌/协议的机器人本体翻译成统一语义指令，主张"一次开发、全量适配"。CTO 顾舒航为前哲库 AI 算法负责人、电子科大教授 |

**值得关注的原因**

1. **这与 10-31 期"整机融资腰斩（10 月 33 起/101 亿 vs 9 月 60 起）"形成剪刀差：钱没走，换了层。** 整机在退潮的同时，数据层与大脑层在单笔放大。这是"资本从本体溢出到数据供给端"最直接的证据链，也解释了为什么 10 月笔数腰斩但头部单笔反而变大。
2. **简智的单位经济是全部叙事的支点。** 行业数据售价约 **500–1000 元/小时**，采集成本约 **30 元/小时**——这个毛利空间解释了 14 个月 7 轮。但风险也在这里：一旦供给放量到千万小时/季，价格会以多快速度塌？自动驾驶的数据成本被整车销量摊薄，人类技能数据没有这层缓冲，这是简智必须回答的问题（参考 Scale AI 的路径与 Meta 143 亿美元买 49% 股权的先例）。
3. **考拉悠然代表"只做大脑不做本体"的第三条路，若成立会压缩本体厂商的议价权。** 硬件抽象层做统一语义指令，理论上本体就退化为执行器与代工。对照机器科学的"Visics 跨本体泛化"、简智的"无本体数据"，三家从三个角度押注同一件事：**本体不是壁垒，数据与大脑才是。** 这是本周最值得持续观察的结构性赌注。

## 附注速览
