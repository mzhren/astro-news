**适用人群**：习惯终端工作流的资深开发者；需要自动化大型改造任务的团队。

**核心能力**：

- 仓库级任务自主执行：读代码、改代码、跑测试、提 PR 一条龙。
- 与 Claude 4.5 的长任务能力深度配合，可持续工作数小时。
- MCP 协议支持接入任意外部工具与数据源。

**价格**：按 API 用量计费，也包含在 Claude Pro/Max 订阅中。

**一周体验**：让它独立完成"升级依赖 + 修复全部测试"的任务，90 分钟无人值守跑完，中途只在权限确认时打扰了一次。成本不低，但省下的时间远超账单。
