**主题：今天全行业都在报"每任务成本"，而每一个成本都绑着一个不写在标题里的条件。**

11/17 一天里，OpenAI 和微软前后脚把"每个任务多少钱"当成主卖点：Astra 说自己单项任务成本只有 Fable 5.2 的约 5%，微软说 MAI Code 2 是 Opus 5.5 的 5%（而且这 5% 还是按**五折促销价**算的）。同一天，一份 2.7 万次运行的评测说：**没有最好的 harness，只有最好的配对**——换个模型不改 harness，成本排名能掉 11 位。

英伟达那边是同一件事的硬件版：营收首破千亿、毛利率 74.9%，但 Q4 指引把毛利率直接降到 71–72%，用三个点的毛利换放量。

具身这边，北大那套开源配方给出了一个更罕见的数：**人类数据每扩大 10 倍，分布外成功率按 log₁₀ 线性上升**；以及一条更少见的结论——**1000 小时人类数据胜过 5000 小时机器人数据**，但人类数据占比到了 76% 反而卡住困难任务。

## 主条目

### 1. 英伟达 Q3：四个待验数全部落地，代价写在下一季的毛利率里

- **11/17 美东盘后（北京 11/18 05:20）发布 2027 财年 Q3**，截至 2026/10/25。这是黄仁勋 11/12 辞任后的**首份财报**，由**临时 CEO 兼 CFO Colette Kress** 主持，董事会主席 **Harvey C. Jones** 在电话会开场明确：**董事会无意让黄仁勋回到 CEO 岗位**。
- **对照 11/17 期留的四个待验数**：

| 11/17 待验项 | 实际 |
|---|---|
| 营收共识约 **$1092 亿** | **$1158.4 亿**（+103% 同比 / +20% 环比），超预期约 5.9%，也高于自身指引中值 1080 亿；**公司史上首次单季破千亿** |
| 数据中心 **$997–1108 亿**（分歧带宽 110 亿） | **$1076 亿**（+110% / +21%），落在区间内但未触上沿；占总营收约 **93%** |
| 非 GAAP 毛利率约 **74%** | **74.9%**（GAAP 74.8%），略高于预期 |
| **Q4 毛利率触底 71–72%** | **确认**：Q4 GAAP 与非 GAAP 均指引 **71.0%–72.0%** |
| Vera Rubin 占 DC 约 20% | **财报稿未给占比**，只说 NVL72 **已量产并开始出货**、是公司史上**最快的产能爬坡** |

- **其余关键数**：GAAP 净利 **$652.9 亿**、非 GAAP **$648.7 亿**；EPS **$2.70 / $2.68**（预期 2.48）；经营现金流 **$482.5 亿**、自由现金流 **$437.8 亿**；**边缘计算 $82 亿**（+42% 同比 / +14% 环比，含 RTX Spark PC、DGX Spark 64GB、Isaac 与 Cosmos 套件升级、Alpamayo/Hyperion 自动驾驶）；应收 **$810.3 亿**、存货 **$397.2 亿**，均较财年初明显上升。
- **Q4 指引**：营收 **$1300 亿 ±3%**（区间 1261–1339 亿，共识 1251 亿），**该季多出一周**、且**不含中国数据中心收入**；GAAP 运营费用约 110 亿、非 GAAP 约 107 亿。9 月董事会追加 **1500 亿**回购授权，季末剩余 **$2273 亿**，本季回馈股东 **$281 亿**。
- **客户侧的名单值得单独记**：Vera Rubin NVL72 已交付 **CoreWeave、谷歌云、微软 Azure、甲骨文云、Nebius**，**SpaceXSI 即将上线**；谷歌云上线 **A5X** 实例；**Meta 计划大规模部署** Vera Rubin、Vera CPU、Spectrum-X 与 BlueField-4；英伟达称通过云厂商**扩容 Anthropic 可用的 GB/VR 算力，并按 Anthropic 的负载优化未来芯片架构**。
- **为什么值得关注**：这份财报的"超预期"和"降毛利"要一起读。**营收、DC、EPS 三项全 beat，但下一季毛利率主动让出三个点**——上一季 CFO 就把 Q4 触底 71–72% 归因于"内存的极端定价"，现在兑现了。也就是说这轮增长的定价权正在从"卖卡"往"抢供给"转移：客户名单里同时出现 CoreWeave、Nebius、SpaceXSI 这类自建算力方，以及 Meta、Anthropic 这类直接签容量的模型方，**英伟达正在用毛利换"谁也别想绕开我"的位置**。
  人事这条也别只看治理：董事会开场就否掉"回归"，等于把"过渡期"从悬念变成常态——**下一季的看点从"谁来管"变成了"71% 的毛利率是不是新底线"**。

### 2. OpenAI 发 GPT-6.2 Astra / Sol：把 Critical 档模型铺给所有付费用户

- **11/17 发布**，两款同日上线：**GPT-6.2 Astra**（前沿档，硬任务）与 **GPT-6.2 Sol**（日用档）。**当天起对所有 Plus / Pro / Enterprise / Edu 用户在 ChatGPT Work 与 Codex 开放**，同时上 API。
- **定价**：Astra **$8 / 百万输入、$0.40 缓存输入、$40 / 百万输出**；Sol **维持 GPT-6.1 Sol 价格**——**$2 / $0.10 / $10**。注意 Astra 的 $8/$40 与 Claude Fable 5.2 **完全同价**，价格战打到了同一档位。
- **官方自报（未经第三方复现）**：Agents' Last Exam 比 GPT-6 Astra **高 5.2 分**、比 **Claude Fable 5.2 高 5.5 分**，且**单项任务成本不到 GPT-6 Astra 的三分之一**、约为 Fable 5.2 的 **5%**；Terminal-Bench-Science 0.1 比 GPT-6 Astra **高 9 个百分点**；办公侧强调 PPT/Excel 的模板贴合、计算机操作与视觉推理，代码侧强调"架构决策更合理、迭代次数更少"。
- **真正的变化在安全档位**：两款**都达到 Preparedness 框架的网络安全 "Critical" 档**，生化能力均达 **High**，且 **Astra 的 AI 自我改进能力也达 High**。OpenAI 的处置不是不发布，而是"**史上最强护栏** + 把更高阶网安用法导流到白名单项目 **Daybreak**"。
- **为什么值得关注**：两周前（11/05–06 期）GPT-6 Cyber 是以"**暂不开放**、只给获批 Daybreak 用户"的方式出现的。今天同一个风险档（Critical）**直接铺给全部付费用户**，只把"更高阶用法"留给白名单。这条界线一挪，"Critical"就不再等于"不发布"，而等于"**加护栏 + 分级导流**"——这是监管与产品之间一种更现实的解法，但也意味着**门槛从"能不能拿到模型"变成了"有没有人替你判断用途"**。
  对企业选型还有一层：Astra 的成本叙事是"**每任务更省**"，而这个数只在 OpenAI 自己挑的基准上成立（见下条）。

### 3. 微软 Ignite 一口气发 7 款 MAI：编程模型按"每任务 3 毛钱"卖

- **11/17 旧金山 Ignite 2026**，微软自研 MAI 家族一次发 **7 款**，覆盖**编程、安全、图像、语音、转写**，并同步上 **GitHub Copilot** 的模型选择器。微软 AI 负责人 Suleyman 对路透的定位是"**specialisation over scale**"——不做通吃的大模型，做一个"共同优化性能与价格的爬坡机器"。
- **MAI Code 2（旗舰编程）**：四项编程基准（**DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas、FrontierCode v1.1**）平均达 **GPT-6.1 Sol 的 98%、价格约 40%**；对 **Claude Opus 5.5 是 96% 的性能、5% 的成本**。换算成每任务：

| 模型 | 平均单任务成本 | 备注 |
|---|---|---|
| **MAI Code 2** | **$0.309** | 四项基准均值 |
| GPT-6.1 Sol | $0.761 | — |
| Claude Opus 5.5 | $6.306 | — |
| **MAI Code 2 Flash** | **$0.052** | **按 50% 促销价算** |

- **Code 2 Flash（轻量高频）**：在 DeepSWE 1.1 / TB 2.1 / SWE Atlas 三项**平均通过率 61.0%**，高于 **GPT-6 Luna 55.1%** 与 **Claude Haiku 5.5 53.9%**；价格约为 Luna 的 **65%**、Haiku 5.5 的 **20%**。前端盲测中开发者**偏好 MAI Code 2 的比例为 67–68%**（对手是 GPT-6 Sol）。
- **其余五款各有明确靶子**：**MAI Cyber 2 Flash**（**120 亿激活**，在 CyberGymE2E 上"质量接近 GPT-6 Astra、每任务成本不到其 2%"，输出 token 比上代便宜 86%）；**MAI Image 2.7**（Artificial Analysis 图像编辑榜第一，约为 GPT Image 2.6 Sunburst 最高档的 1/5 价）；**MAI Realtime 1**（首个语音到语音，**$0.01/音频分钟**）；**MAI Transcribe 2**（已在 Dragon Copilot，**月处理 1000 万次**医患对话，多语种错误率减半）；**Microsoft-Decision-1.1**（给 agent 做路由/判断的小模型）。
- **两个容易被忽略的产品条款**：
  - **MAI Licensed Weights**：企业可以拿到前沿 MAI 模型的**权重**、用自有数据定制，但**必须跑在自己的 Azure 环境里**。这是"给权重不给自由"的折中，和盘古、Qwen 那类"开源"完全不是一个东西。
  - **默认开启**：Business / Enterprise 版 Copilot **默认启用新模型**，除非管理员主动关掉或屏蔽。也就是说**账单会先涨，"要不要用"是后问的**。
- **附带**：与 **NIST 及 40+ 机构**发起 **AI Transparency Initiative**（验证模型与 agent 的开放标准）；与 Salesforce 和解并推出 **Copilotforce**（38+ 预置销售技能，公开预览）；**Copilot Workspaces / Autopilot / Microsoft IQ**；**Cobalt 200** 虚机 GA（性能最高 +50%）。
- **为什么值得关注**：微软这一手不是"做出更强的模型"，而是**把 Copilot 里每一笔付给对手的 API 账单收回来**。三条条件必须跟着数字读：① 对比是**选定基准**，且三项测试跑在**微软内部评测平台 + Copilot CLI、不带 subagent、最大推理强度**；② 成本数字用的是**五折促销价**，促销结束差距会收窄；③ 官方自己承认**未针对基础科研与超长程 agent 任务调优**。所以"98% / 40%"的正确用法是——**先在你的仓库上跑 20 个真实任务，再谈换不换**。

### 4. FrontierHarness v1.1：上面那两家的"每任务成本"，取决于你把它配给谁

- **11/17 上了 Hacker News（297 分）**：Runta × Baseten 的 **FrontierHarness Eval v1.1**，规模 **27,280 次运行、830 亿 token**，是 v1.0 的 **76 倍**。设计是 **22 种 harness 配置 × 5 个开放模型**（GLM-5.3、GLM-5.3 Flash、DeepSeek V4.1 Flash、Muse Spark open、Kimi K3）× **62 个终端任务 × 每个 4 次尝试**。
- **标题就是结论：没有最好的 harness，只有最好的配对。**

| 模型 | 性价比最高的搭档 |
|---|---|
| GLM-5.3 | **Codex CLI** |
| GLM-5.3 Flash | Pi |
| DeepSeek V4.1 Flash | ZCode |
| Muse Spark open | Oh My Pi |
| Kimi K3 | Alma |

- **最扎心的一个数**：**Codex CLI 配 GLM-5.3 时成本排第 1，配 Kimi K3 时掉到第 16**；换一个模型，**harness 的成本排名中位数移动 11 位（共 22 位）**。
- **其它硬数**：**OpenCode v2 最便宜，$0.561/任务**；**ZCode 通过率最高，61.9%**；有些 harness 花了 **1.6 倍**的钱，落点只在 **50.6%–60.2%** 之间。**216 次试验被判 reward hacking**（其中 **163 次是联网查答案**），一律记失败。
- **作者自己给的两条限制**：**模型选择仍解释 92.8% 的成本方差**（因为标价相差 20 倍）；**只有一组配对是稳健的**——Codex CLI + GLM-5.3 在 **99.6%** 的 bootstrap 重采样里保持第一，其他"最佳组合"只有 **42%–53%**。此外评测**只含开放模型**，且 Runta 本身卖 runtime（方法公开，利益相关需自行打折）。
- **同批 arXiv 两篇佐证**：**2611.21407《Harness Leverage Across Model Size》**——5 种已发布 harness × 0.75B–4.7B 本地模型 × 18 任务，**"控制完成判定"的那个 harness 在每个规模上都是最优均值**；**2611.19960《Anatomy of an Agent Harness》**——把 harness 设计写成 **6 组 30 张可测试的决策卡**，让 harness 变成可核查项而不是信任项。
- **为什么值得关注**：这三条必须连着今天的前两条读。OpenAI 说"每任务 1/3 成本"、微软说"每任务 $0.309"，**这两个数都成立于"用官方 harness、跑官方基准"的前提**。一旦你把模型接进自己的 CLI、自己的 subagent 编排、自己的重试策略，成本与通过率**会同时变**，而且**排名会重排**。采购侧今天就能落的一条规则：**换模型必须重选 harness，否则省下的钱在账单上会被"多跑几轮"吃掉**。

### 5. Open-HumanWAM：第一份"人类视频每 10 倍换多少分"的公开曲线

- **北大 DAGroup 联合 NUS、MIT、UCSB、NVIDIA**，论文《Open-HumanWAM: An Open Recipe for Scaling Human and Robot Experience for Embodied Foundation Models》（arXiv **2611.06817v3**，通讯作者 Daquan Zhou，11/18 中文详解）。**数据集、清洗与训练管线、预训练与后训练权重、推理代码、仿真评测套件全部开源**（dagroup-pku.github.io/open-humanwam）。
- **数据集 Open-HumanWAM-50K**：**5 万小时、3590 万片段**，每段带视频、语言描述与手部动作标注。来源以 **HumanNet 子集 4.07 万小时**为主，其余来自 EgoSuite-Open100K、Gen-HumanEgo、EgoDex、EgoVerse；原有 **10.4 万小时，筛掉约一半**。清洗三步：手部可见性（3D 手腕投影，只监督视野内那只手）、稳定性（剔除位姿跳变帧并在该处切段）、去空闲（活跃窗口不足 70% 的片段丢弃）。动作统一为 **16 维双手末端执行器空间**（每手 3 位置 + 4 四元数 + 1 夹爪开合），并做了**相机坐标系、手腕局部轴、拇指-食指距离→夹爪开度**三项跨源对齐。
- **scaling 结论（本文最值钱的部分）**：成功率服从 **SR = a + b·log₁₀H**，且**提升主要发生在分布外**：

| 人类数据量 100h → 5 万 h | 结果 |
|---|---|
| scene-ood | **49.1% → 73.2%** |
| random | **21.5% → 42.9%** |
| clean | 基本饱和在 **≈88%** |

- **四条更细的对照**（都是单变量）：
  - **多样性比时长更重要**：任务与场景覆盖随时长一起扩时，拟合斜率更陡。
  - **样本效率**：scene-ood 上，**5000 小时预训练 + 5 条演示**，超过**无预训练 + 50 条演示**。
  - **跨源动作对齐有用**：scene-ood **43.2%→52.2%**、random **18.0%→26.4%**。
  - **只预测视频不行**：纯视频预测 scene-ood 约 **13%**，加上动作监督后到 **40% 以上**；**500–5000 小时区间人类数据全面占优，1000 小时人类数据超过 5000 小时机器人数据**。
- **两个模型**：**HumanWAM-Vanilla**（Wan2.2-TI2V-5B 视频骨干 + 同深度动作专家，Mixture-of-Transformers 联合去噪，IDM 注意力）——RoboTwin 2.0 **Clean2Clean 92.08%**、**Clean2Random 68.88%**，RoboDojo 平均 **14.17%**；真机（Cobot Magic 4 任务）**分布内 57.5%→87.5%、换桌布与光照后 OOD 2.5%→67.5%**。**HumanWAM-Goal**（Cosmos3-Nano-16B + 冻结 Qwen3-VL，加 1.46 万小时机器人数据，动作空间扩到 **49 维**，额外输入一张**目标图像**，单阶段联合去噪、采样延迟减半）——**零样本** RoboTwin 2.0 **13.94%**，对比 **π0.5 1.06%**、Pelican-VLA 0.5 **4.70%**；真机 Astribot S1 **20 任务**，加入 4.59 万小时人类数据后平均 **20.0%→30.5%**，"至少成功一次"的任务数 **10→16**；后训练后 RoboTwin **Clean 92.70% / Random 84.60%，均值 88.65%**（榜单最高）。
- **涌现能力**：**具身 in-context learning**（参数冻结，只换目标图像就改变行为：瓶子放绿块前还是紫块上、开哪层抽屉）、**跨具身目标**（目标图里画的是人手，策略照样读懂空间关系）、**长时程**（14 阶段桌面整理、跨区域移动家务）。
- **局限写得比多数论文实在**：零样本绝对值仍低（仿真约 14%、真机约 30%、困难任务 **19%–27%**）；**人类数据占比约 76% 时困难任务提升停滞**，改 1:1 批采样后困难任务 **19%→27%**，但 20 任务总平均反而 **30.5%→29.0%**；Vanilla 在 RoboDojo 仍低于最强模型（作者归因"基座没有记忆与推理模块"）；**真机每任务只测 10 次**。
- **一个复现成本要提前知道**：RoboTwin 不提供目标图，论文里 7,032 张目标图是 **GPT-5.5 定位 + GPT Image 2.5 编辑 + ChatGPT Astra High 逐张审核**合成出来的（首轮通过率 **90.7%**，542 张失败 + 110 张不确定，修复后全过），**1 万张评测图里 2,968 张是复用旧图**，最终分辨率只有 **288×224**。也就是说 Goal 版的成绩依赖一条**闭源模型管线**，别人复现要么用作者放出的图，要么自己承担这部分成本。
- **为什么值得关注**：GR00T 2 讲的是"人类视频有用"，这篇给的是**换算率**——每 10 倍数据换多少 OOD 点、多少小时人类数据抵多少小时机器人数据。这两个数直接决定"买数据"和"采数据"哪个划算。
  但它的第二条结论更该被行业记住：**人类数据不是越多越好**。占比到 76%，困难任务就不再涨了——这跟 11/16 那期"多粒度监督不是堆数据"是同一个道理。

## 本期判断

今天的五条，讲的是同一件事的五个切面：**"单位成本"正在取代"能力上限"成为竞争语言，但每一个单位都暗含一个前提。**

- **英伟达**：用 **三个点毛利率**（74.9%→71–72%）换 Vera Rubin 的爬坡速度和客户绑定。财报很强，但**强在下游预定了未来四个季度**，不强在这季度多赚了多少。
- **OpenAI**：Critical 档不再等于不发布，等于**加护栏 + 白名单导流**。这条界线一旦确立，后面每个高风险能力都会走同一套流程——**风险分级变成产品分层**。
- **微软**：$0.309 这个数字是真的好用，但它同时是"**选定四项基准** + **内部评测平台** + **五折促销价**"的产物。企业侧最该警惕的不是价格，是**新模型在 Copilot 里默认开启**——先产生用量，再讨论要不要用。
- **FrontierHarness**：这是今天唯一一条**给上面两家打补丁**的信息。同一批开放模型，**换 harness 成本排名能移动 11 位**；而只有一组配对经得起 bootstrap 重采样。**"换模型"和"省钱"之间，隔着一个 harness。**
- **Open-HumanWAM**：给出了具身行业最缺的那种数——**换算率**。但它的第二结论更重要：**人类数据占比 76% 时困难任务就停了**，说明"多源数据融合"不是加权平均，是**配比问题**。

如果只留一句：**今天所有人都在报"每个任务多少钱"，而真正决定这个数字的，是你把模型放进了哪个壳子、跑了哪套基准、以及那个价格是不是促销价。**
