Amp 推出 Spaces：用户只与一个主 Agent 对话，由它理解目标、拆解任务，**自动创建并协调并行 Agent 线程**；各线程的进展以实时卡片呈现在聊天中，点开卡片即可进入线程查看产出、继续迭代。

## 定位：团队协作场所

Spaces 被明确定位为团队协作空间：成员在同一 Space 里提需求、评论；为减少干扰，仅在 @amp 时才会读取评论。官方给出的案例包括：单个 Space 内完成服务账号功能发布、定期安全审查。

## 为什么值得关注

多 Agent 工作流此前是"用户自己拆分、分派、追踪"，Spaces 把组织层交给 Agent。这与 LoopForge 的 Main Bot、被 Meta 收编的 Conductor 是同一趋势的三家不同解法——编码 Agent 正从"工具"走向"AI 项目经理"。
