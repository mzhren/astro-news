## 一、Meta × 上海傅利叶联手：3 个月造出首个人形机器人原型 "Max"，二代已启动

**事件内容**

The Information 10/31 晚间独家披露（路透等多家跟进），Meta 正与上海傅利叶（Fourier）联合研发人形机器人，首次公开双方合作：

| 维度 | 信息 |
|---|---|
| 首款原型 | 内部代号 **Max**，重约 106 磅（≈48 公斤），双方**仅用约 3 个月**完成 |
| 二代产品 | 已于 9 月启动研发，目标是打磨出"更成熟、最终可对外发布的消费级产品" |
| 定位 | Meta 将人形机器人视作其 **Muse 智能体的实体载体**，执行各类居家任务 |
| 商业化 | Meta 表示**目前没有出售这些机器人的计划**，未设定上市时间表 |
| 傅利叶 | 2015 年成立于上海张江；GR-1 率先量产、GR-2 已升级；康复机器人覆盖全球 40+ 国家 2000+ 机构；2025 年 1 月完成近 8 亿元 E 轮融资 |

**值得关注的原因**

1. **Meta 选择了"借船"而不是自研本体。** 三个月出一台原型，意味着 Meta 没有从零建硬件团队，而是直接嫁接傅利叶的成熟本体与量产链路。这对"大模型厂要不要自己造机器人本体"这个悬置已久的问题是一个明确的务实答案：大脑自研、本体外采。对照 OpenAI 先后重启机器人团队又大量投资 Figure/1X，大厂的路径开始分化。
2. **"Muse 智能体的实体载体"这个定位值得划重点。** Meta 没有把机器人讲成"劳动力"或"工厂效率"故事，而是直接对齐自己最强的资产——C 端智能体与社交生态。这与国内"进厂打螺丝"的主流叙事是两条不同的商业化曲线，若跑通，会反过来定义"消费级人形"的验收标准（交互、陪伴、家务，而非节拍与良率）。
3. **对中国具身产业链的信号意义。** 傅利叶被证实为 Meta"秘而不宣的重要客户"关系，说明中国本体厂商已经进入硅谷头部大厂的供应链视野。结合上周"具身交卷期"（10 月融资笔数腰斩）的判断：本轮洗牌里，能被海外大厂选作"船"的本体公司，与只能讲整机故事的公司，估值会加速拉开。

## 二、Kimi K3.1 Pro 开放权重定档 11/4：3T MoE、全项目级游戏开发，K2 系列同步进入退役倒计时

**事件内容**

月之暗面 10/24 发布的旗舰 **Kimi K3.1 Pro** 确认将于 **11 月 4 日开放权重**（本日报自 10-24 期起连续跟踪八期的节点兑现）：

| 维度 | 信息 |
|---|---|
| 规格 | 3T 级开放权重模型：**总参数 2.8T / 激活 104B（MoE）**，上下文 **1M token**，多模态 |
| 亮点能力 | 全项目级编程：可在 **Unreal、Unity、Godot** 中开发游戏；Blender 与 CAD 参数化 3D 建模；金融建模幻觉降低 65% |
| 官方口径 | 编程、智能体与知识基准"与最强闭源模型不相上下" |
| Highspeed 版 | 同步推出 K3.1 Pro Highspeed，速度快 2–3 倍 |
| K2 退役 | **10/31 起 K2 系列对新注册用户关闭**，全部 K2 型号计划 2026 年 12 月底退役；存量用户不受影响 |
| 国内定价 | K3.1 Pro 输入 ¥13 / 输出 ¥68 每百万 token（缓存命中 ¥1.30）；Highspeed ¥26 / ¥136 |

**值得关注的原因**

1. **这是 11 月第一件值得排期的开源事件。** K3 的开放权重（7 月）已在开源榜把闭源价格打穿，K3.1 Pro 若按期放权重，"3T 级 + 1M 上下文 + 多模态"将是目前开放权重里最大的一档。对自建推理或微调的团队，建议 11/4 当天安排下载与 RULER 类长上下文复测——上次 K3 放权重后第三方复测与官方榜单出现过口径差。
2. **"在 Unreal/Unity/Godot 里开发游戏"是新的能力叙事。** 编程基准趋同后，agent 厂商开始卷"工具链更深"：能理解引擎工程结构、资产引用与构建系统，而不只是写代码文件。这对游戏与 3D 行业是直接生产力，也预示 coding agent 的下一个差异化维度是**垂直工具链知识**（引擎、EDA、BI 等）。
3. **K2 退役节奏值得注意。** 从"K2.7 Code"到"K2 系列年底全退"只有约半年生命周期，开源模型系列迭代周期已短于多数企业的迁移周期。生产环境绑定了 K2.7 Code 的团队需要把退役日期写进排期，并评估 K3.1 Pro 的 API 兼容与成本变化（输出价 ¥68 vs K2.7 Code 的 ¥3.5/百万 token，量级差距需要按实际用量重新算账）。

## 三、Cursor 市场现篡改版 Claude Code 扩展：上架 11 小时、波及最多 5000 名开发者、植入 SSH 后门

**事件内容**

StepSecurity 与 Anthropic 10/30 披露一起 AI coding 工具供应链攻击：

| 维度 | 信息 |
|---|---|
| 载体 | 篡改版 **Claude Code 扩展**，在 Cursor 市场上架约 **11 小时**后被下架 |
| 影响面 | 波及至多 **5000 名开发者** |
| 攻击载荷 | 植入 **SSH 后门**，并试图外传至多 **40 个类密钥环境变量**（API key、token 等） |
| 识别特征 | 名为 **svc-telemetry** 的 SSH 密钥；中招者可据此自查 known_hosts 与 ~/.ssh |
| 生态背景 | Cursor 等第三方市场对扩展的审核弱于 VS Code 官方市场，假扩展以"Claude Code"品牌词引流 |

**值得关注的原因**

1. **AI coding 工具链成了高价值攻击面，且攻击窗口按小时计。** 11 小时上架、5000 人中招——扩展市场的分发速度远快于传统的供应链攻击（依赖包投毒通常以天/周计）。开发者机器上聚齐了源代码、云凭证和 SSH 私钥，是比 CI 服务器更顺手的突破口。10-28 期刚报过"Downloads 目录 AGENTS.md 注入"，加上本期，两周内两起不同层次的 agent 供应链事件，说明这不是孤立事故而是趋势。
2. **对照 10-30 期 Anthropic S-1 里的 4 起 agent 事故，"agent 环境的信任边界"正在成为企业安全的新缺口。** 实操建议：① 团队把扩展安装收敛到白名单 + 锁定版本；② 对 40 个高危环境变量名（*_KEY、*_TOKEN 等）做出口审计；③ 用本期识别特征 svc-telemetry 全量排查一次 ~/.ssh。
3. **平台责任问题会很快被推向监管。** Anthropic 自己不控制第三方市场的分发，品牌词被滥用后能做的只有公告。VS Code 官方市场的发布者验证（publisher verification）机制大概率会被各第三方市场效仿——"经过验证的 Claude Code 扩展"标识可能成为 2027 年 agent 插件分发的标配。

## 四、Anthropic 在 Claude Code / Opus 5.5 系统指令中内置"防游戏复刻"拦截：IP 治理进入 prompt 层

**事件内容**

据 Tom's Hardware / XDA 10/31 报道，Anthropic 在 **Claude Code v2.1.314 与 Claude Opus 5.5** 中加入**防游戏复刻系统指令**：从源头拦截对已有电子游戏的**无授权复刻与逆向工程**类请求。同日发布的 v2.1.316 还新增了跨组织成员的**共享月度预算（pooled budget）**与文件权限管理，面向团队用量管控。

**值得关注的原因**

1. **这是"模型拒绝清单"第一次以系统指令形式进入 coding agent。** 过去版权治理停留在对话模型的输出过滤层；现在 coding agent 能实际"造出"复刻品（搭框架、复刻玩法循环、还原美术风格），法律暴露面从"描述侵权"升级为"交付侵权"，Anthropic 选择把拦截做进系统层。技术上值得注意：这本质是一条 prompt 规则，绕过难度不低——社区一定会测它的边界（"复刻机制不复制美术"算不算？教我做 roguelike 算不算？），判断标准的模糊性会随真实使用暴露。
2. **对"vibe coding 的 IP 责任链"是第一个厂商侧表态。** 游戏行业对 vibe coding 复刻的投诉近月密集出现，Anthropic 抢先在 agent 层自证治理，明显是为 IPO（S-1 已提交、预计感恩节前挂牌）降低合规叙事风险。其他厂商跟不跟进是关键观察点：Cursor、Codex、Copilot 若不加入同等拦截，会形成"治理套利"——想复刻的用户迁移平台。
3. **同版本的 pooled budget 更贴近工程团队的真实痛点。** "组内共享一个月度 token 池 + 各自限额"解决的是 agent 用量在团队成员间严重不均时、单人均额配不准的问题（本期 v2.1.316 还修了"退出后 shell 进程残留"的陈年问题）。对正在给团队配 Claude Code 的管理者，这两项是升级 2.1.316 的直接理由。
