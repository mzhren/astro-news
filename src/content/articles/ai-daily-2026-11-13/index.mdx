## 主条目

### 1. 黄仁勋辞任英伟达 CEO：33 年后，那个"替行业提前下注"的角色交回给董事会

- **11/12 美东时间，英伟达发布声明**：黄仁勋辞去**总裁、首席执行官及董事会成员**职务，**即刻生效**。现任执行副总裁兼 CFO **科莱特·克雷斯（Colette Kress）** 出任**临时 CEO** 并继续兼任 CFO；董事会**已启动正式 CEO 遴选，内部与外部候选人都纳入考量**；同时任命 **Harvey C. Jones** 为公司史上**首位董事会主席**。2027 财年 Q3 财报**维持原定时间**——太平洋时间 **11/17 13:20** 发布、14:00 电话会。
- **起因不是业绩**：10/29《纽约时报》披露黄仁勋与一名受美国情报机构关注的中国籍商界女性关系密切，引发对英伟达商业关系与出口管制的追问；**11/08 黄仁勋公开承认婚外情并向家人、员工、股东道歉**，董事会随后启动独立调查。四天后辞职。
- **市场给的是"关键人风险"的定价**：

| 时点 | 数值 |
|---|---|
| 前一日收盘 | $173.73 |
| 11/12 开盘 | $151.01（盘前一度 -10%） |
| 盘中最大跌幅 | **约 -14%**，市值蒸发近 **6000 亿美元** |
| 跌幅收窄后 | 约 **-7.5%**，市值 **3.88 万亿美元**，跌至美股第三 |

  卖方同步下调：**Baird 把评级从"买入"直接降到"中性"、目标价 $500→$200**；花旗 $285、富国 $300、瑞穗 $250；摩根士丹利将其移出首选名单。做空方账面获利约 **38 亿美元**（ORTEX 数据）。黄仁勋及关联实体持股约 **8.115 亿股**（2026/9 披露文件），自 10/29 事件曝光以来账面缩水约 **407 亿美元**。
- **为什么值得关注**：这条不是人事新闻，是**"确定性溢价"被重新折现**。英伟达过去两年的高估值建立在四件确定性上——训练与推理需求扩张、软硬件协同生态、产品迭代节奏、订单能见度。管理层变动不会自动改变任何一条，但它改变了市场**给这四条打几折**的方式。更值得记的是黄仁勋的不可替代性来自哪里：CUDA 是他顶着多年亏损押的，GPU 从图形处理器变成通用计算是他押的，AI 需求爆发前的软硬件布局也是他押的——**这些都是"风险无法被准确计算时仍要下注"的决策，而 CFO 的职责结构恰好相反，是先算清再下注**。所以短期的观察点不是股价，是 11/17 财报里**客户订单与产品路线图有没有转向**；Michael Burry 的判断可以当参照：财报会"非常出色"，但围绕 CEO 的危机会威胁支撑英伟达增长的**融资安排与客户交易**——这句话真正指向的是那套"模型厂→云厂→芯片厂"的循环融资结构。
- **对本期两条主线（coding 与具身）的传导是直接的**：全球绝大多数前沿 coding 模型与机器人基础模型都跑在英伟达的卡上；**12 月 GR00T 2 与 Turbo 要开源、Turbo 要在宇树 G1 的 Jetson Thor 上跑 124ms**（11/10 期），Cosmos、Isaac Lab、Jetson Thor 这条具身技术栈的路线连续性，现在由一位临时 CEO 和一届新董事会保管。对照 11/07 期那条"英伟达单日 -9%、蒸发 4500 亿"——当时还只能归因于板块回调与 Anthropic IPO 传闻，五天后有了明确因果。

### 2. Gemini 4 Hydrogen + Orchestrator：谷歌把"选哪个模型"从开发者手里收走了

- **11/12（PT）发布、11/13 全球铺开**：**Gemini 4 Hydrogen** 是 Gemini 4 家族的**快速执行档**，取代原 Flash 档位（但**价格没有沿用 Flash**）。同步在 **Google Antigravity** 上线 **Orchestrator**：同一会话内**自动在 Carbon 与 Hydrogen 之间切换**。

| 项目 | 数值 |
|---|---|
| 价格 | **$1.50 / $7.50** 每百万输入/输出 token（含思考 token），**全 100 万上下文统一价，无阶梯** |
| 隐式缓存 | $0.075 / M；**不支持显式缓存** |
| 上下文 | 1,048,576 token，**输入、思考、输出共享同一个窗口**；单步同步输出上限 65,536 |
| AA 智能指数 | **51**（默认 high）/ **54**（xhigh）｜Argon 为 50 |
| Terminal-Bench 4.1（去作弊校正） | **57.0%**｜Claude Sonnet 5.5 **63.9%** |
| OSWorld-2.1 | 77.6%｜Sonnet 5.5 83.9% |
| 其他 | SWE-sweep 13.5%（vs 3.1%/5.8%）、Agents' Last Exam v1.1 71.6%、AutomationBench-AA 76.1%、HLE-Diamond 58.8% |
| 对比 3.8 Flash | 同档速度 **2.5×**、TB4.1 **18.2%→57%**、虚构陈述**减少 5 倍以上** |
| 安全 | agent 越权 **-81%**、服务不足 **-79%**、走捷径/失准 **-12 倍**、越权绕过权限边界 **-2×**、内部诚实度 **96.7%**、Gray Swan 间接注入韧性 **+2.3×**｜**但无理拒答比 3.8 Flash 高 5.57 个百分点** |

- **Orchestrator 才是这条的真新闻**。分工是"**Carbon 规划，Hydrogen 改代码、跑测试、做验证**"；执行卡住时**可以把控制权交回 Carbon 重新规划**，而不是"开局选一个模型、整段任务用到底"。并行场景下 Carbon 当协调者，Hydrogen 驱动 worker 与 verifier 在**互相隔离的工作空间**里并行改与测。Antigravity 团队自测：Terminal-Bench 4.0 上**接近 Carbon 的任务成功率，配额少用 24%，平均快 19%**。先开放给付费 AI Pro/Ultra，Orchestrator 先给 Ultra。
- **有两个容易被忽略的账单细节**：①Vertex 价目表注明**自 11/13 起，任何超过 32K token 的 Gemini 4 补全，即使请求因客户端或服务端超时失败，也按可检索 token 用量计费**——跑长输出 agent 的团队今天就该去对一遍超时设置；②**xhigh 档会过度思考简单 prompt**，官方建议多数复杂任务用 high。
- **为什么值得关注**：过去一年"大模型规划、小模型执行"是所有 agent 团队**自己搭**的架构——自己写路由、自己定阈值、自己垫兜底。Orchestrator 把这套东西变成**平台默认**，等于模型厂商开始卖"调度"而不是卖"最强单点"。这有三个后果：①**选型指标变了**——不再是"哪个模型分最高"，而是"这套分层在我的任务分布上省多少配额"；②**成本结构从单价转向配比**，Hydrogen 的 $1.50 只有在被大量调用时才有意义，而调用多少由平台决定；③**可解释性下降**——一次会话里换过模型，出问题时你面对的是一条混合轨迹，复现难度上升，这条对做评测与审计的团队是真问题。
- **但别把它读成"谷歌全面领先"**：去作弊校正后 Sonnet 5.5 在 Terminal-Bench 4.1 与 OSWorld-2.1 上仍然领先，Artificial Analysis 的评价是"智能略低于 Sonnet 5.5 与 GPT-6.1 Sol，成本约为 Sonnet 的三分之一、但约为 GPT-6.1 Sol 的 2.5 倍"——**Hydrogen 在成本前沿上并没有压过 OpenAI**。它真正的卖点是"在谷歌自家栈里又快又稳"，以及**一个工程细节**：Hydrogen 会**并行批量读文件与搜索**，而不是一次看一个文件；合作方在图、SQL、数据密集工作流上报的是 2–2.8 倍提速与 12–23% 的 token 下降。对在大仓库里干活的 agent，这条比 token/s 更值钱。
- **一个顺手发生的对照**：**Gemini 4 Carbon 已登陆 Cursor**，而 **OpenAI 对 Cursor 的断供在 11/12 如期进入收尾**（见附注）。11/12 期那条"模型选择器是所有权战场"的故事，两天内就演完了第一幕：**撤走的一方留下 5% 的空位，补位的是另一家的旗舰**。

### 3. Gemini Decision 1：不逐字解码，把 agent 的"判断"做成 0.1 美元的 API

- **11/11 官方博客发布、11/12 中文圈集中解读**：谷歌推出 **Gemini Decisions API**，由新模型 **Gemini Decision 1** 驱动。它不做自由生成，只做**封闭选项内的判断**，输出是**选项概率 + 置信度**，没有一段解释性文字。
- **三种决策类型**：①**是非判断**（可分别描述成立与不成立的标准）；②**多选**（2–255 个候选）；③**有序量表评分**（自定义等级，返回连续加权分与各等级概率）。**三种可混在同一次请求里**。
- **规格与价格**：

| 项目 | 数值 |
|---|---|
| 单次请求 | 一份共享多模态输入（文本/图像/音频/视频/PDF，**≤256K token**）+ **最多 1000 个互相独立的问题** |
| 计算方式 | **单次前向传播**打分，不逐 token 解码 |
| 延迟 | ≤16K token 输入下，模型计算中位 **50–100ms**，端到端 **150–250ms**；1→100 个问题**基本持平** |
| 价格 | **$0.10 / M 输入 token，输出免费**，约为 Gemini 3.5 Flash-Lite 走 Interactions API 的 **1/5** |
| 评测 | 9 项基准**拿下 7 项第一**，校准误差最低，最高准确率 92.2% |

- **这是一个已经存在的品类，不是谷歌首创**：第一家是 **TypeSafe AI 的 Jev**（9 月中发布，几天内破百万用户，三周后以 **75 亿美元估值融资 8.7 亿美元**）；**OpenAI 上个月**也上了 Decisions API。谷歌自己的说法是对比 Jev 与 OpenAI 在 9 项里赢 7 项，但**承认 Jev 更省**。
- **一个独立开发者的实测值得抄下来**：用免费额度跑 54 次调用、30 条客服工单、8 项多语言任务，**分类全对**；单次处理 100 个判断问题耗时 **0.41 秒**。但发现的缺陷很具体：**模型会把超出预设范围的输入强行归入已有类别**——它没有"以上都不是"这个出口。
- **已经在用的地方**：Gemini Notebook，以及**谷歌搜索用它给 MCP 工具做安全防护**——这一条最能说明它的定位：不是替代大模型，是**给 agent 的工具调用加一道毫秒级门禁**。
- **为什么值得关注**：过去做 agent，路由、工具选择、政策校验、上下文质量评估全都要调一个生成模型，然后从它写的散文里抠出结论——**又慢又贵又不稳**。Decision 1 把这件事改成了"给候选打分"，延迟压到 150ms、成本压到 1/5，等于把 agent 的一个**夹层**（判断层）从"顺便用一下大模型"变成"专门买一个便宜模型"。对架构的含义是：agent 不再是"一个聪明模型 + 工具"，而是**采购清单**——判断层、执行层、规划层各自有价格标签。今天谷歌同时给出了两个标签：**判断 $0.10、执行 $1.50**。
- **但有一条硬边界必须写进设计文档**：**如果候选选项本身漏掉了实际情况，返回最高概率也不能证明判断正确**。这和 11/12 期 AMP1 那条"给强模型加辅助例程反而掉 7.5 分"是同一个结构问题——**接口设计决定了失败是被发现还是被掩盖**。用一个只会在 A/B/C 里选的模型做门禁，等于假设世界上只有 A/B/C。

### 4. 清华赵行在 CoRL 2026 讲"时钟"：前沿模型直控机器人，97% 的时间机器人在等模型思考

- **11/12 奥斯汀，CoRL 2026 主会场**：清华大学交叉信息研究院助理教授、**星海图 CTO 赵行**做 **Early Career Keynote（青年成就奖）** 演讲——该奖项须同行提名、不得自荐，只授予博士毕业十年内、已在机器人学习领域留下实质成果的年轻研究者；**今年全球仅三位，赵行是唯一中国面孔**。
- **他先承认了那个让全场焦虑的事实**：GPT-6 Astra 发布后几天内就有人把它接进机器人、发现直接能用。英伟达研究者在 **RoboLab-120** 上报 **Astra 66% vs π0.5 28%**，**RoboDojo** 上 **Astra 22 分 vs π0.5 7 分**。"这很惊人，我相信领域里很多人还没准备好。"
- **然后他指出了这些基准缺的那一列**：**它们不测时间**。Astra 走直接策略，**每次调用基础模型要 18 秒，机器人 97% 的时间在等模型思考**。
- **受控实验（RoboCasa，5 个没见过的厨房、5 项任务、每项限 50 秒，五种控制方式）**：

| 控制方式 | 不限思考时间 | **加上真实时钟** |
|---|---|---|
| 编程策略（模型理解任务后写代码，部署时程序直接跑，不再调模型） | 45% | — |
| 编程 + 询问（跑挂了才求助，每回合约 1 次调用） | >60% | — |
| 编排策略（前沿模型调度不同技能，每回合约 4 次调用） | >60% | — |
| **直接策略**（模型直接控机器人） | >60% | **15%** |
| **智能体策略**（每步可控、可调工具，最费 token） | >60% | **20%** |

  结论一句话：**慢模型没问题，只要它和一个快的 System 1 配合**；问题出在"让慢模型直接开车"。
- **核心主张：时钟定义层级，在时钟变化处画线**。不是按功能分（感知/规划/控制），而是先问"这一层必须对什么做出反应"，再由此定时钟：**System 2 秒到分钟**（用过往经验理解当下）、**System 1 几十赫兹**（手与物体的相对运动）、**System 0 几百赫兹**（接触与力）。他在自动驾驶上验证过这套：慢 VLM 负责理解学区与减速意图、快驾驶栈负责响应，**DriveVLM-Dual 已落地 40 万辆以上量产车**。2023 年四足从视觉学跑酷、到今年全尺寸人形全身跑酷，让他确认第二件事：**反射必须住在快的层，且那一层要独立完成从感知到动作的全部事项**。
- **让每层够快的三项工作**：①**Fast-WAM**——视频模型与动作模型**共享权重**，训练时想象、测试时可跳过，**提速 4 倍以上**；新版本 **5B→16B**、混合 Transformer，RTX 5090D 上**每个动作 60 毫秒**。②**G0.5**（星海图自研 VLA）——任务、边界框、动作轨迹写进**同一条离散 token 流**，同一组权重上可开关推理：**90% 的任务有无推理成功率完全相同**，跳过推理**快一倍**，**推理只在长程任务上有用**。③**ActionCodec2**——流式动作 tokenizer，每个 token 就是一小段运动，收到即执行；对比分块 tokenizer，演示里追踪移动方块时**分块那侧跟丢、流式那侧抓住**。
- **层间传什么，是他真正想讲的**：向下 System 2→1 传语言、目标、程序、动作，System 1→0 传运动；向上 System 0 应反馈接触、力、跟踪状态，System 1 应反馈进度、置信度与状态——**但今天多数工作只做了向下通路，向上通路严重缺失**。WB-WAM 做全身动作生成、OMG 支持"一个动作多种输入"（文字/音乐/参考姿态），可 System 1 到 0 **向下传的仍然只有运动**。"只有运动是不够的。机器人只知道跟着轨迹，不知道目的，而交互的本质是力，比如擦桌子，几乎只有力、没有运动。"
- **他给的关键反例是 UC Berkeley 的 Ctrl-F**：给跟踪器参考动作**和每只手的力指令**，顶层再配一个小规划器按实时情况调力。推 **20 公斤重箱子**——左边 SONIC 只跟踪运动，箱子纹丝不动；右边能推动。**注意是谁在决定力：是贴近物体的那个小规划器（System 1），不是远在顶层的慢模型**。
- **失败落在哪里，也讲得很直白**：底层系统大多时候自己行动却不知道自己已经失败，高层不够快没注意到任务已失败——**这些失败都落在层与层之间，而跨边界的反馈今天是缺失的**。
- **两条路线**：①**分层**——每层有自己的时钟，上层不发精确的接触与力、只发**意图**，下层向上**报失败**；难点是下层必须能自己感知失败、自己纠正、主动上报。②**单模型**——统一架构共享权重，**每个时钟配各自的专家**，推理时以不同时钟运行；好处是共享上下文、KV cache 可复用，难点是联合训练（System 1/2 靠行为克隆、System 0 靠仿真强化学习，两套机制怎么放进一个环境一起训）。
- **他最后给社区的请求，是本期最该被引用的一句话**：以后做机器人仿真基准，**请同时报告"截止时限前的成功率"与"所需推理时间"**。"系统要对什么做出反应，决定了它的时钟；**要选配得上时钟的模型，而不是反过来**。层间要向下发意图、向上报失败。**不要只造一个快模型或一个小模型，要造整个系统。**"
- **为什么值得关注**：这条把 11/12 期 AMP1 那份实验从"苹果的方案很聪明"顶到了"**它的代价被明确标价**"——AMP1 平均**每次成功 280 秒**、大部分时间在思考，而赵行的对照组说的正是：**把思考留在回路里，成功率会从 60% 掉到 15%**。两条并不矛盾，合起来才是完整判断：**agent 直控适合长尾、低频、可等的任务；高频闭环必须交给学出来的快策略**。更重要的是它对当下两个流行阵营同时否定了：既不是"通用大模型接管一切"，也不是"VLA 刷分就够了"，而是**先定系统要对什么反应，再选配得上这个时钟的模型**。同日还有一组数据给这个论点做注脚：一份对 **160 个机器人评测基准**的梳理发现，**只有 11 个真正对比了 VLA 与世界模型，仅 4 个把预测变成了真机动作**——行业攒了一堆"预测分数"，拿不出"干活证据"。

### 5. Agile Robots 拿 5 亿美元、85 亿估值：买的不是人形，是两万台已经在产线上干活的非人形机器人

- **11/12 慕尼黑**：Agile Robots 完成 **5 亿美元 F 轮**，估值 **85 亿美元**，**软银集团领投**，**英伟达、日立（含日立创投）、德国电信旗下 T.Capital** 参投，累计融资 **20 亿美元**。公司自称已是欧洲估值最高的"物理 AI"机器人公司。
