> 主线：今天的关键词是「重装」。AI coding 侧，入口正在被算力和平台重新收编——Cursor 600 亿美元并入 SpaceX 后首次并表，OpenCode 用一次大重构把终端/桌面/Web 收到同一个后台；具身智能侧，路线之争从「模型 vs 本体」转向「全栈能不能跑通」，智元、无界动力同一天给出答卷，国家标准也终于落地。

---

## 1. OpenCode 2.0 正式发布：一次架构级重写，Code Mode 成 MCP 默认模式

**事件**（Anomaly 周一公告，10 月 21–22 日中英文媒体集中报道，更新日志已切至 2.x）

- **统一共享后台服务**：终端、桌面、Web 三个界面接同一个后端，可在任一端接管同一编程会话，跨端无缝续接。
- **重构 API + 可嵌入 SDK**：从「一个 CLI 工具」变成「可被集成的智能体外壳」。
- **子代理与 Shell 后台执行**：可把代码审查委派给跑不同模型的子代理并行进行；跑测试、构建这类长任务转后台，完成后主动通知主代理；也支持快捷键把超时的前台任务转后台。
- **Code Mode（重点）**：围绕 `@opencode/codemode` 的轻量 JS 解释器，把 MCP 服务器和 OpenAPI 端点转成**可编程调用的函数**。例如「从 GitHub 取 issue → 提取信息 → 在 Linear 建单」一次脚本调用完成，不必每一步都往返一次模型。官方称可支撑「上千个 MCP 服务器而上下文膨胀很小」，并设为 2.0 所有 MCP 连接的默认模式。
- 已内部实现 80+ 插件覆盖 2.0 大部分功能；TUI 插件从实验转稳定，支持会话中热重载插件。
- **破坏性变更**：1.0 插件在 2.0 无法运行，基于旧 Server API 的集成需重写。升级需手动 `opencode upgrade --major`（10/11 起更新不再自动安装）。

**为什么值得关注**

这是今年 MCP 生态里最实质的一次「上下文经济学」改良。当前 agent 接 MCP 的瓶颈不在能力而在上下文：几十个工具定义就能吃掉大半窗口。Code Mode 把「工具描述」换成「一段可读的 TypeScript 类型签名 + 解释器」，本质是把 tool-calling 降级成 code-calling——和 Anthropic 早前推的 code execution with MCP 是同一条思路，但 OpenCode 把它做成了默认路径且有开源实现。对已经在用 MCP 的团队，这是「能不能扩展到几十上百个数据源」的分水岭。风险是生态割裂：1.0 插件全废，第三方集成的迁移成本会在未来两三个月集中爆发。

## 2. Cursor 600 亿美元交易首次并表：AI 编程入口被算力方收编

**事件**（SpaceX 于 10 月 20 日盘后发布上市后第二份财报，10 月 21 日持续发酵）

- 交易于 **2026 年 8 月 14 日**完成交割，**隐含股权估值 600 亿美元**，GAAP 购买对价 425 亿美元；其中约 230 亿（近四成股权价值）被归为**核心人才保留与未归属股权置换**，将在约 3 年内确认为股权激励费用。
- 交割日至 9 月 30 日，Cursor 为 SpaceX 贡献收入 **6.08 亿美元**。
- 新模型 **Composer 3** 据报在 **10 万+ GPU** 上、基于 Colossus 超算训练；联合训练的模型将同时进入 Cursor 与 Grok Build。
- 整合动作：Grok + Grok Bot + Cursor + X Premium 打包进同一订阅；含 Cursor 在内，Grok Enterprise 年收入运行率超 100 万美元的客户数环比 +50%。
- 大盘面：SpaceX Q3 营收 145.75 亿美元（+161%），AI（SI）分部 75.6 亿（+830%）首次超过星链成为最大收入来源；单季资本开支 195.93 亿，其中 164.44 亿投向 AI。

**为什么值得关注**

600 亿美元买一个 IDE，账面上并不难算——Cursor 三个月贡献 6 亿美元收入，年化约 24 亿，对应 25 倍 PS，在当下并不算离谱；真正稀缺的是**「模型 + 算力 + 分发入口」的垂直整合**：谁掌握写代码的那块界面，谁就掌握最高价值的 token 消耗场景。对开发者更实际的影响有三点：其一，Composer 3 走「联合训练、双端分发」，意味着 Cursor 的模型路线将越来越绑定 Grok 系而非多模型中立；其二，打包订阅会加速「一个订阅覆盖聊天+agent+IDE」的整合，独立 IDE 的定价空间被压缩；其三，230 亿美元的人才保留费用说明买方认定价值在人而不在产品——这也解释了为什么这类收购之后，产品迭代节奏往往会先慢后快。**建议动作**：把「单一 AI IDE 锁定风险」写进技术选型评审，尤其是团队级 seat 采购。

## 3. 智元 AI WAVE 开跑：七天七项全栈发布，今天先交「具身推理」数据集

**事件**（10 月 22 日起，作为 2026 智元创新日的前奏）

- **10/22（今日）**：AGIBOT WORLD 2026 第四期 **「具身推理」（Physical Reasoning）数据集**，首批 **150 小时真机数据**专攻决策——目标是让机器人从「学会操作」走到「自主完成任务」。
- 后续排期：10/23 Genie Studio 2.0（一站式作业平台）；10/26 G2 Max（安规级重载工业机器人，重载 + 亚毫米精度）；10/27 Genie Master（宣称在真实业务场景首次实现 **Physical RSI**，具身递归自我改进）；10/28 Genie Sim 升级自研物理引擎，宣称柔性仿真下**真机-仿真一致性 >95%**；10/29 基座大模型；10/30 群体经验学习 CEL（首个百台级真机集群原型验证）。
- **验收方式**：11 月 2–3 日，6 台 G2 进入便利店，24 小时不间断直播，走完午高峰、晚高峰、深夜值班、早餐准备四个班次，作为「转正考核」。

**为什么值得关注**

智元这次的叙事很清晰：不辩论「通用大模型变强后具身还有没有价值」，而是把数据、工具、本体、系统、模型五环一起摊开，用「便利店 24 小时直播」当公开验收。这种做法比发布会演示可信度高一个量级——连续作业暴露的是异常处理、长时稳定性、能耗与人工介入率，而这恰是当前 85% 出货流向表演/科研/导览的行业短板。**最该盯的两个点**：一是 10/28 宣称的 >95% 真机-仿真一致性（这是「仿真训练能否省掉真机采数」的核心前提，若能复现，数据成本结构会变）；二是 10/27 的 Physical RSI 是否有可验证的自我改进闭环，还是只是「自动调参」换了说法。

## 4. 无界动力开源 MWA-Phoenix：端侧 7B 世界模型基座，六榜同时登顶

**事件**（10 月 22 日发布并开源）

- 端侧 **7B 参数、完整预训练**的隐空间世界模型基座，同时登顶 **LIBERO-Plus / LIBERO-Pro / RoboCasa GR1 / Bench2Dex / RoboTwin 2.0 / RoboDojo 真机榜**六项评测，覆盖环境扰动鲁棒性、任务变化泛化、复杂物体操作、跨本体迁移与真机执行。
- 技术路线：**隐空间世界模型 + 强化学习**；配套 **Phoenix-ILA** 把「运动」与「接触」共同纳入动作学习；同时发布交互式仿真世界模型 **Phoenix-PhysCanvas**，模型部署前在云端仿真中自我进化。
- 三个「不做」作为卖点：不做测试数据复刻、不使用深度信息传感器、不依赖任何 Agent 编排。
- 已放出技术报告与 GitHub 代码。

**为什么值得关注**

这是今天技术含量最高的一条。「六榜同时登顶 + 从仿真延伸到真机」比单榜 SOTA 有意义得多——单个 benchmark 容易被过拟合，而跨环境扰动、跨本体、真机执行同时领先，说明泛化不是靠数据复刻刷出来的。**不用深度传感器**这一点尤其值得注意：它把感知成本从「RGB-D + 标定」压到纯 RGB，直接决定 BOM 和部署速度。7B 端侧可跑，意味着不依赖云端推理链路，对时延和安全关键场景是硬需求。**保留意见**：六榜里多数仍是仿真基准，RoboDojo 真机榜的具体任务分布与样本量需要看技术报告再判断，「不依赖 Agent」在长程任务上是否成立也要看后续第三方复现。

## 5. 首批 6 项人形机器人国标落地，同期一级市场融资断崖

**事件**（10 月 19–20 日）

- 市场监管总局批准发布**首批 6 项人形机器人国家标准**：5 项《人形机器人技术要求》系列（本体构成、系统架构、环境感知、智能决策等关键功能与性能指标）+ 1 项《人形机器人仿真测试平台技术规范》，**2027 年 4 月 1 日起实施**。王兴兴为《技术要求》起草人之一，直言「各家产品在尺寸、性能、电池电压、通信与使用接口上差别都非常大」。
- 同期商务部等 9 部门发布《关于加快推进科技兴商的意见》，首次从消费端为机器人打开需求空间。
- **资本面反向**：7–9 月具身智能单月融资均在 70 起以上（8 月 91 起、313 亿元），**10 月前半月仅 19 起、49 亿元**，折年化不足 8 月三分之一；9 月证监会窗口指导提高人形机器人上市审核门槛（重点核查收入真实性、亏损收窄路径、实质性原创创新）；一家关节减速器公司 IPO 被终止，智元 7 月启动港股筹备、10 月完成新融资但年内已无缘挂牌。
- 产业端仍在上行：上半年整机产品突破 400 款、产量超 4 万台，全年预计破 10 万台，全国已建成 70+ 训练场；但全球约 1.8 万台出货中 **85% 流向表演、科研、导览**，中国厂商上半年出货超 1.9 万台、占全球近八成。

**为什么值得关注**

标准出台的真实作用是**把「看起来很聪明」变成「可复现地稳定可靠」**——尤其仿真测试平台规范，第一次给了行业统一的评测标尺。结合昨天信通院报告里「出货≠上岗」的结论，这两件事指向同一个判断：2026 年下半年的分水岭不是产能（4 万→10 万台靠建厂就能解决），而是**需求侧能否证明稳定承担日常工作**。而一级市场从 313 亿/月掉到 49 亿/半月，说明资本已经开始按这个标准重新定价——出口收窄会先杀死「只有演示、没有收入结构」的公司。对从业者来说，未来 6 个月的融资叙事必须从「本体参数」换成「单台日均有效作业时长 + 人工介入率」。

## 今日一句话判断

AI coding 的竞争焦点已经从「谁的模型分高」转到「谁掌握入口与上下文成本」——Cursor 被算力方收编、OpenCode 用 Code Mode 把 MCP 的成本结构重做，都是同一个方向；具身智能则在同一天收到两份方向相反的信号：技术侧（无界动力、智元）在拿真机一致性说话，资本侧（一级市场断崖、上市门槛抬高）开始按「能不能稳定上岗」重新定价。**未来 6 个月，两个赛道都只看一个指标：单位成本下的持续有效产出。**
