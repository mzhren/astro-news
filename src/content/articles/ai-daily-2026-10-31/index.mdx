## 一、Google 关停 Jules，Coding Agent 产品线并入 Antigravity

**事件内容**

Google 10/29 宣布，异步编码 agent **Jules 将于 2026 年 12 月 31 日停止服务**，团队能力并入 agent-first 开发平台 Antigravity：

| 维度 | 说明 |
|---|---|
| 时间线 | 10/29 宣布；**11/11 后转只读**；12/31 关停 |
| 导出范围 | 设置、环境变量、定时任务、关联仓库、memories、setup 脚本、完整会话历史（含 prompt/计划/日志/补丁），可导出到本地 |
| 代码归属 | 代码、分支、PR 均在 GitHub，不受关停影响 |
| 衔接动作 | 同日 Antigravity 上线 **Plugin Marketplace**：一个插件打包 skills + MCP server + rules + hooks + 自定义 agent，应用内与 CLI 均可一键安装 |
| 首发伙伴 | Atlassian、Figma、Stripe、Canva、CrowdStrike、Databricks、Datadog、Dropbox 等 |
| 未定事项 | Jules 式后台异步任务进入 Antigravity 的时间、memories 自动迁移方案均未公布 |

**值得关注的原因**

1. **这是主流大厂第一次明确"做减法"关停一条 coding agent 产品线。** Jules 是 2024 年 12 月上线的头部异步 agent，定位是"干开发者不想干的活"。关停理由是官方原话级别的信号：把分散的 agentic coding 投入统一到一处。对照 10-29 期 Android Studio Rabbit 2 的 BYOA 化，Google 的编码 agent 矩阵正在从"多点实验"收敛为"Antigravity 单一入口"。
2. **Plugin Marketplace 的打包方式值得抄。** skills + MCP + rules + hooks + 自定义 agent 捆绑成一键安装单元，等于给"团队级 agent 配置"一个分发格式——这比单个 MCP server 的分发粒度更接近真实使用方式。对企业用户，Jules 的迁移窗口（11/11 只读）是硬 deadline：定时任务和 memories 不迁移就没了。
3. **异步后台任务是 Antigravity 的明确补课方向。** IDE 内多 agent 监控（Antigravity 强项）与云端后台排队干活（Jules 强项）合并后，"一个开发者管一队 agent"的形态基本定型。竞品对照：OpenAI Codex 的 autopilot、Anthropic Claude Code 的 headless 模式都在抢同一个生态位，Q4 会有一轮同质化竞速。

## 二、微软开源 TokenEconomizer：给 Coding Agent 装"成本刹车"，SWE-Bench 降本 18.4%–30.9%

**事件内容**

微软研究院 × UC Berkeley 发布开源插件 **TokenEconomizer**（Apache 2.0），以"外挂监督者"方式为 coding agent 控制成本——不改模型权重、不改 agent 核心代码，兼容 Claude Code、Codex、GitHub Copilot CLI、Pi。它在仓库内从历史任务学习，动态优化后续任务的开销：

| 维度 | 数据 |
|---|---|
| 评测范围 | SWE-Bench **277 个任务**、5 种 agent×模型组合、30 个仓库场景 |
| 降本区间 | **18.4%**（Copilot CLI + Sonnet 5）至 **30.9%**（Claude Code + Opus 4.8）；30 个场景全部省钱 |
| 质量影响 | 5 个设置中 4 个 Pass@1 反而提升；个别场景（Opus 4.8）降 1.0 分 |
| 横向验证 | Web-Bench 降 16.0%–21.2%、CredData 16.5%–19.6%、ReposVul 6.4%–9.3% |
| 三大机制 | **Micro-skills**（LLM 从轨迹蒸馏事实注入 prompt，错误事实快速退役）· **工具裁剪**（连续 3 个任务未用的工具屏蔽，每 5 任务全量重审）· **失败循环熔断**（按成功 run 的 P90 设 turn 预算，LLM judge 0.7 置信判定卡死后先纠偏一次、再终止） |
| 归因 | 工具裁剪贡献 13.2%–17.7%，micro-skills 11.8%–14.3%，熔断 5.4%–7.1% |

诊断出的三大浪费源头（比解法本身更有信息量）：前 5 个任务之后约 **30% 的工具调用在重复早前动作**；单轮加载 23 个工具 schema 实际只用 3 个（占 98% 调用）；占任务数 17% 的失败执行烧掉了 **32% 的总 token**。

**值得关注的原因**

1. **Agent 的成本问题第一次被系统量化，而不是靠体感。** "重复发现""工具 schema 膨胀""失败循环"这三条，几乎每个跑过 Claude Code/Codex 的团队都在账单里见过，但 30% 重复调用、32% token 烧在失败上这个比例值得写进内部成本模型。对照 10-30 期 Fusion 的"分级调用省一半"，方向一致但手段不同：Fusion 靠编排层选模型，这个靠执行层砍无效动作——两者可以叠加。
2. **"每仓库学习"是关键设计。** 通用省钱策略（RTK、Serena、Aider RepoMap）效果不稳定，TokenEconomizer 学的是本仓库的测试命令、常用工具、正常任务长度分布，所以能做成默认开启的工具裁剪+熔断。这暗示 agent 基础设施的下个竞争点是**仓库级持久记忆**，而不是更大的上下文窗口。
3. **实用建议：** Django + Claude Code 的示例里，第 2 个任务的首轮 prompt token 从 43,351 降到 16,295——对按 token 计费的 API 用户是直接账单差异。默认开裁剪+熔断、micro-skills 视情况开（它有额外模型调用成本），学习数据全部本地存储，合规风险低。

## 三、YC × Olam Labs：50 个 Agent 同吃一个 Minecraft 世界，多 agent 协作被当成对齐问题研究

**事件内容**

Y Combinator 联合多 agent 环境公司 Olam Labs 发布一组**大规模 coding agent 群体行为实验**（10/30），三套设置、结果已汇总公开：

| 设置 | 内容 |
|---|---|
| **Civ50** | 50 个 GPT-6.1 Sol agent 共处一个 Minecraft 生存世界 3 小时；配 agent 目录、共享沙箱、点对点私信 |
| **Bed Wars** | 10 个 Claude Opus 5.5 vs 10 个 GPT-6.1 Sol，9 局 45 分钟对抗赛，指令只有"赢" |
| **Mindustry** | GPT-6.1 Sol（跑在 Codex 里）vs Claude Opus 5.5（跑在 Claude Code 里），同一游戏 API、零策略提示 |
| 开源 | Minecraft harness 核心循环基于 Pi + Mineflayer 工具，已发布：github.com/yc-software/minecraft-agent-harness |
| 研究框架 | 把群体行为定义为对齐问题：**"agent 们共同做出、但没有任何单个 agent 被告知要做的行为"**；每次失败被转化为多 agent 团队的检查项 |

**值得关注的原因**

1. **这组实验补上了"多 agent 并发"缺失的一环：群体涌现行为。** 今年的多 agent 实践（swarm、Critique 模式、多 agent 评审）默认假设"n 个好 agent = 更好的团队"，但对"没有谁被指使、却集体做出的行为"几乎没有观测手段。50 个 agent 在共享环境里 3 小时的涌现数据，是目前少有的公开样本——对正在把 agent 编制扩到两位数的团队，这是直接可引用的对齐检查清单来源。
2. **游戏是最便宜的多 agent 压力测试场。** 对抗赛天然提供评分函数，沙盒天然提供开放交互，成本远低于真实仓库。企业侧可以低成本复用：开源 harness 可直接跑，或用相同思路（共享环境 + agent 目录 + 私信通道）在内部 staging 环境复刻，观察 agent 群体在无监督时的行为边界。
3. **同为 GPT-6.1 系（Terra 之后是 Sol），同一模型不同 harness 的表现差异本身就是数据点。** Mindustry 里 Codex vs Claude Code 各带一个 GPT-6.1 Sol/Opus 5.5，harness 差异直接决定团队表现——再次验证 10-28 期 Terra 系统卡的结论方向：**harness 层的安全与行为设计，权重一样重要**。

## 四、前 Meta 首席工程负责人创业公司智澄 AI 获数亿元融资：押注"世界模型"路线

**事件内容**

杭州具身智能公司**智澄 AI** 10/30 宣布完成**数亿元融资**，由杭州资本、富浙科技、财通资本、岭澜资本联合投资，重点投向具身智能与世界模型：

| 维度 | 说明 |
|---|---|
| 创始团队 | 创始人兼 CEO 胡鲁辉，曾任 **Meta 首席工程负责人**，先后任职微软、亚马逊、华为美研 |
| 技术定位 | 自称国内首家自研世界模型企业；两大能力方向：**world memory（模型世界记忆）**与**物理智能自进化** |
| 已开源 | 今年 5 月开源**澄灵物理世界模型 0.1**——自称全球首个基于 **JEPA 架构**、专为机器人设计的端到端物理世界模型，直接从视觉/本体觉等原始感官输入学习物理规律 |
| 产品线 | **XR1** 轮式双臂工业机器人（双臂协同负载 50kg，垂直作业范围约 2m，支持自主充电）；**TR6** 通用人形（176cm/62kg/续航 8h/最高 2m/s） |
| 商业化 | XR1 已进入**蔚来汽车工厂产线**，面向大众汽车开启场景测试；与国家电网合作第三代全天候安防巡检机器人 |
| 资本节奏 | 今年 6 月完成 A 轮（金额未公布），历史股东含梅花创投、芯能资本等 |

**值得关注的原因**

1. **JEPA 路线在机器人侧第一次有了中国参赛者的开源实现。** JEPA（LeCun 主张的世界模型架构）一直停留在论文和 Meta 内部，智澄把"专为机器人的端到端 JEPA"开源到 0.1 版，等于给"端到端 VLA"之外的第二条技术路线开了个可复现的起点——值得直接下载测一测，与 π0.5、GO-3 系做同任务对比。
2. **融资结构是"地方国资 + 产业资本"组合**（杭州资本、富浙科技），且创始人带 Meta 级工程背景。对照本期第五条的融资上游化趋势：地方政府在押的已经不是整机品牌，而是"世界模型/大脑"这类卡位上游的标的。
3. **验证点记在账上：** XR1 进蔚来产线是真实产线部署而非实验室，下一期值得跟踪的是量产规模与换线重调周期——这正是 10-30 期给美罗U 定的"复制/换机型重调"观察口径，可跨公司横向比。

## 五、具身智能进入"交卷期"：10 月融资笔数腰斩，钱集体流向整机身后

**事件内容**

10 月最后一周，具身智能赛道呈现"资本冷、产业热"的割裂，两条数据线同时出现：

**资金端：**
- IT 桔子：10 月融资 **33 起 / 101.05 亿元**，对比 9 月 60 起 / 110.28 亿元，**笔数近乎腰斩**；Q3 融资 333.35 亿元，低于上半年季度均值的 467.5 亿
- 上半年国内具身赛道融资 935 亿元（同比约 5 倍）；艾媒口径下**"具身大脑"吸走 595.44 亿元、占 54.5%**，核心硬件仅占 10.4%
- 近日单日四笔早期融资全部指向整机身后：**模感科技**（亿元级天使+，全身多模态触觉）、**乙太科技**（超亿元，物理空间引擎/空间智能）、**伊塔动力**（超亿元种子，操作平台与动力系统）、美国 **Dream Labs**（$9000 万种子，具身大脑）
- 零部件侧：雷赛智能上半年营收 12.47 亿（+39.9%）、净利 1.94 亿（+62.8%），1–8 月灵巧手销量翻倍——**整机在亏，零件在满产**

**产业端：**
- 工信部：上半年国内人形整机超 400 款、产量超 4 万台，**全年预计突破 10 万台**
- 智元创新日披露**上半年收入接近 20 亿元**；彭志辉定调："万台下线只是制造业的胜利，万台上岗才是物理 AI 的胜利"
- Counterpoint：上半年全球人形 **六成以上卖给舞台和实验室**；生产作业用途仅 0.12 万台、收入 0.78 亿美元（弗若斯特沙利文）
- 相当比例设备月均开机不足 10 天，表演租赁日租金跌去八到九成

**值得关注的原因**

1. **行业估值逻辑正在切换：从"能造"到"上岗"。** 供给端数字越漂亮（10 万台），"卖了但没在干活"的结构性问题越刺眼——六成进舞台实验室、月开机不足 10 天，说明大量出货是科研/展演场景的一次性采购，不构成复购飞轮。对投资人，2027 年的关键指标不再是出货量，而是**开机时长与单台产出**（智元 Worken 那套口径，10-30 期已立论，此处只确认它正在成为行业共同语言）。
2. **"上游化"是资金用脚投票的结果。** 整机毛利被场景不确定性和价格战压制，而触觉、动力、数据引擎、大脑这些环节无论哪家整机赢都要买——同日四笔上游融资不是巧合，是资本在整机格局明朗前买"必经之路"。对二级市场同样适用：看具身链，零部件（雷赛这类已盈利满产的）账本比整机干净得多。
3. **智元近 20 亿半年收入是本期新增的重要分母。** 10-29 期已报宇树前三季 18.17 亿，智元半年近 20 亿说明头部两家体量已在同一量级；结合工信部 10 万台产量预期，"头部兑现 + 腰部出清"的淘汰赛格局开始显形。上交所终止环动科技科创板审核（10-30 报道）是同一信号的资本市场侧注脚。
