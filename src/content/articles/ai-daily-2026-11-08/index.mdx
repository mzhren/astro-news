**主题：悬念集中兑现日——安全专用模型开放、权重开源落进生态、苹果进场做人形大脑**

## 主条目

### 1. Thinking Machines 发布 Inkling 2 Small：594B/17B，承诺下周 Apache 2.0 开权重

- Mira Murati 创立的 Thinking Machines 推出 **Inkling 2 Small**：594B 总参 / 17B 激活的稀疏 MoE，支持 **1M token 上下文**与图像输入；**SWE-Bench Pro v2 Hard 86.3%**，官方将其与 DeepSeek V4.1 Flash、GLM-5.3-Flash 并列在"开放权重性能 + 高级智能体工具调用"这条基准线上。
- 目前经 **Tinker** 提供 API 推理与微调（并演示了对 Qwen3.5-4B 的自动化微调）；完成含对抗测试的外部安全评估后，**计划下周以 Apache 2.0 开放权重**。
- **为什么值得关注**：本周开源节奏密集（Hy4、ERNIE 5.5 Flash Base、Kimi K3.1 Pro 权重、Mistral Le Chonk），Inkling 2 Small 是其中唯一一家"非大厂、纯模型公司"的近 600B 级开放承诺——若兑现，开源线在 coding 基准上对闭源中端模型的挤压将进一步加剧；且它把"模型 + 微调基础设施"打包卖，与 OpenAI/Anthropic 的路线明显不同。

### 2. 苹果披露人形机器人自主控制系统 HALO：千问驱动，宇树 G1 上 91% 单项成功率

- 苹果研究团队 11/4 在 arXiv 提交论文《Perceptive Humanoid Motion from Simulation》，披露人形机器人自主控制系统 **HALO**，并**开源了数据生成、训练与部署全部代码**。系统部署在宇树 G1 上验证：6 个未预先建图的真实房间 360 次单项任务**平均成功率 91%**；3 种组合任务平均 70%（最难"俯身过障—走向目标—推箱子"50%）。
- 三层架构：顶层 VLM 任务编排（**千问 Qwen3.6-35B-A3B，跑在 G1 背包里的 Mac mini M4 Pro 64GB 上，本地离线推理**）；中层动作生成（Qwen3.5-2B 冻结编码器 + DiT 解码器，规划未来 5 秒全身动作，每秒重规划 3 次）；底层 RL 动作跟踪器（50Hz 关节控制）。训练成本不高：250 张 H100×48h 合成主数据 + 64 张 B200 模仿学习。
- 团队自认短板：纯视觉、难以感知接触，遮挡场景接触类任务下降，触觉是下一步。
- **为什么值得关注**：苹果首次系统性公开人形机器人"大脑"工作，三个信号：①不训专用大模型，直接用**千问开源模型**做编排+生成，印证"开放权重已是机器人栈默认件"；②分层"编排/生成/跟踪"架构与国内"大脑-小脑"分层路线殊途同归，且给出了可信的真机成功率口径；③苹果 + 宇树本体 + Mac mini 算力包的组合，是"本体开放找大脑"（宇树全球找大脑）迄今最高规格的响应者。

### 3. 具身资本两大落点：DeepSeek 入股两家机器人公司 + Skild AI 融 14 亿美元

- **DeepSeek 确认战略投资具身智能**：入股 **Winverse**（通用机器人决策大脑）与**理格万物**（工业场景具身应用），推动"大模型 + 具身决策"协同——从技术输出升级为"资本 + 技术"双布局。
- 美国机器人基础模型公司 **Skild AI 拿下 14 亿美元**融资，专项攻坚机器人基础模型。
- **为什么值得关注**：这是 10/30 期"具身公司 VC 化"趋势的具体标的兑现。DeepSeek 一直被视为纯模型玩家，此番下场使"模算一体"进一步走向"模机一体"——国内大模型厂（DeepSeek、字节 Seed 招机器人人才、腾讯 Hy4）与机器人栈的融合在加速；对照海外 Skild/PI（200 亿美元估值）的融资烈度，"机器人基础模型"已成为大模型之后最明确的资本焦点。

### 4. GPT-6 Cyber 开放节奏兑现：面向获批用户开放 + 高风险专用模型的治理模板

- 11/6 期已报过 GPT-6 Cyber 的能力数据（ExploitGym 48.5%、Linux 内核 948 个真实崩溃等），按既定去重原则只报**开放节奏**增量：模型现已正式面向审核批准的 **Daybreak Red 用户**开放，配套**沙箱隔离、滥用行为监测、人工复核监督**多层防护；同期 Images 2.6 生成速度 +50%。
- **为什么值得关注**：这是"高危能力专用模型"第一个从"已训成、未开放"走到"受限开放"的完整样本——审批名单制 + 沙箱 + 人工复核的治理模板，大概率会被后续网络安全/生物类专用模型（Google、Anthropic 同类产品）参照。

### 5. 悬念打包兑现：Kimi Hosted Agents 上线 + Hy4 发布即开源 + 国产三模型进驻英伟达 NIM

- **Kimi**：K3.1 Pro 同步推出 **Hosted Agents 托管服务**（智能体运行框架云端化，支持长程任务与多智能体协作）——此前连续跟踪的"权重落地但无托管"缺口补上；权重并已上架**英伟达 NIM 网页端免费体验**。
- **腾讯混元 Hy4**：发布即开源（新增视觉理解与电脑操作能力，权重近期开放）——11/5 期跟踪的"Hy4 权重开源"兑现。
- **英伟达 NIM**：DeepSeek-V4.1-Flash 与 GLM-5.3-Flash 的 API 免费开放（无需绑卡），加上 Kimi，**三个国产开源模型同日获国际主流部署平台官方支持**。
- **为什么值得关注**：上周立的几个"待跟踪"节点在 24 小时内集中兑现，且指向同一件事：**开源权重 → 托管服务 → 国际生态入驻**的完整链路已经跑通。中国开源模型的质量认可（NIM 官方支持）与商业闭环（Kimi 托管）同时落地，开源竞争从"放权重"进入"拼生态位"阶段。

## 附注

- **Anthropic 发布跨会话智能体记忆与 "dreaming" 机制研究**（基于 Claude 3.7 Sonnet / Opus 5）——长期会话状态管理是长程自主智能体可靠性的核心工程难题，值得跟进是否进产品。
- **METR 独立评估**：Anthropic 内部模型开发速度约为 2024-2025 的 2 倍，其中 **80% 由研发环节使用 AI 驱动**——但报道同时指出 Anthropic 删减了大部分佐证证据，数字待核。
- **英伟达开源 Cosmos 3 世界模型权重**（11/5 上 Hugging Face，驾驶 + 机器人场景；最小配置单张工作站 GPU 可跑）——世界模型作为机器人策略训练的仿真底座，与本周具身主线互补。
- **通用具身大脑产业创新联合体启动**（进博会配套，眸深智能战略发布会）：复旦未来信息创新学院、国家地方共建人形机器人创新中心、宇树、优必选等 **42 家**企业与机构加入。
- **Perplexity 推出 Teammates**：常驻协作智能体，可承接任务、相互协作、在 Slack 里给同事发消息；Max 订阅（约 $200/月）网页版可用——"多智能体同事"从概念走到订阅产品，与本周 Amp Spaces 一脉。
- **字节扣子企业版分阶段下线**：11/30 起停止新客购买与新团队创建，智能体能力并入其他企业服务——头部厂商收缩通用 agent 平台线。
- **OpenAI 110 亿美元融资首批到账**（估值 1.25 万亿，原拟 300 亿/1.4 万亿后下调；阿联酋联合体最大出资方、软银缩减），并**秘密向 SEC 递交 IPO 招股书**。
- **DeepMind AI agent 协助发现 1024-bit RSA 两个弱点**：签名伪造理论加速约 1600 倍、批量分解单密钥成本降约 30 倍——注意均为**理论值**，实测部分是复现已被破解的密钥（CPU 时间省 3.5 倍）；2048-bit 不受影响。
- **Gemini Omni 1.2 Flash GA**：视频生成 10→15 秒，720p 降价 30% 至约 $0.07/秒，登顶 Arena 图生视频榜。
- 中博会具身智能展：乐聚全球首款 5G-A 人形机器人 Kuavo（1.73m/7km/h）、逐际动力全尺寸交互机器人 Luna（27 DOF）。
