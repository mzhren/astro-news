**主题：11/09 一天里三条线同时交数字——Coding 给"长程编排"标了价，具身把"人类视频能换多少技能"画成了曲线，落地侧改按营业厅和"每任务美元"算账**

---

## 主条目

### 1. Claude Fable 5.2 / Mythos 5.2 发布：coding 旗舰降价 20%，并用 1000 个 subagent 交了一份 8 天的作业

- **11/9 发布**，同一底座模型两个配置：Fable 5.2 全量开放，Mythos 5.2 只对 Cyber / Life Sciences 验证计划内的机构开放（同时驱动企业版 Claude Security）。编号仍叫 5.2 而非 5.5（Opus/Sonnet/Haiku 已到 5.5），Anthropic 明确表示**多数 coding 与知识任务仍建议从 Opus 5.5 起步**，Fable 用于"最棘手的技术难题"。
- **价格与速度**：$8 / $40 每百万 token（原 $10 / $50，降 20%），可选 fast mode $16 / $80、生成速度最多 **2.5×**；常规输出比 5.1 快最多 **30%**；平台文档标注 1M 上下文、128K 最大输出、知识截止 2026 年 6 月。
- **自测基准**：FrontierCode 2.0 **49.1%**（Fable 5.1 32.4%、Opus 5.5 45.5%、GPT-6 Astra 42.8%）；FrontierSWE v2 **69.9%**（Astra 65.5%、Opus 62.3%）；Terminal-Bench-Science **74.6%**（5.1 为 52.6%）。成本口径更值得看：**High effort 的 Fable 约等于 Max effort 的 Opus 5.5，单任务成本约一半**，Medium 已成为 Claude Code 的默认 effort。并非全胜——AutomationBench 51.4% 输给 Gemini 4 Carbon 的 53.9%，AA-Briefcase 的 Elo 也仍略低于 Opus。
- **长程证据（本期最值得看的部分）**：①**1000+ subagent 连跑 8 天**，从空文件夹做出可在笔记本上启动的原型 OS——自研内核、磁盘/键盘/网络驱动、持久化存储、窗口、登录界面、安装器；②早期版 Fable 把一套生产服务从 **Python 迁到 Rust**，启动快约 **26×**；③**1000 个 agent 用 30 小时**在 Lean 里完成费马大定理形式化（此前研究版 Claude + 专用 harness 用了 11 天），action token 为原来 1/3、证明长度 1/7；同配置下 Opus 5.5 跑 18 小时只完成约 26%。
- **训练期做了减法**：Anthropic 承认在训练时**刻意限制了最可能直接加速 AI 研发的两块能力——加速器 kernel 优化、LLM 架构改进**，压到约 Opus 5.5 水平；声明不影响 agentic coding、硬件开发、可解释性研究；不在推理期做手脚；对少数非标准加速器 kernel 开发**透明回退到 Opus 5**。另有：内部代码库合并变更 **>90% 由 Claude 撰写**；误拦比 5.1 少约 55%；抗蒸馏让蒸馏者拿到的数据少 90–99%。
- **为什么值得关注**：coding 的竞争指标这一天被改写了——不再是单点跑分，而是**"每任务美元 × 长程保持率"**。"8 天 1000 agent 做出一个 OS"是全行业第一次给出"编排规模 × 时长"的可核对样本（虽然仍是自家 harness、自家评测）；而"训练期就把两块能力按住"是治理上第一次公开的**能力负向设计**，代价是把"能不能加速 AI 研发"从一句承诺变成了一个需要被独立验证的声明。顺带注意 RoboDojo Sim：Fable 5.2 拿到 **64.9%**（Opus 39.4%、Astra 29.8%、5.1 为 27.6%）——通用模型在机器人仿真基准上的水位，已经不能忽略。

### 2. 英伟达在 CoRL 开源 GR00T 2：5 次演示 = 95%，把"人类视频值多少技能"画成了曲线

- 奥斯汀时间 11/9 下午（北京时间今晨）由 **Jim Fan** 在 keynote 上发布，正是上期跟踪的悬念。**20 亿参数**，底座 Cosmos-Predict2.5-2B，定位不是 VLA 而是 **WAM（world-action model）**：单个 diffusion transformer **同时去噪"未来画面"和"动作 chunk"**，先想象场景会怎么变，再给出把它实现的动作。一个 checkpoint 覆盖平行夹爪、灵巧手、人形，每个本体只换一个小 head。
- **数据配方**：**402,730 小时**第一视角人类视频 + **10,184 小时**手持 UMI 夹爪演示（2,897 个任务）+ 仅 **23,500 小时**真机遥操作。其中 10 万小时以 **Human-1M-100K** 名义上 Hugging Face，**CC BY 4.0、允许商用**，采集硬件设计也开源。
- **少样本曲线**：50 个目标机器人训练数据里从未出现的任务，**零样本平均 40%**；每任务给 1 次演示升到 **71%**；5 次演示（不到 3 分钟真机数据）到 **95%**，其中 37/50 个任务每次都成功。每次适配是**单张 RTX 5090 上约 30 分钟 LoRA**。
- **关键消融**：人类视频占比从 0 → 1% → 10% → 100%，72 个 Dexter 任务的**真机**任务进度从 **50% → 70%**。这一格比任何总分都重要。
- **跨本体**：只给戴手套的人类化学实验演示、零遥操作，双臂机器人 **65%** 完成"漏斗套滤纸并润湿"；只给 UMI 夹爪演示，YAM 机械臂 **60%** 独立装完玩具卡车（任务最长 4 分钟）。硬指标上：传送带分拣 **86%**（GR00T 1.7 为 28%、π0.5 为 0%）；双 22-DoF Sharpa 手插装 GB300 内存条 **85%**、装玩具卡车 65%；真机 RL 把三个接触密集的插入任务从 40–76%（SFT 后）推到 **88–96%**。
- **接口是 MCP**：推理模型当 System2 拆任务、查进度、写代码，GR00T 2 通过 **MCP server 被当作工具调用**去干手上的活。桌面上倒一堆零件，这对组合组装玩具飞机 **98/100**、拖拉机 97/100、Hot Wheels 97/100。
- **两处必须打的折**：白皮书自认评测任务是"从 5 个 episode 就能到 80% 以上"的任务里挑出来的；社媒上流传的"40 个任务零样本成功"是把"40/50 至少成功一次"和"平均成功率 40%"混成了一句，论文原文是后者。
- **生态与澄清**：Foxconn（用于 AI 服务器产线）、Siemens、Nexuni（洗衣）在测，均未说进量产；LG 2027 年人形用的是前代 GR00T；**代码 12 月开放**；GR00T 2 Turbo（2B）已在宇树 G1 上跑。同日同框的 **Isaac Lab 3.0 是 10/20 已 GA，不是今天新发**，今天新的是 Isaac Lab-Arena 与 DexBench v1.0（与韩国 RLWRLD 合作，15 个任务）。
- **为什么值得关注**：10/28 期我们报过"全球真机数据约 100 万小时、缺口百倍"。GR00T 2 第一次把这道缺口换算成了一个**斜率**：人类视频占比 0→100%，真机进度 50→70。这意味着采集生意的估值逻辑会被改写——决定单价的不再只是"小时数"，而是"这段视频能不能被这个模型换算成真机技能"。另一层更结构性的变化：**MCP 当接口**，等于具身正式接进了 agent 的工具协议栈；同一个 harness 里，coding agent 调代码工具，也可以调一只机械手。

### 3. Meta 放出 Muse Ember：$0.10 的"执行层"，把 coding agent 的账单结构摊开了

- **11/9 发布**，Muse 家族第四款、最小最便宜：**$0.10 / $0.50** 每百万 token，缓存输入 $0.004，model id `muse-ember-1.0`，走 Responses API。**1M 上下文 / 最多 512K 输出**，原生吃文本、图像、音频、视频。
- 定位非常明确——agent 里**重复一整天的小步骤**：工具调用、编码子任务、路由、抽取、长文档解析。官方口径是"Wonder 规划、Spark 做 coding 与 agent、Ember 扛量"。
- **成本对比**：Artificial Analysis 综合指数 36（Spark 1.3 为 37），但**每个 AA 任务 $0.14 vs $2.39**；Meta 称以约 1/3 成本打到 Claude Haiku 5.5 的最好成绩，并在所有 reasoning 档位胜过 GPT-6 Luna。
- **自测（max reasoning）**：AutomationBench-AA **37.8%**（Haiku 5.5 13.9%、Luna 20.2%）；Agents' Last Exam Linux 子集 61.6%（57.0% / 57.1%）；Terminal-Bench 4.0 **40.9%**（39.2% / 16.4%）；Coding Agent Index-AA **46**（37 / 31）；OSWorld 2.1 69.5%（68.9% / 50.5%）。
- **但有一格是反的**：**FrontierCode 2.0-AA 只有 27.2%，输给 Haiku 5.5 的 34.9%**。这个基准测的是"改动会不会被开源 maintainer 合并"，是整张表里最难糊弄的一项。
- 早期伙伴给的数字更实用：Cloudflare CTO 称尾部延迟快最多 **30%**、跨多仓库排查好用；You.com 报 **P95 2.2 秒**、输出 token 少 **36–48%**。
- **为什么值得关注**：coding agent 的钱到底花在哪，这一天被明码拆开了——大头不是那次"想难题"的旗舰调用，而是成千上万次小的工具步。于是选型口径从"旗舰模型单价"变成"**分层 + 每任务美元**"。而 FrontierCode 的落后恰好划出边界：便宜的执行层能把大多数 agent 类跑分刷上去，但"这个改动能不能被合并"没法靠便宜换。

### 4. 优必选把 10 万台人形的目标交给了中国电信的营业厅

- **11/9**，中国电信全资子公司**天翼电信终端**与优必选签全面战略合作，"天翼电信终端-优必选机器人联合创新实验室"同日揭牌。三年内共同推动**家庭陪伴机器人终端行业规模破百万台**、**超仿生/轮式人形终端行业规模破十万台**。注意措辞是"行业规模"，不是优必选自身的销量承诺。
- **渠道才是重点**：优必选此前人形收入几乎全部来自工业制造与政企集采；天翼承担中国电信终端运营与生态合作，有全国营业厅网络与家庭客户资源。试点包含**租赁、"AI 权益+终端"、营业厅体验场景**——收入结构从 B 端集采往 C 端走。
- **财务底盘**：2025 年交付全尺寸人形 **1,079 台**、营收 20.01 亿（+53.3%），全尺寸具身收入 8.2 亿（+2,203.7%，占 41.1%），据此推算**单台均价约 76 万元**；2026H1 营收 12.69 亿（+104.2%），全尺寸占比升到 46.5%；毛利率 2024 年 28.7% → 2025 年 37.7% → 2026H1 **44.7%**；净亏从 11.37 亿收窄到 7.03 亿；管理层维持 2027Q4 单季盈亏平衡。当日股价盘中涨超 14%、收 70.3 港元（+8.99%）。
- **冲突点必须写出来**：IDC 数据显示 2025 年全球人形出货约 **1.8 万台**、市场规模约 4.4 亿美元；优必选副总裁焦继超此前公开表示"人形**进家庭至少还需 8–10 年**"。
- **为什么值得关注**：这是 11/09 期"Optimus 只租不卖"、中石油×宇树+昆仑租赁之后的第三块拼图——中国走的是"**运营商渠道 + 租赁 + 权益捆绑**"，本质是把机器人当"终端品类"卖，而不是当设备卖，从而绕开单台 76 万的购买决策门槛。代价是这份协议把"百万台家庭陪伴"写成了公开目标，与自家高管"8–10 年"的判断正面冲突，等于提前给自己上了一道兑现压力。

### 5. Anthropic 补全 agent memory 实验：413 份笔记输给 9 份，差别在"能不能被核对"

- 11/06 工程博客《The components of agent memory》（Lance Martin）首发，11/09 中文媒体拆出完整数据。11/08 期只在附注里一句带过，本期补实验细节，**不是今天的新发布**。
- 定义很干净：agent memory 指**跨会话保留、从经验中得来的知识**；明确排除改权重、上下文内学习、compaction。机制两层：随手记（给 session log 打标签、写 memory notes）+ **dreaming**（空闲时重读 transcript，纠错、重组、把笔记提升到每次会话必加载的顶层）。
- **CL-Bench 1.0**：Sonnet 4.6 只在笔记里写"未经检验的猜想"，且除非明确要求，**开会话读记忆的比例不到一半**；Opus 4.7 收敛成一份参考文档并标注"已核对/未确认"；Sonnet 5 自主在 **>90%** 的会话先读记忆；Opus 5 首次闭环——记规则、记"我怎么知道它是真的"、记旧答案和陷阱警告。
- **Pokémon Red 是最有说服力的一组**：Sonnet 3.7 写了 **413 个记忆文件、225 个文件夹**，玩到 1 万步只拿到 1 枚徽章，中间有连续 17 步在删旧笔记；Fable 5 只写 **9 个文件、2 个文件夹 + 1 个 global.md**，拿到 4 枚徽章；Opus 5.5 保持小目录并通关。
- **纠错的真实价值**：Claude 把 Mt. Moon 出口的 PokéCenter 方位记反了并标注"已完成"，走出洞口踩上单向坡三次回到起点；dreaming 把笔记和原始 transcript 对照后改写方向，下一次直接进洞抵达 Cerulean City。
- **企业语料**：Stainless（Anthropic 2026/5 收购）**35 万文件、约 4.2 亿 token**、25 道题。128 次 dreaming 会话后，只靠 wiki 的评分标准覆盖率从 13% 升到 **48%**；wiki + 搜索从 54% 升到 **61%**（纯搜索 53%），**每问答省约 2 万 token**；多文档题在查 wiki 时 **87%**，纯搜索 73%。
- **反例同样重要**：一个 Harvey LAB 法律简报任务上 wiki 没有任何增益；另一个任务里 wiki 长得比源文档还大。维持表征要算力，还要防幻觉累积。
- 提示词层面最反直觉的一条：**告诉模型"记忆是为了什么"比"怎么用记忆"有效**；而"只记失败"这类硬规则，让 Opus 5 和 4.7 的记忆收益大幅缩水。
- **为什么值得关注**：长程 coding agent 真正缺的不是更长的窗口，而是**跨会话的经验从来没被验证过**。413 份输给 9 份，本质是记忆的瓶颈在"能不能被核对"，不在"记得够不够多"。可迁移的工程结论只有三条：**顶层记忆必须小**（每次会话都加载，错一条就错一路）、**纠正必须回到原始 transcript**、**别用硬规则规定该记什么**。
