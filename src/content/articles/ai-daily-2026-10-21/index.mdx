> 主线：今天的关键词是「降温」。具身智能被信通院点名「出货≠上岗」、2–3 年首轮出清；AI coding 侧价格战打到 $0.15/百万 token，但榜单可信度与陌生任务泛化同时被质疑。真正的进展出现在「分发」和「工程化」层面。

---

## 1. 信通院《具身智能发展报告（2026）》：出货 2.2 万台，只有 13% 进了产线

**事件**（10 月 20 日发布，信通院 + 清华电子系 + 具身智能测试实验室，连续第三年）

- 上半年国内具身智能融资 322 起、约 935 亿元，同比增约 5 倍；世界机器人大会新品从 123 款增至 311 款。
- 全球人形机器人出货超 2.2 万台，同比增近 300%；5 家国内整机厂合计占 86% 以上。
- **结构失衡**：文娱商演 + 科教数采合计超 60%，导览导购 19%，智能制造 13%，仓储物流 5%——真正进产线的不到两成。
- **数据边际效用骤降**：Dyna-2 在 14 个自建任务集上，预训练数据从 10 万小时扩到百万小时，平均成功率仅 45% → 53%（+8pt）；国内多数模型还停在 10 万小时以内，落后约一个数量级。
- **表演经济退潮**：表演租赁日租金从 2025 年初约 2 万元跌至千元级（-80%~90%）；二手旧款工程样机（原价 30–80 万）残值跌到 3–6 万，缩水近九成。
- **增收不增利**：越疆科技上半年营收 3.16 亿元（+106.6%），净亏 1.08 亿元（同比扩大 163.8%）；A 股 500+ 公司提及具身智能，披露相关收入的仅个位数。

**为什么值得关注**
这是目前对「演示经济 vs 真实需求」最硬的一份数据底座。它给出的判断是：洗牌已启动，未来 2–3 年完成首轮出清，政策端「实景实训专项行动」要求年底前推动超万台设备从演示转向常态作业。对做选型、投资、技术路线的人，校准预期的关键是三件事——泛化、可靠性、数据闭环，而不是本体出货量。同时它推翻了一个流行假设：堆数据不一定换来能力跃迁，具身很难复制 LLM 的扩展定律。

## 2. 奇瑞墨甲「墨宝」全球首发：车企把具身智能从「上岗」推到「入户」

**事件**（10 月 21 日，安徽芜湖，2026 奇瑞全球创新大会）

- 墨甲首款**消费级家庭陪伴人形机器人「墨宝」**全球首发并开启预订，定位从 B 端场景走向 C 端家庭。
- 技术核心是自研 **MoAgent 大脑**：多模态感知融合、任务自主规划（模糊指令拆解）、长时记忆（记住家庭成员偏好与历史对话）。
- 工程底座：31 个自研实验室；把智驾的环境感知算法、智能座舱的交互逻辑迁移到机器人；复用汽车级供应链与质量控制体系。
- 背景：墨甲机器人此前已在教育、医疗等 100+ 场景常态上岗，走的是 B 端先行路线。

**为什么值得关注**
家庭是高度非结构化场景，对运动控制与容错的要求远高于展厅和商场。车企以「车规级量产一致性 + 现成供应链 + 智驾算法迁移」切入消费级机器人，是今年最具差异化的一条路径。但发布会演示的可信度历来最虚——真正要盯的是**预订转化率、实际使用时长、退货率**，而不是情景剧。

**资本面注脚**：10 月 20 日晚宇树科技发布股票异常波动公告，三日涨幅偏离值累计超 30%，滚动 PE 388 倍（通用设备行业均值 39.5 倍），公司自行提示「人形机器人仍处商业化早期，存在估值回归风险」。一级市场同期：智元创新新一轮估值约 500 亿元，星尘智能 10 亿元融资后估值 150 亿元。估值已明显跑在收入前面。

## 3. Dream Labs 开放机器人 API：$3/小时，具身智能开始「按调用计费」

**事件**（10 月 19 日）

- 发布公开机器人 API 与 **9000 万美元种子轮**。旗舰模型 Dream-1 定价 **$3/小时**（Flash 版 $2），面向双臂 + 平行夹爪机器人。
- 硬件伙伴 MakerMods 称其机器人接入后数分钟内即开始尝试新任务。
- 定位为研究性 beta：性能随硬件变化，未针对安全关键场景做验证。

**为什么值得关注**
这是「具身智能的 API 化」——把模型能力与本体解耦、按小时计费，替代过去「每个场景重新采数据 + 微调」的老路。若这条路走通，机器人应用的开发门槛和试错成本会像 2023 年之后的 LLM 应用一样骤降，小团队也能低成本验证场景。短期风险很明确：硬件适配未标准化、可靠性未知，现阶段的定价更像是获客而非成本结构。

## 4. Agent 成本战打到 $0.15/百万 token，但「榜单可信度」同时被质疑

**事件**

- **MiniMax M3.1 Flash**（10 月 19 日）：输入 $0.15、输出 $0.60、缓存读取 $0.015（¥1/¥4/¥0.1 每百万 token）；线上推理提速近 3 倍（200+ tok/s），官方称 Agent 类任务综合成本降 70%。成绩：DeepSWE v1.1 73.7%、BankerToolBench 76.2、OSWorld V2 61.7（称国产第一）、CyberGym 82%。已上线 API / M Plan / MiniMax Code，权重后续开源。
- **DeepSeek V4.1-Flash-1017**（10 月 17 日）：不降 token 单价，改任务处理方式，单次编码任务成本从 $0.5 降到 $0.2 以下。
- **争议**：有研究者用改写过的 AA-Omniscience 留出题测试，指 M3.1 Flash 直接输出原答案（"query sniping"质疑，MiniMax 未回应，尚无第二家独立证实）。另有独立数据：事实准确率 56%，答错时 93% 的概率是高置信幻觉。

**为什么值得关注**
Agent 的经济性拐点确实到了——1 元/百万 token 意味着长循环 agent 可以「随便跑」，这是过去两年最大的成本约束松动。但选型的逻辑必须改：便宜的代价从「token 账单」转移到了「校验开销」。如果 93% 的错误是自信的错误，省下的 70% 成本会被人工复核吃掉。结论很直接：**自建 held-out 评测集（自己的仓库、自己的工单、自己的失败样例）比任何公开榜单都重要**，尤其当你把模型 hosted 在厂商自己的推理服务上时。

## 5. Meta Muse Wonder 一次铺进 7 家平台：coding 模型竞争从「跑分」转向「分发」

**事件**

- Muse Wonder / Wonder Full（10 月 12 日）主打**长任务 coding agent**：Active Memory（跨长任务保持状态）、Active Focus（长时专注）、失败后可恢复；1M 上下文、多模态输入、工具调用、子 agent 委派、computer use。定价 $4/$20 每百万 token。
- **分发**：已通过 Cline、Cursor、Cognition、OpenRouter、Vercel AI Gateway、Cloudflare、Oracle 开放，不自锁在 Meta 自家产品内。
- **翻车**：社区用「熔岩灯 3D 测试」（要求生成带透明玻璃外壳、动态熔岩、光照效果的灯）实测，普通版只输出一个红色圆柱体，被质疑 benchmaxxing（针对榜单过拟合）。Meta 首席 AI 官 Alexandr Wang 承认未针对 3D 演示显式训练，Model Card 也已把 3D/空间推理列为已知短板；同时强调公开的 SWE-Marathon 57.5、DeepSWE 1.1 79.0 分部分来自更强的 Wonder Full。

**为什么值得关注**
两点。一是策略：Meta 用「跨平台可移植」抢 agent 栈的默认模型位，而不是做封闭生态——这意味着模型层的竞争会越来越像云厂商的战争，赢在集成摩擦而不是单项跑分。二是它把「高分 vs 陌生任务翻车」的落差摆到了台面上，对所有用 benchmark 做采购决策的团队都是一次提醒：分数是必要条件，不是充分条件。

## 顺手一提（工程细节）

**Claude Code 2.1.299+**（10 月 14 日）值得跑长会话的团队审一遍配置：

- 超长空闲会话在缓存过期前自动 **idle compaction**（涉及 `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`）；
- 新增环境变量让 `@` 提及只发送**文件路径**而非文件内容（`CLAUDE_CODE_DISABLE_FILE_MENTIONS`）——对代码保密和 resumed-session 读取成本都有直接影响；
- plugin / hook 失败语义收紧，resume、缓存与权限模式行为有变，依赖 session-resume 的 CI 需要回归。

同期 **LangChain 1.4.6** 为 HumanInTheLoop 中间件加入 per-call interrupt，可以对单个工具调用（shell、部署、commit）设置审批门，而不是一刀切的全局开关——生产环境 coding agent 的必需件。

## 今日观察

1. 具身智能的分水岭不是「能不能动」，而是「能不能稳定完成真实工作」。而数据规模已不再是唯一解释项——10 万到百万小时只换来 8 个点的成功率，说明瓶颈在数据质量、训练目标与部署工程，不在数量。
2. AI coding 的竞争重心正从「模型能力」下移到「成本 × 分发 × 工程可靠性」三件套，而评测可信度正在变成一项新的隐性成本——买模型的人，得先学会不信榜单。
