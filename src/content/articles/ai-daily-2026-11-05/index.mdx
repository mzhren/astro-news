## 一、Kimi K3.1 Pro 权重如期落地：1.56TB 权重 + 一份"MIT 加两条门槛"的许可证 + vLLM 首日四芯片适配（连续跟踪 11 期的兑现增量）

**事件内容**

月之暗面兑现 10/23 的承诺，K3.1 Pro 完整权重已可下载。按上期去重原则，只报前日未确认的差异项：

| 维度 | 上期待确认 → 本期落地 |
|---|---|
| 权重 | HF 上 `moonshotai/Kimi-K3.1-Pro`，96 个 safetensors 分片合计 **1.56TB**（MXFP4 量化感知训练），无需申请、gated=false；HF 月下载量已约 79.7 万 |
| 许可证 | 自定义 **"Kimi K3.1 Pro License"**，主体沿用 MIT 措辞，但加两条门槛：① 经营 Model as a Service 且关联方任意连续 12 个月营收合计超 **$2000 万**，商用前须另签协议；② 商用产品月活超 **1 亿**或月收入超 $2000 万，界面须显著标注"Kimi K3.1-Pro"。**内部使用与官方产品/认证推理伙伴不受约束** |
| 一个不对齐 | 许可证把"inference and training code"一并纳入 Software，但仓库里**并无训练代码**（只有 transformers 加载路径 + vLLM/SGLang/TokenSpeed 配方）——训练配方与数据管线仍未开放 |
| 部署生态 | **vLLM 11/5 凌晨发布首日适配**：NVIDIA GPU / AMD GPU / Google TPU / 平头哥 PPU 四条硬件路线同日支持；8×GB300 可装约 3 个完整百万 token 上下文（DCP8+NVFP4 可扩至约 36 个，12 倍容量差）；另训了 DSpark 草稿模型实现约 3 倍 decode 加速 |
| 第三方复测 | Vals AI Terminal-Bench 4.0 独立测试 **63.64%、59 模型第三**（Opus 5.5 为 65.15%），但每题成本 **$4.57 vs Opus 的 $13.20**，约为 1/3 |
| 托管 | HF 页面标注"尚未被任何推理供应商部署"——第三方托管价仍是下期观察点 |

**值得关注的原因**

1. **中国开源实验室"说好哪天放就哪天放"第一次在 3T 级尺度上兑现**，Nathan Lambert 的评价点出了实质：可预期的开放时间表本身就是竞争力。对采购方，这把"会不会随时收回"的风险从谈判桌上去掉了。
2. **许可证两条门槛划定得异常清晰，直接影响三类团队**：做内部产品/嵌入功能的几乎无感；对外卖推理 API 的过 $2000 万线要签约；月活上亿的产品只需署名。比 Mistral"修改版 MIT 含 MaaS 条款"的模糊表述更可执行——这正在成为国产开放权重的标准条款模板。
3. **部署生态的速度比权重本身更说明问题**：权重 11/2 建仓、11/4 到期兑现、vLLM 11/5 凌晨发适配稿且四家芯片同日上线——"权重一放、生态次日跟上"的基础设施成熟度，是开源权重从"跑分道具"变成"可部署资产"的实际前提。

## 二、字节跳动封禁个人 AI 账号访问 L4 代码仓库：企业级 coding 进入"统一管控"阶段

**事件内容**

11/5 凌晨多家媒体报道：字节跳动自 11 月起对**全部 L4 级代码仓库与飞书文档实施外部 AI 访问封禁**，覆盖全公司，**员工个人采购的 Claude、Codex 等账号均不可再用**；技术副总裁洪定坤内网回应称 L3 及以上内容泄露后果严重。

**值得关注的原因**

1. **这是"shadow AI"治理的标志性一刀。** 个人订阅 → 工作流依赖 → 代码资产外流，是过去两年大厂默认发生的事；字节把"个人付费买的能力"与"公司代码资产"之间的通道明确关死，等于承认：coding agent 的采用瓶颈已经从能力转移到**数据边界与 IP 归属**。
2. **对国内编码工具市场是直接的需求转移信号。** 封禁创造真空：要么走私有化部署的开源权重（K3.1 Pro、GLM、LongCat 恰好接上），要么自研托管栈（豆包/扣子内部承接）。参考 Revolut 的路径（上期已报），"数据不出域的自托管编码模型"从银行特例变成科技大厂标配，这条曲线会加速。
3. **可预期的连锁反应**：其他大厂跟进同等管控；coding 采购的准入清单里"审计日志、权限分级、私有化"从加分项变成必选项。这也是本期附注里乌镇《智能体发展自律公约》的另一面——治理从公约层落到内网权限层。

## 三、Meta 收购 Conductor、OpenAI 收购 Pierre：头部实验室同日用收购补"编排与代码审查"后端

**事件内容**

| | Meta × Conductor | OpenAI × Pierre Computer |
|---|---|---|
| 对方是谁 | 2024 年成立，核心产品"**并行工作区 + 多智能体编排**"：把同一项目不同模块派给多个 agent，本机/云端/手机同时推进，底层调用 Anthropic/OpenAI 等模型；2026-03 刚完成 **2200 万美元 A 轮** | 开发 Trees、Diffs 等**代码管理与审查库**，已被 **Codex 实际使用** |
| 交易 | 金额未披露，团队整体加入（CEO Charlie Holtz 将与 Alexandr Wang、Nat Friedman 共事）；云服务 **11/20 关停、随后删除云端数据** | 金额未披露，补齐代码探索、审查与存储能力 |
| 节奏 | 都在 11/4–5 官宣/确认 | 同左 |

**值得关注的原因**

1. **模型能力已成公共品，稀缺的是"调度权"与"审查权"。** Conductor 卖的不是模型，是让多个 agent 并行干活、产出可合并可审查的工作流；Pierre 补的是 diff/review 这层"agent 产出可信度"的基础设施。两家实验室同日出手，延续 10 月以来 harness/编排层是主战场的叙事——**竞争重心从单模型能力滑向 agent 工程化后端，自研周期被收购压缩**。
2. **acqui-hire 的副作用值得依赖方警惕：云服务 11/20 关停、数据删除。** Conductor 类工具的资产全在云端，团队须在窗口内迁移仓库与任务记录，否则整套工作流蒸发。把工作流押在独立编排工具上的团队，需要把"被收购即服务终止"写进风险评估。
3. **对独立 coding 工具创业公司是估值逻辑的转折**：编排层价值被巨头定价后，中间层公司要么被收编、要么退守垂直场景。"明年 Meta 出新产品"预示编排能力将捆绑进超级智能实验室的体系，独立工具的生存空间被结构性挤压。

## 四、Agility Robotics 以 AGLT 登陆纳斯达克：公开市场第一次给人形整机定价

**事件内容**

11/5，Agility Robotics 通过 SPAC（Churchill Capital XI，股东会 84% 赞成）合并后于纳斯达克挂牌，代码 **AGLT/AGLTW**，成为美国唯一公开上市且有活跃商业部署的纯人形机器人公司：

| 维度 | 信息 |
|---|---|
| 募资 | 毛额约 **4.65 亿美元**：Churchill XI 信托约 1.64 亿 + **富士康领投 PIPE 2.01 亿美元**（每股 $10）+ 此前 1 亿；较 6 月宣布时"超 6.2 亿"**缩水约 25%**（SPAC 信托赎回） |
| 估值 | 投前约 **25 亿美元** |
| 业务底数 | 9 个客户场地，**累计实运营超 6.5 万小时**，GXO 仓库搬运超 10 万个物流箱，手握超 **3 亿美元** Digit 5 多年期订单；RaaS 模式 **8500 美元/月/台** |
| 对照 | 国内同期：智元暂缓港股、微亿挂牌前叫停；宇树 Q3 扣非净利 1.05 亿（-17.42%），二级市场要现金流 |

**值得关注的原因**

1. **这是"能干活"的公开市场标尺，首日走势比募资额更重要。** 富士康按 $10/股掏 2 亿领投，等于用制造业的尺子替二级市场先量了一遍量产能力；而募资缩水 25% 说明在"能交付"与"能盈利"之间，公开市场目前只愿意先为前者付钱。
2. **给国内整机厂的估值锚定漂移提供参照。** AGLT 的定价逻辑是"6.5 万小时实运营 + 3 亿美元订单"，而非模型跑分——若首日站得住，国内"看跑分"的估值叙事会加速向"看真实复购率"迁移；若破发，则同样说明交付叙事尚未穿透二级市场。注意流通盘仅约 1595 万股，首日信号意义需打折。
3. **商业模型样本**：RaaS 按月出租而非卖硬件，与附注里 Tutor Intelligence"按小时/按件卖机器人劳动力"同向——具身行业正在从硬件销售向"劳动力计费"迁移，这是判断行业成熟度更硬的指标。

## 五、智元便利店 24 小时考核收官：4 台转正、2 台待观察，"无人在环"首次交出用工口径答卷（第 3 期跟踪兑现）

**事件内容**

11/3 10 时，上海徐汇营业中便利店内 6 台精灵 G2 结束 24 小时直播值守，智元公布完整数据：

| 维度 | 数据 |
|---|---|
| 任务完成 | 累计 **1730 项**：接待 683 次、取送 369 件、咖啡 147 杯 |
| 覆盖班次 | 午高峰 / 晚高峰 / **深夜无人在场值守** / 早高峰，四个班次连续 |
| 人员口径 | **4 台转正、2 台待观察**（因主动性与路线稳定性不足）——不再依赖后台工程师接管或遥控 |
| 过程问题 | 曾出现下单失败、订单状态未更新、位置冲突等 |
| 传播 | 全网观看超 200 万人次 |

**值得关注的原因**

1. **"转正/待观察"是行业第一次用 HR 口径而非 Demo 口径汇报机器人表现。** 24 小时考验的不是单台体力，而是整套工作流的**持续、可恢复、可打断**——深夜无人值守段落尤其关键。2 台"主动性不足待观察"的负面披露比 4 台转正更有信息量：它承认了当前模型在自主决策一致性上的真实水位。
2. **便利店比工厂更接近通用化的考场。** 顾客随意走动、商品状态随时变化，暴露的问题（订单状态失步、位置冲突）恰恰是"数据—模型—自愈"闭环的真实缺口；与小米汽车工厂 8 小时整班（结构化场景）对照，两类场景的数据回流质量差异本身就是行业分水岭。
3. **观测口径对齐后，横向比较第一次成为可能**：转正率 4/6、任务量 1730/24h/6 台、观看 200 万——下期起可跟踪"转正率"是否成为智元乃至同行的常态化披露指标，以及外卖/商超场景的复制速度。
