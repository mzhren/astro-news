## 一、Gemini 4 Carbon 发布：提示词注入攻击成功率 0%，但"最强模型你现在用不上"

**事件内容**

10/29，谷歌在 Gemini 4 Argon（两周前发布）之后推出新一代前沿模型 **Gemini 4 Carbon**：

| 维度 | 数据 |
|---|---|
| 综合排名 | Artificial Analysis Intelligence Index v5.0 **第一**（59 分），领先 GPT-6 Astra、Claude Opus 5.5 |
| 找漏洞 | SEC-bench Pro **88.2%**（SOTA），自主发现真实软件中的复杂缺陷 |
| 漏洞利用验证 | ExploitGym **54.8%**（SOTA） |
| 修漏洞 | CWE-bench **71.0%**（SOTA），输出可用补丁 |
| 安全代码生成 | 较 Argon 提升逾 **2 倍**；Chrome 团队称补丁质量比另一家实验室前沿模型高 **10 倍** |
| 提示词注入 | Grey Swan 评估 **0%** 成功率（Argon 0.7%、Opus 5.5 1%、GPT-6 Astra 8.5%）；高严重性安全对齐警报减少近 80% |
| 长程任务 | 内部团队让它在大型代码库上连续运行**数天**做根因定位与修复；WebDev Arena +89 elo 至第 4（1769） |
| 定价 | 与 Argon 首发价相同：$2/百万输入、$10/百万输出，缓存输入 95% 折扣 |
| 可用性 | **分阶段开放**：先向部分网络防御人员，经 Fairwind 项目扩大，参与美国政府自愿式发布前测试；**未承诺全面开放时间** |

**值得关注的原因**

1. **"网络安全能力"正式成为前沿模型的竞争轴心。** 对照 10-27 期 Terra 的 ExploitBench 24.5%（被归入 Critical 档），两大实验室现在都在系统卡里量化披露"攻"的能力，而 Google 的叙事是"以攻助防"（Fairwind 防御者优先）。攻防两侧同时被基准化，意味着安全能力披露正在从主动行为变成军备竞赛的被动义务——这与 Terra 10-28 引发的"发布阈值锚点"判断互相印证。
2. **0% 提示词注入是首个"零成功"公开口径，可与 Terra 的 13.75% 越权数据直接对照。** 昨天我们写"agent 何时该停手第一次有量化基线"，今天 Google 给出了另一家厂商的同题答案。两份系统卡摆在一起，多 agent 架构里"外部输入该信谁"第一次有了跨厂商可比数据——不过 Grey Swan 是特定评估集，0% 不等于生产环境 0%，等第三方复测。
3. **"最强但先用不上"成为新的发布范式。** 继 Argon 之后 Carbon 再次以"自愿式预发布测试 + 防御者分批开放"落地，Ars Technica 直接标题《你不能用的最强模型》。对开发者务实的判断是：**Argon 才是当前实际可用的 Google 最强模型**（其折扣价 11 月底到期），Carbon 的真实可用性和全面开放后的表现，比发布日跑分更重要。

## 二、Android Studio Rabbit 2"Bring Your Own Agent"转正：IDE 向 40+ 第三方 agent 开放，终端直出 Compose 预览

**事件内容**

10/28 Android Dev Summit 发布 **Android Studio Rabbit 2**，核心是把 IDE 和终端系统性开放给外部 coding agent：

| 能力 | 说明 |
|---|---|
| BYOA（转正为 stable） | 基于 Agent Client Protocol，支持 **40+ agent**（Claude Agent、Codex、Google Antigravity 等），IDE 内可装多个随时切换 |
| IDE 上下文继承 | agent 直接获得项目结构、构建配置、符号解析、Compose Preview、模拟器、Logcat——否则要靠代码搜索自己重建 |
| `android preview` | 在**终端直接渲染 Compose 预览**，不用启动 IDE/模拟器；官方内测称 UI 任务快 **77%**、token 少 **3 倍** |
| `android device remote` | agent 可远程调用 Google 实验室真机做测试 |
| LeakCanary 集成 | heap dump 在开发机分析；演示中 Claude Code 单条指令完成多设备内存泄漏排查→定位→修复→复测，官方 A/B 称快近 2 倍、token 省 25% |
| `android signals` | 把 Android Vitals 和 Crashlytics 生产崩溃数据直接管道化给 agent |
| Change Review | 扫描 agent 待应用改动、生成问题报告，先审后落 |
| 30+ Android Skills | Play 政策、折叠屏适配等文档喂给 agent；另有 Android Bench 2.0 基准（含"需要工程师几天"的任务，计时计费） |
| 应用侧 | AppFunctions API beta：App 经 **MCP** 向本地/系统 agent 暴露函数；Agentic API alpha 基于 Gemini Nano 4 |

**值得关注的原因**

1. **Google 选择了"平台中立裁判"位而非"自家 agent 优先"。** 主开发工具向竞争对手的 agent 开放 IDE 内核上下文，这在所有主流 IDE 里是最大胆的一次。动机可以算出来：Android 开发是 agent 最容易翻车的领域（昨天 Expo 那条已论证），与其让开发者拿着残缺上下文的 agent 翻车，不如把上下文管道化——**留住开发者的方式从"绑模型"变成"供上下文"**。这与 10-28 期 Expo 形成互补的两层：Expo 改造确定性 CLI 让 agent 少猜，Google 开放上下文与真机让 agent 少造轮子。
2. **终端渲染 Compose 预览是降本的关键一招。** agent 改 UI 的验证环过去必须"编译→起模拟器→截图"，又慢又烧 token；把视觉反馈变成终端里的一次渲染调用，token 立省 3 倍。这个思路值得所有 GUI 框架跟进：**给 agent 的反馈回路越轻，agent 自主迭代的回合数上限越高**。
3. **生产数据直连 agent，闭环打穿但别高估。** Vitals/Crashlytics → agent → 修复 → 复测，这是一条完整的"线上 bug 自愈"管线雏形。但报道同时引用了一个冷静的数字：Anthropic 扫描器曾标记约 2.9 万个开源漏洞疑点，最终被修的只有几百个——**自主找 bug 的能力远快于自主修 bug**，闭环自动化率才是真实指标。

## 三、智元创新日发布 GO-3 Preview：登顶三大榜单，承诺 2026 年底全面开源

**事件内容**

10/29 在 2026 智元创新日上（10-28 期预告的 10/29 节点如期兑现），智元联合创始人姚卯青发布新一代具身基座模型 **GO-3 Preview**：

- **架构**：自研具身原生架构 **WRAM（World Reasoning Action Model，世界推理动作模型）**，对理解、预测、动作统一建模，主打跨任务泛化与精细操作；
- **成绩**：自称近日登顶 **RoboDojo、RoboTwin、RoboColiseum** 三大评测榜单；
- **训练体系**：**Genie Evolver**（真机/仿真/世界模型协同的后训练系统）+ **Genie Master** 具身智能体框架（10-27 期已报其 Physical RSI），构成"预训练→后训练→部署后持续学习"全链路；
- **开源**：**2026 年底全面开源**。

**值得关注的原因**

1. **"全面开源"是国内具身基座第一次给出明确时限的头部承诺。** 按 10-28 期引用的出货数据，智元上半年占全球人形机器人出货超 43%——份额第一的厂商把基座模型开源，等于把"基座"从各家私有壁垒变成公共设施，行业竞争焦点会被迫上移到本体、数据与场景运营。年底前需要盯住的关键细节：**开源的是权重，还是含数据管线与训练代码的全链路**——两者含金量差一个量级。
2. **WRAM 的命名本身就是路线宣言：世界模型与 VLA 合流。** "理解-预测-动作统一建模"意味着把预测（世界模型）塞进控制回路，而 Genie Evolver 把真机、仿真、世界模型三个数据源在后训练里协同——这正面回应了 10-28 期"100 万 vs 1 亿小时数据缺口"的结论：**纯采集填不平，世界模型当"数据放大器"是必然选项**。智元把这条逻辑做成了产品架构。
3. **榜单成绩全部是自报口径，先存疑再采信。** RoboDojo/RoboTwin/RoboColismus 的评测协议、任务集、对照组均未随新闻稿披露；10-28 期立的规矩同样适用——等第三方口径。挂起中的 **Genie Sim 3.5（真机-仿真一致性 >95%）截至本期发稿仍未见正式发布报道**， consistency 数据没落地前，WRAM 的泛化主张先按宣传看。

## 四、宇树上市后首份财报：营收 +55.71% 的另一面，是 Q3 利润转降、现金流腰斩

**事件内容**

10/29，宇树科技披露上市（8/19 科创板，发行价 150.80 元，募资 60.99 亿元）后首份三季报：

| 指标 | 前三季度 | 备注 |
|---|---|---|
| 营业收入 | **18.17 亿元，+55.71%** | 收入在加速 |
| 归母净利润 | **3.87 亿元，+270.54%** | 媒体标题数字；公司自述主要来自**上年同期一次性股份支付费用的低基数**；非经常性损益 3772 万（其中政府补助 2910 万） |
| 研发投入 | **2.63 亿元，+191.48%**，占营收 14.47%（+6.74pct） | Q3 单季 1.27 亿，**+249.58%**，占营收升至 19.10%，明确指向"具身大模型研发与算力投入大幅增长" |
| 单季度利润 | **Q3 同比转降** | 研发增量约为利润减量的 3.8 倍 |
| 经营现金流净额 | **1.94 亿元，-54.69%** | 采购、人工、研发支出吞掉大部分销售回款 |
| 存货 / 应收账款 | **10.19 亿（+177%）/ 1.43 亿（+143.5%）** | 双双远超收入增速，备货与回款同时占款 |
| 账上现金 | 73.54 亿元 | 募资到账，总资产 +216.5% 至 101.56 亿 |

行业背景：上半年全球人形机器人出货约 2.2 万台（+近 300%），前五名全是中国厂商合计约 86%——智元 9700 台（43%）居首，宇树 7000+ 台（31%）第二；全年预计突破 5 万台。

**值得关注的原因**

1. **这是第一份"上市具身公司"的完整报表，行业第一次有了可审计的账本。** 之前所有"具身智能算账"（10-26 期）都是券商估算和一级市场口径，现在终于有审计数据：**收入 +55% 的同时 Q3 利润转降、现金流腰斩**——具身大模型是真的烧钱（Q3 研发费率冲到 19.1%），"卖机器人养大模型"的模式毛利额尚未完全对冲投入。所有拿宇树对标估值的同行，账本大概率长一个样。
2. **270.54% 的净利增速是标题陷阱，读财报要看扣非和基数。** 公司自己在报表里写明主因是上年一次性股份支付，外加 2910 万政府补助。这条对二级市场的意义在于：**宇树股价（10/28 盘中破 700 元、市值约 2900 亿、滚动 PE 约 465-490 倍）的定价基础是"增速"，而这个增速里最容易高估的成分恰恰是一次性因素**。
3. **存货 +177%、应收 +143% 指向交付驱动的真实运营压力。** 备货节奏加快 + 回款周期拉长同时出现，说明"规模化量产落地"伴随的是营运资金被上下游占用——10-26 期"租金腰斩、残值缩水"讲的是资产端，这份报表补上了运营端的另一半证据。行业景气是真的，**现金转换效率的恶化也是真的**，两件事同时成立。

## 五、小鹏全球首发"机器人专用固态电池"：车企供应链开始向机器人外溢

**事件内容**

10/27-30 在苏州召开的 2026 中国汽车工程学会年会上，小鹏首发**机器人专用固态电池**：

- 相比传统液态锂电池：**减重约 30%、电量提升约 30%**；
- 小鹏宣布计划 **2026 年底实现高阶人形机器人规模化量产**（10-28 期特斯拉弗里蒙特 Optimus 量产启动后，第二家给出明确量产时点的整车厂系玩家）。

**值得关注的原因**

1. **电池是人形机器人最被低估的瓶颈，车企供应链是现成的解法。** 当前人形机器人续航普遍只有 2-4 小时，电池的重量、发热、换电问题直接吃掉有效作业时长——而作业时长决定时薪，时薪决定回本周期。"减重 30% + 电量 30%"翻译过来就是**作业时间接近翻倍**，对经济性测算的影响不亚于任何算法进步。
2. **"汽车技术栈外溢"是具身智能成本曲线的第二条腿。** 10-26 期讲过制造成本（租金、残值），本期补上能源部件：固态电池的量产工艺、良率、供应链由车载市场养大，机器人作为"第二应用"几乎是搭便车。车企做机器人的优势从此不只制造管理，还有**整个三电供应链**——这与特斯拉 Optimus 的逻辑同构，小鹏是国内对照样本。
3. **量产时点开始"对表"，2026 年底成为检验窗口。** Optimus 弗里蒙量产启动（10-28 期）、小鹏 2026 年底规模化量产、宇树存货 +177% 备货——三家公司三条证据链指向同一点：**2026 年底-2027 年是人形机器人从"发布会产能"到"报表产能"的验收期**。届时 10-26 期"租金腰斩"与 10-28 期"数据定价"两张表的数字都会被真实交付重新校准。

## 附注速览

- **Symantec 报告信息窃取木马"Aoki"专盗 AI 凭证**：目标是 Anthropic Claude、OpenAI Codex、Cursor、Gemini 的 API 密钥与会话文件（`.claude.json`、Codex 的 config.toml/.env 等），AI 凭证价值"比肩银行卡"。与 10-28 期"AGENTS.md 注入攻击"是两类互补威胁——前者偷凭证，后者劫持指令；共同点是**攻击面都在开发者本地环境**，`~/.claude`、`~/.codex` 目录的权限管理值得立刻过一遍。

- **Gemini 4 Argon 折扣价 11 月底到期**：首发价 $2/$10 将在到期后翻倍，选型预算要把这算进去。
