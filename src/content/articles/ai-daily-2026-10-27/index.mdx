## 一、OpenAI 发布 GPT-6.1 Terra：$1 / $5 每百万 token，Terminal-Bench 从 21.5% 跳到 50.3%

**事件内容**

10/27，OpenAI 推出 **GPT-6.1 Terra**，定位不是"最强"，而是"够用且便宜到可以无脑调用"。重点强化视觉理解与电脑操作（computer use），同步上线 ChatGPT Work、Codex 与 API。

| 维度 | 数据 |
|---|---|
| 价格 | 输入 **$1** / 输出 **$5** 每百万 token，为 GPT-5.6 Terra 与 GPT-6.1 Sol 的 **一半** |
| Terminal-Bench | **21.5% → 50.3%**（Artificial Analysis 复测：+20 个点） |
| Agents' Last Exam（中等推理强度） | 比 GPT-5.6 Terra 高 **15 个点**，成本约其 **1/3**；得分追平 GPT-6 Astra，单 token 价格仅后者 **1/10** |
| 速度 | 完成同一批测试任务的速度是 GPT-6 Astra / GPT-6.1 Sol 的 **3 倍以上** |
| 成本对照 | 最高推理强度下，vs Claude Opus 5.5，单任务成本约低 **9 倍** |
| 幻觉/事实错误 | 低推理强度下错误率 **53.6% → 16.7%**；最高强度降至 **4.3%** |

**值得关注的原因**

1. **这是"coding agent 的燃料价格"第一次被单独定价。** 过去一年 agent 的成本讨论都在 token 用量侧（同任务 token 消耗可差 30 倍），Terra 换了个方向：把单 token 价格压到 1 美元档。当 Terminal-Bench 从 21.5% 抬到 50.3%，意味着**便宜模型正式进入"可托付终端任务"的区间**——大量不需要前沿推理的仓库操作、批量改测试、跑脚本，可以不再用最贵的模型。这会直接改变 agent 产品的默认模型选择与毛利结构。
2. **50.3% 这个数字要放在正确的坐标里看。** 它仍明显低于 Kimi K3.1 Pro 自报的 Terminal-Bench 4.0 65.7%、Claude Opus 5.5 的 66.4%（10-24 期已推）。Terra 的定位是"计算机操作 + 视觉"的中档层，不是前沿编码天花板。真正的变化是性价比曲线而不是能力上限——把它当"便宜一半的 Astra"用是对的，当"新的最强编码模型"用会翻车。
3. **它同时说明了 OpenAI 的产品节奏**：先用 Astra 立能力标杆，再用 Terra 把标杆之下的工作负载收进自己的价格带。对 Codex 而言，这是把"额度能干的活变多"这种最朴素的留存手段。

## 二、Anthropic 335 页招股书：翻身的答案"只有两个字：代码"，Claude Code 独占一章

**事件内容**

10/26，Anthropic 向 SEC 递交 S-1，拟以 **ANT** 为代码登陆纳斯达克，承销团 20+ 家（高盛、摩根士丹利、摩根大通牵头），发行价与股数未定。

| 财务/运营指标 | 数值 |
|---|---|
| 2026 H1 收入 | **163 亿美元**（去年同期 12 亿，+1300%）；Q2 单季 116 亿 |
| 历史收入 | 2023 年 4100 万 → 2024 年 3.86 亿 → 2025 年 46 亿 |
| 账面净亏损 | **807 亿美元**，其中 **724 亿为非现金**（可转债/SAFE 公允价值变动，估值涨得越快亏得越多） |
| 经营亏损 | H1 约 **6.93 亿美元**（收入 163 亿 / 经营成本 170 亿），经营亏损率从 2025 年的 176% 收窄到约 4% |
| 算力成本 | H1 **89 亿美元**，约占每 1 美元收入的 55 美分；Trainium + TPU + NVDA/AMD 混跑 |
| 付费客户结构 | TTM ≥10 万美元客户 **11,900 家**（一年前 950 家）；≥100 万 1,900 家；≥1000 万 250 家；另有约 4000 万小额客户 |
| 净收入留存率 | 约 **900%**（一年前已付费客户，现季度花费约为去年同期 9 倍） |
| 收入结构 | 按用量计费 **130.6 亿**（80.2%）/ 订阅 **32 亿**（19.6%） |
| 增速归因 | 2026 年 4–9 月发布的模型贡献 Q3 **八成以上**收入 |

与编程直接相关的三处硬信息：

- **代码生成市场份额**：Menlo Ventures 口径，19 亿美元代码生成市场中 Anthropic 占 **42%**，OpenAI 21%。
- **Claude Code 单独成章**：招股书称其为"我们认为最具体地定义了什么叫自主 AI 工作"的产品，举例是 NASA 工程师用它规划火星车指令。
- **Claude Code 是花钱的入口**：Q3 数据，Claude Enterprise 里**不用** Claude Code 的用户月均花费不到 75 美元；**用 Claude Code 的头部 5% 用户，花费约为其 20 倍**。
- **"不做清单"**：明确不开发图像/视频生成模型，把全部算力投向**编程、Agent 能力、安全研究**。

另有两个细节值得记：前两大客户各贡献约 12% 收入，泄漏版猜是 Cursor 和 GitHub Copilot，正式版是**亚马逊和谷歌**；2026 年前九个月约 **5%–7% 的收入来自后来被判定违反使用政策/商业条款的客户**，8–9 月加强执法后这部分会缩水，可能拖累增速。

**值得关注的原因**

1. **这是 AI 编程商业化第一次有审计级账本。** 42% 份额 + 头部用户 20 倍花费 + 900% NRR，三组数字拼出的结论是：coding agent 是目前唯一被验证的、能撑起"usage-based 收入"的 AI 品类。对国内做 coding 工具的团队，这等于给出了一个可对标的商业模型上限估值锚。
2. **"不做图像视频"是战略取舍，不是能力缺失。** 它把公司押在"高价值企业级认知工作"上，而 coding 恰好是唯一能同时产生高频调用、可验证结果、企业付费意愿的交叉点。这解释了为什么 coding agent 的竞争会从产品层直接烧到模型层。
3. **风险也写在同一份文件里。** 55 美分/美元的算力成本、take-or-pay 的长期算力合约（金额在这版里留空）、5%–7% 的违规客户收入——这三项任何一个恶化，都会先打在 coding 这类高频用量业务上。Claude Code 越成功，对算力承诺的敞口越大。

## 三、Fanatics 用 Codex 改建商品推荐：3 万件 MLB 商品互动率 +10%，50 个搭配 24 小时跑完

**事件内容**

10/27，OpenAI 公布与全球数字体育零售平台 **Fanatics** 的合作细节。Fanatics 上线由 OpenAI 模型驱动的 **"Shop the Look"**：球迷浏览某队球衣时，商品页直接给出成套搭配建议。

| 维度 | 细节 |
|---|---|
| 覆盖 | Fanatics.com + NFL / NBA / MLB / NHL 官方线上商店等网络内多站点 |
| 数据基础 | 商品与目录数据增强、球队信息、实时库存；搭配由 Fanatics 自己的 merchandising 规则约束，**每日随目录刷新** |
| 用 Codex 干了什么 | 双方工程团队用 Codex 快速搭出"商品/目录数据增强 → 找可搭配商品 → 评估推荐结果 → 生成搭配"的工具链 |
| 测试速度 | 首批 **50 个搭配不到 24 小时**跑完；迭代两天当周通过 MVP，随后推广到数千款商品 |
| 效果 | 约 **3 万件 MLB 商品**测试，互动率比旧版高 **10%** |
| 业务体量 | 全站 150 万+ SKU，每周新增最多 1000 个新品 |

**值得关注的原因**

1. **这是"coding agent 走出软件团队"的一个可量化样本。** 过去 coding agent 的案例几乎都在研发部门内部（补测试、改迁移、修 bug）。Fanatics 这个案例的实质是：**运营/电商团队拿 Codex 现造内部工具**，去解决一个原本"人工排不出、买 SaaS 又不合适"的长尾需求（150 万 SKU × 每日刷新 × 球队/风格约束）。这类需求正是 agent 最合适的落点——一次性、规则复杂、价值可测。
2. **它把"效率"翻译成了"业务指标"。** 24 小时 vs 传统排期数周，最后落在互动率 +10%。对照 10-25 期 Push 的 harness 分差、10-26 期的成本账，这是第一次出现"coding agent 的产出直接对应一个 C 端指标"。对做 to B 销售的人，这比任何 benchmark 都好用。
3. **但 +10% 的口径必须打问号。** OpenAI 未定义 "engagement" 是什么（点击/停留/加购？），也未给基线、测试周期，更未说明是否带来成交/转化提升。**互动率 ≠ 营收**，这是零售 AI 案例最常见的注水点。看这类新闻时，值得先找"有没有披露转化率和 GMV"。

## 四、智元 Genie Master 发布：把 Agent 与物理世界接起来，号称首次在真实业务场景跑通 Physical RSI

**事件内容**

10/27，智元 AI WAVE 第六弹 **Genie Master** 正式发布（10-22 期已列为待跟踪项，本期为兑现）。官方定位一句话：**"连通 Agent 与物理世界——在真实业务场景首次实现 Physical RSI（具身递归自我改进）"**。

据官方与媒体报道，它是一个**中间层框架**，位于大模型 Agent 与机器人本体之间，承担三件事：

| 职责 | 含义 |
|---|---|
| 任务理解 | 把自然语言/业务指令转成机器人可执行的作业意图 |
| 动作拆解 | 把意图拆成有序动作序列，分派给本体能力 |
| 容错执行 | 执行中出错时自行诊断、重试或换策略，而不是整体失败 |

**Physical RSI（具身递归自我改进）** 指的是：机器人在真实业务中积累的物理交互经验，反过来改进自身的策略与框架能力，形成闭环——把"软件侧的 RSI"搬到物理场景。**需要说明的是，官方目前只给了定位表述，尚未披露闭环的具体环节（经验如何结构化、如何回灌、改进幅度多少），技术细节待 10/29 基座模型与后续论文。**

把它放进 AI WAVE 七天链条里看，逻辑是连的：

- **10/22** 开源 AGIBOT WORLD 2026 第四期「具身推理」数据集——150 小时真机、100% 真实场景，任务设计**从"操作难度"转向"决策难度"**（覆盖 9 类逻辑推理，同一任务人为构造多种状态分支）；
- **10/23** Genie Studio 2.0——采-训-测-推-编-管全生命周期，宣称**最快 7 天**完成新场景 0→1 部署；
- **10/26** G2 Max 重载本体；
- **10/27** Genie Master（本期）；
- **10/28** Genie Sim 3.5 自研物理引擎，宣称复杂任务真机-仿真一致性 **>95%**；
- **10/29** GO-3 具身基座大模型；**10/30** 群体经验学习（CEL），百台级真机集群原型。

公司侧数据：2025 年收入 **10.5 亿元**（国内最快跨过 10 亿门槛的机器人公司），2026 年预计数倍增长；已于 10 月启动新一轮 **10–15 亿元**融资，接近收尾，估值约 **500 亿元**。

**值得关注的原因**

1. **它把"RSI"从训练侧搬到了业务侧，这是今年具身智能最有争议也最有价值的一个提法。** 此前 RSI 的讨论都在"AI 造 AI"（10-26 期 Mirendil-Base、10-27 Recursive Eureka Machine）。智元把它改成"机器人干活 → 经验回流 → 下一轮干得更好"，如果成立，它绕开了"先有海量数据才能训练"的死循环——数据在业务中自己长出来。这也正是 10-21 期信通院报告里"数据边际效用骤降"的解法方向。
2. **"中间层"这个位置比"又一个 VLA"更值得关注。** Genie Master 不承诺替代本体策略，只承诺做编排与容错。这与 10-26 期 RAX 的"coding agent 直连机器人接口"是同一个思路的两种实现：**上层通用智能 + 下层专用控制**。真正稀缺的是中间那层接口与容错，而不是再训一个模型。
3. **判断它成不成的关键在 10/28–10/30 三弹。** Physical RSI 的闭环需要：可靠的仿真一致性（>95% 才有意义）、足够强的基座（GO-3）、以及群体经验能否跨机复用（CEL）。三件缺一件，RSI 就只是叙事。**这是本周最该盯的三天。**

## 五、中科慧灵数亿元 A++ 轮：制鞋机器人在手订单破 4 亿，单工序 7 秒/个、ROI 50%–70%

**事件内容**

中科院自动化所孵化的 **中科慧灵** 完成数亿元 **A++ 轮**融资，知来投资、涌铧投资、茂天投资、元禾辰坤、国科科智、鲁宁投资联合投资。公司走的是"本体 + 具身大脑 + 灵巧手"全栈自研，主攻工厂与矿山等复杂场景，产品含全尺寸人形与轮臂式机器人。

真正值得注意的是它在制鞋场景的落地数据：

| 指标 | 数值 |
|---|---|
| 在手订单 | 2026 年具身制鞋机器人订单**突破 4 亿元**，排产**数千台**量级 |
| 工序节拍 | 大底盖章 **7 秒/个**；鞋底压合 **18 秒/双** |
| 客户 ROI | 年投资回报率 **50%–70%** |
| 模型 | 自研 **CAS-brain** 具身大模型 + **CASBOT PA**（Perception-to-Action）感知到动作模型，**支持单张消费级 GPU 训练** |
| 验证现场 | 莆田制鞋工厂实建制鞋工位，以机械臂为执行载体 |

**值得关注的原因**

1. **订单 4 亿 + 数千台排产，在当下人形赛道里是稀缺的"真金白银"信号。** 对比 10-26 期"具身算账"那期给出的行业面（日租金跌到千元、二手残值缩水七八成、家庭场景 12%），中科慧灵给的是另一面：**放弃通用人形叙事，挑一道最标准化、最难招人的工序，把 ROI 算到工厂老板能签字。** 这是"先吃透一个垂直行业再复制"的路径，与智元"全栈 + 梯度落地"是两种打法。
2. **"单张消费级 GPU 可训练"是一个被低估的工程指标。** 它意味着迭代成本从"租算力集群"降到"买一张卡"，对硬件创业团队的试错频率是数量级的改变。对照 10-24 期高德"无本体全身数据采集效率 3.4 倍"、10-26 期 Mirendil"1000 万美元训千亿"，同一条主线：**降低训练门槛正在比提升模型上限更能决定落地速度。**
3. **7 秒/个是这类案例最该被追问的数字。** 它决定了机器人能否跟上流水线节拍（人工通常 8–12 秒）。但"在手订单"与"确认收入"之间隔着交付与验收，数千台排产对供应链、品控、售后是真考验——这也是绝大多数机器人公司卡住的地方。**下一期该追的是：这 4 亿里有多少已经交付、复购率如何。**
