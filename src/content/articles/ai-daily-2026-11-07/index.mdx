**主题：Coding 交互层再升级（语音 / 编排），harness 思想反向输出到机器人**

---

## 主条目

### 1. Cursor 推出"与智能体实时语音协作"（11/6）

- 开发者可与编码智能体**双向语音对话**：口头描述改动、询问进展、查看 diff 与运行状态，智能体后台继续干活；执行中主动播报简短进度，完成后给结果说明。
- 覆盖 Agents Window、IDE、网页端、iOS；iPhone 支持 "Hey Siri, call Cursor"，锁屏/灵动岛可静音挂断。通话内查询为只读，不打断编码任务。
- 技术上语音层由 **Grok Voice** 驱动（识别+合成），编码仍走用户自选模型；Privacy Mode 下零数据留存；有每日上限，静默约 10 分钟自动挂断。
- **为什么值得关注**：与"听写转文字"不同，这是语音对语音的双向通道——AI 编程的交互入口从键盘扩展到"打电话"，适合异步监督长任务的场景（用户此前抱怨"睡一觉醒来 agent 卡在第一轮"正是这个痛点）。

### 2. Amp 推出 Spaces：主 Agent 自动编排多线程

- 用户只与一个主 Agent 对话，由它理解目标、拆解任务、**自动创建并协调并行 Agent 线程**；进展以实时卡片呈现在聊天中，点卡片可进线程看产出、继续迭代。
- 定位为团队协作场所：成员在同一 Space 提需求、评论；仅 @amp 时才读取评论以减少干扰。官方案例：单个 Space 完成服务账号功能发布、定期安全审查。
- **为什么值得关注**：多 Agent 工作流此前是"用户自己拆分、分派、追踪"，Spaces 把组织层交给 Agent——与昨天 LoopForge 的 Main Bot、Conductor 被 Meta 收编是同一趋势的三家不同解法：**从"工具"走向"AI 项目经理"**。

### 3. Anthropic coding 治理一松一紧：防复刻禁令放宽 + Security Center 上线

- **放宽**：10 月底上线的 Claude Code 防游戏复刻指令因误伤正常开发（含软件分析、逆向工程），约一周后修改：直接复刻仍拒绝，但**允许做同类型新游戏**（可借鉴特定战斗系统等点子）；升级到 v2.1.317+ 生效。Addy Osmani 承认短规则误伤了"提现有游戏名只是解释需求"的用户。
- **收紧**：Anthropic 上线 **Security Center**——实时仪表盘，覆盖 Chat、Cowork、Claude Code 三个面，持续将企业配置与 Anthropic 安全基线比对，可生成"auditor-ready"导出。
- **为什么值得关注**：一周内一松一紧，说明"系统指令当治理工具"这条路线在真实使用压力下快速迭代；合规仪表盘则可能成为未来企业合同的事实门槛。

### 4. 清华×Berkeley uni-robot-agent：把 Codex/Claude Code 当机器人运行时

- 用 Codex 与 Claude Code 作为 runtime，让开源模型通过标准工具集（看/移/抓）控制机器人；相机帧绑定实时臂状态，模型可"边动边想"。
- 结果：Qwen3.8-Flash-Next 在 RoboDojo 从 **1.90 → 31.39**，超过旧设置下 GPT-6 Astra 的 28.97；19 个真机双臂任务 53.50 分，超过调优过的专用机器人模型；**单任务成本 $1.09 vs $21.29**。
- **为什么值得关注**：本期最有趣的跨界——coding 圈"harness 决定上限"的经验（同一模型换个 harness 分数翻十几倍）被直接搬到具身智能。对"本体厂商开放接口找大脑"（宇树全球找大脑、智元外挂 Astra）路线是一个强佐证：**通用 coding agent + 好的工具层，可能比专用 VLA 更便宜更好用**。

### 5. 它石智航×安波福进博会签约：百台级年底部署 + 千台级集群

- 安波福年底前完成**百台级**它石 A 系列工业具身机器人规模部署，覆盖 8 大生产工艺、33 类应用场景（柔性组装、检测协同、生产管理），首批已进真实产线；工业具身算力底座 2026 年内量产。
- 依托它石通用具身大模型 AWE（AI World Engine），双方此前已启动全国首个**千台级**工业具身机器人集群建设，首期落地安波福生产基地；A3 机器人同步亮相进博会展位。
- **为什么值得关注**：汽车零部件巨头的严格工程标准是具身智能最硬的"考场"；从单点试点→百台→千台集群的口径变化，是"进厂打工"叙事里少有的可验证规模指标（此前优必选柳州、美的美罗U 均为百台内）。
