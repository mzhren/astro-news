**主题：CoRL 开幕日——具身智能的瓶颈从"会不会"挪到"跑不跑得动"；Coding 侧把评审前移成流程**

---

## 主条目

### 1. CoRL 2026 今日开幕（奥斯汀，11/9–12）：687 篇入选创纪录，英伟达同日放出 VFlash 动作解码加速

- 投稿 **2094 篇、接收 687 篇**，均为历史最高，注册已售罄。 keynote 阵容：Wolfram Burgard、Russ Tedrake、李飞飞（另有李飞飞 × 苏姿丰对谈），三场 Early-Career keynote；新增 **Late-Breaking Results** 赛道，明确列出 **Agentic Robotics** 与 **Real2Sim2Real** 两个方向。
- 英伟达 Jim Fan 今日 13:50（奥斯汀时间，北京 11/10 凌晨 3:50）做 keynote，主题 **world action models 与 humanoids**。预热视频已被其本人确认：**真机、全自主、未加速、一镜到底**，展示抓取线缆/橄榄球/哑铃/铸铁锅等差异极大的操作。
- 同日英伟达发布 **VFlash**：用 5 层非因果 Transformer 草稿模型**一次并行预测点、框、轨迹等视觉基元**，替代逐 token 自回归解码。官方口径：机器人动作解码最高 **12×**，整体机器人推理**5.1×**，3D 轨迹误差最多 **-61%**，3D 点运动预测生成快约 **25×**；MolmoSpaces 四组任务中接入 VFlash 规划的世界动作模型平均成功率 **70.2% vs 基线 62.6%**（数据来自基准测试，非真机）。
- **为什么值得关注**：两条线同时说明一件事——**"动作 token 的解码效率"正在成为具身智能的一等公民**。过去一年行业争论"VLA 够不够聪明"，而 12× 的推理解码提速意味着同一条策略可以在更高控制频率下重规划，这是"从演示到能用"的物理前提。这与 coding agent 侧的现实完全同构：模型智商之外，吞吐与延迟才是体验上限。另外 Agentic Robotics 首次成为独立赛道，说明 agent 范式（规划—调用—反馈）已经正式渗进机器人学术界，而不再是工业界的自说自话。

### 2. Google 开源 EGM（Elephant-Goldfish Model）插件：把"评审"从 PR 前移到 Markdown 规格

- EGM 不是模型，是**Apache 2.0 的流程插件**：7 个 skills、9 种 reviewer persona、6 个头脑风暴视角（YAGNI、token 成本、UX、迁移、可观测性、技术债）、5 阶段评审。不含权重，LLM 由宿主 agent 自备。
- 三段式命令：`/egm-brainstorm`（只讨论不写码，产出 concepts_brief.md）→ `/egm-draft`（逐节写设计文档到 docs/designs/）→ `/egm-review`（Goldfish 协议）。评审五个阶段中关键的是**复述测试**：无上下文的新 subagent 要把设计讲回来，讲错说明文档有歧义；其次是实现就绪检查（文件路径、数据结构、函数签名是否齐备）。结论分 Blocker / Major / Nit，每阶段最多复审一次。硬规则：**宿主无法派生 fresh subagent 就直接终止**——同上下文评审不算 Goldfish 评审。
- 时间线上需注意：Google Open Source Blog **10/22 首发**，**11/6 发 v0.1.1**（新增 TRIZ 发明型评审员 + Cursor / OpenCode / GitHub Copilot 实验适配），11/8 MarkTechPost 做了完整拆解，本期按"v0.1.1 可用 + 首次详评"收录。
- 官方与第三方给出的证据是**混合的**，这点比宣传更有信息量：Antigravity CLI 1.4.5 跑通 16 个原生 reviewer、阶段顺序正确；Codex 0.163.0 跑 15 个 reviewer、2 次 live test 共 573.13s；Codex CLI + v0.1.0 ZIP 全套 482.30s 通过；**最差是 Claude Cowork，因用量限制在第 5–7 阶段中断**；另有 issue #237 报告 **AGENTS.md 泄漏进 Codex reviewer**，直接削弱"零上下文"的承诺。README 自认不是 Google 官方支持产品，也没有精度基准。
- **为什么值得关注**：AI coding 的竞争焦点从"上下文工程"（怎么把仓库塞进窗口）转向**"流程工程"**（怎么强制 agent 在写码前把假设摊到纸面上）。同期 GitHub Spec Kit、Kiro Specs、Superpowers 都在做 spec-first，但只有 EGM 把"由无上下文评审员审规格"做成了硬门禁。对团队的真实价值不在装插件，而在两条可迁移的做法：**设计阶段禁止写码**、**用复述测试当最便宜的歧义检测器**。风险同样清晰——token 成本高、部分宿主隔离未验证，等于用钱买纪律。

### 3. 特斯拉 Optimus 改口"只租不卖"：3 万美元成本、100 万台年产能、2027 年底才对外

- 马斯克在第 33 届巴伦投资大会上透露：Optimus 大概率**只租不卖**。初期制造成本约 **3 万美元**，后续有望降至 2 万；单台效率相当于 **5 名普通工人**；Fremont 工厂已开启早期量产，规划**年产能 100 万台**、约一年冲到满产、周产目标 **2 万台**；**2027 年底才开始向外部企业租赁交付**，前期优先供给自家工厂；搭载 AI5 芯片的版本预计 **2027 年 4 月**推出。他给的长期市场是"全球年需求 10 亿台"。
- 值得对照的同向动作：国内中石油与宇树的合营企业（昆仑制造+昆仑资本 60%、宇树 20%、泛界智能 20%）11 月公示，场景锁定油气/炼化巡检与抢险、综合能源站与海外协同，宇树 B2-Ex 防爆四足已在天然气集气站巡检；同时中石油方面明确计划通过**昆仑银行、昆仑金租探索机器人租赁**，对应工信部专项行动里"按效用付费、经营性租赁"的表述。
- **为什么值得关注**：这是主流厂商第一次把"卖硬件"换成"租产能"，等于公开承认——**现阶段人形机器人的客户 ROI 还撑不住一次性买断**。一旦改成租赁，竞争指标就从"单台售价/自由度/续航"变成"月租、在线率、单台月产出工时"。这也让 2026 年反复出现的那句话落地：机器人公司越来越像运营公司（VC 化、RaaS 化），财务报表的核心科目会从"出货量"漂移到"在岗时长 × 利用率"。

### 4. Agent 基础设施同日两层落地：Google ADK 2.14.0 把 A2A 转正，Claude Code 2.1.319 把 MCP 任务挪到后台

- **Google ADK 2.14.0**：把 **A2A（Agent-to-Agent）协议**、执行环境与 core runtime 一并标记 **stable**。这意味着 agent 之间的发现、委派与结果回传有了带版本承诺的规范，而不是各家 SDK 的私有约定。
- **Claude Code 2.1.319**（本周 2.1.317–319 打包看）：MCP server 以 task 方式跑的调用**立即转后台**，完成后回报，慢工具不再阻塞对话（可用 `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` 回退旧行为）；新增 `denyInsteadOfPrompting`；自定节奏 `/loop` 在一轮结束后不再自动续命（`CLAUDE_CODE_LOOP_KEEPALIVE=1` 可恢复）；`/tasks` 增加"Earlier in this session"行，可以重开已结束的 subagent 继续追问；2.1.318 起 `claude auth status` 输出登录到期日并在到期前 10 天告警；2.1.317 在可能把账号邮箱发到网络的工具调用前先询问。
- **为什么值得关注**：MCP（工具层）已经普及，A2A（agent 层）拿到 stable 标记后，跨厂商 agent 协作才真正具备"敢上生产"的前提。而 Claude Code 这几项改动全部指向同一个工程现实——**阻塞点已从"模型会不会写"变成"长任务怎么调度、并发怎么管、权限边界画在哪"**。MCP 任务后台化 + subagent 可重开 + loop 语义收紧，本质是把编程 agent 从"对话工具"改造成"任务队列"。

### 5. 简智机器人 DAS 2.0 今日在 CoRL 首发：数据生意从"卖小时"转向"卖监督质量"

- 两条产品线：**DAS Dex 2.0** 灵巧手数据采集手套 + **DAS Ego 2.0** 第一视角头戴，头手协同，同步记录视觉、手部运动与触觉。三种配置对应不同监督强度：**纯 Ego**（轻量、覆盖广、含异常工况与失败修复过程）／**Ego + 腕部相机**（补接近方向、手指微调、手-物相对运动）／**Ego + Dex**（原生关节构型 + 真实接触，作为独立于视觉推断的测量依据）。
- 它对准的是四个具体断点：遮挡导致动作标签失真、相似轨迹产生不同接触结果、佩戴与信号干扰造成测量漂移、局部抓取片段缺少"走近—调整站位—搬运"的完整过程。
- 官方也自认短板：Ego + 腕部相机方案仍受工作距离、运动模糊、遮挡与时空间对齐影响，部分关节与接触状态存在不确定性；三类数据靠"对齐后的任务/轨迹/交互表征"混合训练，并非直接叠加。
- **为什么值得关注**：11/03 期报过简智 1 亿美元 A+ 时的商业模式是"卖数据小时"（售价 500–1000 元/h、成本约 30 元/h）。DAS 2.0 是这条业务往下扎的一层——**把"标签可不可验证"做成硬件属性**，而不只是堆采集时长。当所有数据商都在喊千万小时缺口时，真正决定单价的不是小时数，而是"这段轨迹的接触状态是否被原生测过"。这也是 CoRL 今年 Real2Sim2Real 与 agentic robotics 之外，最容易被低估的一条基础设施线。
